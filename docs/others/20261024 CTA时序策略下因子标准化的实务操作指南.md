# CTA时序策略下因子标准化的实务操作指南

版本 v1.0 ｜ 2026-10-24 ｜ 适用：日频、多品种期货时序策略（趋势、carry 等）

## 1. 目的与适用范围

本指南回答一个问题：在期货 CTA 时序策略中，原始因子应如何变换为可送入模型（如岭回归）或直接用于定仓的信号，同时做到三点：不引入前视偏差，不破坏信号本身的含义，不增加不必要的研究者自由度。

**适用**：日频或更低频、多品种、时序（每个品种对自身历史做多空判断）的策略。

**不适用**：截面选股类策略（需要每个时点跨资产标准化）、高频策略。

文中方法综合了公开文献（Moskowitz、Ooi、Pedersen 2012；Hurst、Ooi、Pedersen 2017；Carver 2015；López de Prado 2018）和常见从业做法，并非行业统一标准。文中的窗口、阈值均为示例起点，必须按第 0 步规则在你自己的数据上确定，并计入试验次数。

## 2. 标准化要达成的四个目标

1. **量纲统一**：不同因子、不同品种的数值尺度差异很大，需要放到可比的量级。
2. **岭惩罚公平**：岭回归的 λ 对所有特征一视同仁，前提是特征同尺度。
3. **跨品种可比**：同样大小的信号，在不同品种上应有相近的经济含义。
4. **分布近似平稳**：历史上估计出的系数 β，只有在特征分布不剧烈漂移时才可能迁移到未来。

## 3. 七条核心原则

1. **先问因子有没有天然零点。** 有（动量、carry 的正负代表方向），则只缩放、不去均值；没有（水平型因子），才需要去均值。
2. **优先结构性归一。** 在构造因子时就除以风险尺度，使其具有经济含义，再做统计缩放。
3. **所有统计量只能使用 t 时刻已知的数据。** 禁止用全样本均值、标准差。
4. **训练和测试用同一套因子构造程序。** 否则 β 与测试期特征的口径不一致。
5. **标准化器属于模型的一部分。** 随折估计、随折冻结，和回归系数一起处理。
6. **缩放系数优先池化估计。** 跨品种、跨时间合并估计，噪声更小，并保留品种间信号强度的差异。
7. **最后加截断，并把所有选择记录为自由度。** 窗口长度、是否去均值、截断阈值都计入试验次数 N。

## 4. 因子分类与默认处理

| 因子类型 | 例子 | 默认处理 | 不建议 |
| --- | --- | --- | --- |
| 有天然零点，符号即信号 | 时间序列动量、carry（基差） | 结构性归一 + 池化只缩放 + 截断 | 滚动去均值 |
| 水平型，无天然零点 | 波动率水平、持仓量水平 | 取对数后减去因果均值，再缩放 | 直接用原始水平 |
| 变化量型，以零为中心 | 持仓量变化率、基差变化 | 只缩放 + 截断 | 去均值 |
| 比值型 | 短期波动率 / 长期波动率 | 取对数后视作变化量型 | 直接使用比值（右偏严重） |

**为什么动量不能滚动去均值。** 设某品种连续上涨两年，12 个月动量一直为正且很大。对它做 1 年窗口的滚动 z-score，窗口均值也很高，结果接近 0 甚至为负，策略会在趋势最强时减仓。时序动量的信号本身就是方向，去均值把“现在是否为正”变成了“现在是否比最近更强”，含义已经改变。carry 同理。

## 5. 方法库

| 方法 | 做法 | 优点 | 主要风险 | 适用场景 |
| --- | --- | --- | --- | --- |
| 固定窗口 fit | 在训练期估计均值、标准差，冻结后应用于之后数据 | 简单，与 β 口径一致，无前视 | 非平稳时样本外分布漂移 | walk-forward 每折默认做法 |
| 滚动窗口 z-score | 用截至 t 的最近 W 日统计量 | 自适应，分布较平稳 | 多一个自由度 W；会抹掉有方向含义的信号 | 水平型因子 |
| 扩展窗口 | 用起点到 t 的全部历史 | 稳定，估计噪声小 | 适应慢，早期样本少需预热 | 缩放系数估计 |
| EWMA 统计量 | 指数加权的均值和方差 | 无窗口边缘效应，平滑 | 半衰期是自由度 | 波动率估计 |
| 只缩放不去中心 | x / std(x) 或 x / RMS(x) | 保留符号含义 | 无 | 动量、carry、变化量 |
| 结构性归一 | 构造时除以 σ√L 等风险尺度 | 经济含义清晰，天然跨品种可比 | 依赖 σ 的估计质量 | 趋势、carry |
| 池化 vs 逐品种 | 所有品种合并估计一个缩放系数 / 每品种单独估计 | 池化噪声小；逐品种使每个品种分布单位化 | 池化可能被高信号品种主导；逐品种样本少 | 优先池化 |
| 稳健化 | 截断、中位数 / MAD、秩变换、tanh 压缩 | 抑制肥尾和极端行情 | 截断阈值是自由度 | 叠加在上述方法之后 |

截面标准化（每个时点跨品种做 z-score）会减去截面均值，抹掉“整个板块一起涨”的方向信息，把策略变成截面策略，时序 CTA 通常不用。

## 6. 推荐的默认流程

以动量、期限结构（carry）、波动率、持仓量变化四个因子为例。

### 步骤 1：事前波动率 σ

- 用日收益（展期调整后）的 EWMA 标准差，半衰期可从 30 到 60 日起步。
- σ(t) 只能使用截至 t 收盘已知的收益；若在 t 收盘后生成信号、t+1 执行，不可混入 t+1 的数据。
- 设置下限，避免极低波动期出现除以极小数导致信号爆炸。

### 步骤 2：结构性归一（构造因子）

```
动量   m_L = ln(P_t / P_{t-L}) / (σ_t × √L)        # 类 t 统计量；P 为展期调整后价格
carry  c   = 年化基差 / (σ_t × √252)                  # 年化基差 = (近月-远月)/近月 ÷ 合约间隔年数；现货升水为正
波动率 v   = ln σ_t - EWMA(ln σ, 长半衰期)            # 水平型：对数后减因果均值
持仓量 o   = ln(OI_t / OI_{t-k})                      # 用各月份合计持仓；变化量型
```

要点：所有 EWMA、滚动量都必须是因果的；价格序列用展期调整后序列，展期日的价差不可当作收益。

### 步骤 3：池化缩放

对每个因子 f，在估计窗口内把所有品种、所有时点的原始值合并，计算

```
s_f = 1 / sqrt( mean( x_raw² ) )          # RMS 缩放，使信号二阶矩约为 1
x_scaled = s_f × x_raw
```

- 与岭回归的惩罚口径最匹配时用 RMS；若沿用 Carver 的做法，也可使用平均绝对值（令平均 |x| 等于某个固定值）。两者二选一，写入规则。
- 水平型因子先减去因果均值，再做同样的缩放。
- 估计窗口按第 7 节确定：每折固定，或随时间扩展。

### 步骤 4：截断

对缩放后的因子截断到 ±c（c 可取 3 或 4）。训练样本和测试样本必须使用同一个 c。

### 步骤 5：进入模型

截断后的因子进入岭回归，目标变量为 r(t+h) / σ(t)。因子为 x、目标为标准化收益后，仓位为 w ∝ (β̃′x) / σ，再按组合目标波动率统一缩放。

## 7. 在 walk-forward 中的实现

### 7.1 每折估计什么、何时冻结

| 对象 | 估计所用数据 | 注意事项 |
| --- | --- | --- |
| 缩放系数 s\_f、水平型因子的均值 | 仅需特征数据，截至测试开始前 | 因为不依赖标签，不存在标签成熟度问题；但必须在测试开始前冻结 |
| 岭回归系数 β | 训练 + 验证中标签已成熟的样本 | 标签窗口 h 内尚未成熟的样本需剔除（purging）；各段之间留禁入期 |
| 超参数（λ、窗口、截断阈值） | 在验证集上选定 | 选定后不再改动，重拟合时沿用 |

### 7.2 两种部署口径，须与实盘一致

- **口径 A：每折冻结。** 标准化器与 β 一起在折开始时估计并冻结，测试期不更新。最干净，适合研究阶段。
- **口径 B：因果扩展更新。** 测试期内缩放系数随扩展窗口更新，每个值只用到 t 之前的数据。此时训练期的特征也必须用同样的因果方式构造，而不是用整个训练期的统计量一次性标准化，否则训练和测试的特征口径不同。

回测评估的应是你实际会部署的流程。选哪一种，在第 0 步写明。

### 7.3 伪代码

```
for fold in walk_forward_folds:
    feat_raw = build_structural_features(prices, sigma)        # 步骤 1-2，全程因果
    scaler   = fit_pooled_scaler(feat_raw[fold.train_val_end_before_test])   # 仅特征，截至测试开始前
    X        = clip(scaler.transform(feat_raw), -c, c)
    # 超参数在验证集选定
    best     = select_on_validation(X, y, grid)
    # 重拟合：只用标签已成熟的训练+验证样本
    model    = fit_ridge(X[mature_train_val], y[mature_train_val], best)
    freeze(scaler, model)
    pnl      = trade(model, X[fold.test])                      # 测试期只预测，不更新
```

## 8. 常见错误清单

| 错误 | 后果 | 避免方法 |
| --- | --- | --- |
| 用全样本均值、标准差标准化后再切分训练和测试 | 前视偏差，样本外结果虚高 | 标准化器仅用估计窗口内数据 |
| 对动量、carry 做滚动去均值 | 趋势最强时信号变弱或反号 | 只缩放；在构造阶段用 σ 归一 |
| σ 使用未来实现波动率 | 前视偏差 | σ 必须是事前估计，且下限保护 |
| 逐品种用极短窗口估计缩放系数 | 噪声大，信号尺度随机跳动 | 池化，窗口足够长，设预热期 |
| 训练集用整段统计量，测试集用滚动统计量 | 训练、测试特征口径不一致 | 训练和测试使用同一套因果构造 |
| 重拟合时把标签未成熟的样本放进来 | 测试期信息泄露 | 做 purging，仅用标签窗口在测试开始前结束的样本 |
| 展期日的价差被当作收益，进入动量或 σ | 因子和波动率被污染 | 使用展期调整后价格 |
| 只在训练集上截断、测试集不截断（或阈值不同） | 极端行情下测试期仓位失控 | 全程同一阈值 |
| 看到测试结果后更换窗口或阈值 | 测试集被污染 | 规则预先固定；改动视为新试验并计数 |
| 持仓量只取主力合约 | 展期前后出现伪跳变 | 用各月份合计持仓，或在展期窗口内做平滑 |

## 9. 诊断与验收清单

在使用标准化后的因子之前，建议逐项检查：

1. **因果性测试。** 把数据截断到某个时点 t，重新计算该时点的标准化因子，与用全部数据计算的 t 时刻值比较，二者必须完全相同。这是发现前视最直接的方法。
2. **符号一致性。** 对只缩放的因子，缩放前后每个观测的符号必须一致。
3. **跨折分布稳定性。** 每折标准化后特征的均值、标准差、偏度；若各折标准差差异很大，说明标准化口径没有起作用。
4. **缩放系数的跨折稳定性。** s\_f 在各折之间是否大致平稳；剧烈跳变通常意味着窗口太短或数据被极端事件主导。
5. **截断比例。** 被截断的观测占比，按品种和按年份分别看。占比长期偏高，说明因子定义或缩放口径有问题，而不是阈值太小。
6. **板块均衡。** 分板块（能源、金属、农产品、利率、股指）看平均绝对信号，是否有某一板块长期主导。
7. **因子相关性。** 标准化后因子之间的相关矩阵是否稳定，是否出现高度共线导致岭回归系数跨折反复翻转。
8. **换手与成本。** 标准化方案不同会改变信号平滑度，需用含成本的净结果比较。

## 10. 第 0 步：需预先写入的规则

在查看任何测试数据之前，以下选择应写成文档并冻结：

- 展期调整与价格拼接方法；
- σ 的估计方式：EWMA 半衰期、下限；
- 每个因子的类型归属（有零点、水平型、变化量型）及对应处理；
- 结构性归一的具体公式（回看长度 L、年化口径）；
- 缩放方式（RMS 或平均绝对值）、池化范围、估计窗口、预热期长度；
- 截断阈值 c；
- 部署口径（A 每折冻结，或 B 因果扩展更新）；
- 候选方案总数 N（含窗口、阈值、是否去均值等所有选项的组合）；
- 测试集封存声明。

## 11. 稳健性对照

默认方案确定之后，用其他方案做对照，而非用来选优：

- 对照 1：对动量和 carry 做滚动去均值，观察表现和换手的变化，用来量化去均值对信号的破坏程度。
- 对照 2：逐品种缩放替代池化，观察是否被个别品种主导。
- 对照 3：不同截断阈值（例如 3 与 4、不截断），观察极端行情下的敏感度。
- 对照 4：不同波动率半衰期，观察结论是否依赖某个特定参数。

若各对照下结论方向一致，说明结果对标准化选择不敏感，可信度更高；若某个方案明显更好，也不应直接换用，而应把该发现记为新假设，在未被看过的数据上验证，并计入试验次数。

## 12. 一页速查

- 有方向含义的因子：**只缩放，不去均值**。
- 先 **σ 归一** 做结构性归一，再 **池化** 估计缩放系数。
- 统计量一律 **因果**，标准化器随折 **估计、冻结**。
- 训练和测试 **同一套构造程序**。
- 最后 **截断**，阈值全程一致。
- 所有选择 **写入第 0 步、计入 N**，用截断测试验证无前视。

结论：指南中的动量结构化归一公式是合理、常见的一类“波动率调整趋势强度”构造，可以作为基准方案；但它不是 CTA 唯一的标准做法，也不应称为严格的 Student t 统计量。

## 1. 对指南中动量公式的判断

指南当前公式为：

$$
m_{t,L}=
\frac{\ln(P_t/P_{t-L})}
{\hat\sigma_t\sqrt L}
$$

见[实务操作指南第 71 行](</D:/量化策略/CTA策略/Multi-factor Trend Following/docs/others/20261024 CTA时序策略下因子标准化的实务操作指南.md:71>)。

若 $\hat\sigma_t$ 是日波动率，则：

- 分子是过去 $L$ 日累计对数收益；
- 分母是“日波动率 × $\sqrt L$”；
- 结果可解释为过去趋势收益相对于正常波动范围有多强，是无量纲信号；
- 保留正负号，不需要再减去滚动均值。

因此，这是合理而且实务中常见的连续型趋势信号。J.P. Morgan 的趋势指标分类中也明确列有“过去收益除以收益波动率”的 Return-to-Volatility 指标。[J.P. Morgan《Momentum Strategies Across Asset Classes》](https://www.cmegroup.com/education/files/jpm-momentum-strategies-2015-04-15.pdf)

不过需要澄清三点。

### 它只是“类 t 统计量”

在独立同分布、方差稳定的简化假设下，检验日均收益是否为零的 t 统计量是：

$$
t=
\frac{\bar r}{s/\sqrt L}
=
\frac{\sum_{j=0}^{L-1}r_{t-j}}
{s\sqrt L}
$$

这和指南公式形式接近。但指南中的 $\hat\sigma_t$ 是另行估计的事前条件波动率，而不是同一窗口内用于计算标准误的样本标准差；也没有处理收益自相关。

因此更准确的名称是：

> 波动率调整后的累计收益、Sharpe-like trend strength，或近似 t-score。

如果真的需要统计意义上的 t 值，应估计均值的标准误，并在存在自相关时使用 Newey–West/HAC 标准误。CTA 文献中确实也有直接使用过去日收益 Newey–West t 统计量作为连续趋势强度的做法。[CME/Baltas & Kosowski 的研究](https://www.cmegroup.com/content/dam/cmegroup/education/files/demystifiing-time-series-momentum-strategies.pdf)

### 日波动率与年化波动率必须明确

上述写法要求 $\hat\sigma_t$ 是日波动率。如果内部保存的是年化波动率，则应写成：

$$
m_{t,L}=
\frac{\ln(P_t/P_{t-L})}
{\hat\sigma_t^{ann}\sqrt{L/A}}
$$

其中 $A$ 是每年交易期数，例如 252。

两种写法完全等价：

$$
\hat\sigma_t^{ann}=\sqrt A\,\hat\sigma_t^{daily}
$$

同理，年化 carry 应当除以年化波动率：

$$
c_t=\frac{\text{annualized carry}_t}{\hat\sigma_t^{ann}}
=
\frac{\text{annualized carry}_t}
{\hat\sigma_t^{daily}\sqrt A}
$$

我建议项目内部明确规定“波动率组件输出日波动率还是年化波动率”，不要在各因子中隐式猜测。

### 当前实现和指南并不完全相同

当前 `MomentumFactor` 计算的是：

$$
\prod_{j=0}^{L-1}(1+r_{t-j})-1
$$

即累计简单收益，见[trend.py](</D:/量化策略/CTA策略/Multi-factor Trend Following/factors/library/trend.py:100>)；指南准备使用累计对数收益。

两者符号相同，但数值并不完全相等。若最终采用指南公式，最一致的计算是：

$$
\ln(P_t/P_{t-L})
=\sum_{j=0}^{L-1}\ln(1+r_{t-j})
$$

同时用这些日对数收益估计 $\sigma$。

另外，经典 Moskowitz–Ooi–Pedersen TSMOM 并不是直接采用这个连续信号，而是：

$$
\operatorname{sign}(R_{t-L,t})
$$

决定方向，再用 $1/\sigma_t$ 定仓。也就是说，指南属于“连续趋势强度”版本，而经典 TSMOM 是“二元方向 + 逆波动率仓位”版本。[Moskowitz、Ooi、Pedersen 原文](https://docs.lhpedersen.com/TimeSeriesMomentum.pdf)

所以最准确的结论是：

> 指南公式属于实务常见且合理的连续型波动率调整动量，但不是唯一或原始的经典 TSMOM 定义。

## 2. EWMA 条件波动率

令 $r_t$ 为日收益，并假定在 $t$ 收盘后估计下一期波动率。

### 零均值二阶矩版本

日频收益的条件均值很小，风险管理中经常直接假设其为零：

$$
\hat v_{t+1|t}
=(1-\lambda)\sum_{j=0}^{\infty}\lambda^j r_{t-j}^2
$$

递推形式为：

$$
\hat v_{t+1|t}
=\lambda\hat v_{t|t-1}
+(1-\lambda)r_t^2
$$

$$
\hat\sigma_{t+1|t}=\sqrt{\hat v_{t+1|t}}
$$

这是常说的 EWMA 二阶矩/RiskMetrics 版本。

### 去均值版本

如果希望和通常的标准差定义一致，可以同时估计 EWMA 均值：

$$
\hat\mu_t=(1-\lambda)
\sum_{j=0}^{\infty}\lambda^jr_{t-j}
$$

$$
\hat v_{t+1|t}
=(1-\lambda)\sum_{j=0}^{\infty}
\lambda^j(r_{t-j}-\hat\mu_t)^2
$$

Moskowitz、Ooi、Pedersen 使用的就是类似的去均值 EWMA，并使用上一期可得的波动率，避免前视。

日频 CTA 中两种结果通常很接近。若目标主要是定仓和风险控制，零均值二阶矩更简单、稳定；若希望与统计意义上的标准差完全一致，可采用去均值版本。关键是统一口径。

### 衰减参数

半衰期 $h$ 和衰减系数 $\lambda$ 的关系是：

$$
\lambda=2^{-1/h},
\qquad
h=\frac{\ln(1/2)}{\ln\lambda}
$$

几个有代表性的值：

| 口径 | $\lambda$ | 半衰期 |
|---|---:|---:|
| RiskMetrics 日频默认 | 0.94 | 约 11.2 日 |
| 半衰期 30 日 | 0.9772 | 30 日 |
| MOP“权重重心 60 日” | $60/61=0.9836$ | 约 41.9 日 |
| 半衰期 60 日 | 0.9885 | 60 日 |

这里特别容易混淆：

> MOP 的“权重重心 60 日”不等于“半衰期 60 日”。

RiskMetrics 的经典日频参数是 $\lambda=0.94$，但它比较灵敏，更接近短期市场风险模型。对于日频、中慢速 CTA，指南提出的 30～60 日半衰期是合理的起始区间。MOP 的设定折算成约 42 日半衰期，正好处于其中。[RiskMetrics Technical Document](https://faculty.runi.ac.il/kobi/riskmgt/rmtd.pdf)

### 实务估计算法

对每个品种分别计算，基本步骤如下：

1. 准备展期处理后的日收益 $r_t$，缺失值不填成 0。
2. 由半衰期计算 $\lambda=2^{-1/h}$。
3. 维护权重和 $W$、一阶加权和 $S$、二阶加权和 $Q$ 与有效观测数 $n$。
4. 有效收益到达时更新 $W\leftarrow\lambda W+1$、$S\leftarrow\lambda S+r_t$、$Q\leftarrow\lambda Q+r_t^2$；缺失时该品种状态不变。
5. 零均值方差取 $Q/W$；去均值方差取 $Q/W-(S/W)^2$。暖机期不足、方差非正或非有限时输出 NaN。

归一化有限样本权重避免了首值初始化口径对早期结果的额外影响。核心 NumPy 写法如下：

```python
def ewma_volatility(returns, halflife, min_periods=20, demean=False):
    values = np.asarray(returns, dtype=float)
    one_dimensional = values.ndim == 1
    matrix = values.reshape(-1, 1) if one_dimensional else values
    lam = 2.0 ** (-1.0 / halflife)
    weight = np.zeros(matrix.shape[1])
    first = np.zeros(matrix.shape[1])
    second = np.zeros(matrix.shape[1])
    count = np.zeros(matrix.shape[1], dtype=int)
    output = np.full(matrix.shape, np.nan)

    for i, row in enumerate(matrix):
        valid = np.isfinite(row)
        weight[valid] = lam * weight[valid] + 1.0
        first[valid] = lam * first[valid] + row[valid]
        second[valid] = lam * second[valid] + row[valid] ** 2
        count[valid] += 1

        with np.errstate(invalid='ignore', divide='ignore'):
            variance = second / weight
            if demean:
                variance -= (first / weight) ** 2
        usable = ((count >= min_periods) & np.isfinite(variance)
                  & (variance > 0))
        output[i, usable] = np.sqrt(variance[usable])

    return output[:, 0] if one_dimensional else output
```

上述时点 $t$ 的输出已经吸收 $r_t$，含义是 $\hat\sigma_{t+1|t}$，可用于 $t$ 收盘后生成、下一期执行的信号。若用它缩放同一期收益 $r_t$，必须先 `shift(1)`。年化时再乘 $\sqrt A$；逆波动率定仓前还应设置波动率下限，避免除以接近 0 的估计值。

工程上，供因子调用的共享波动率组件只提供批量接口，不公开增量状态。权重机为避免每次重新扫描全部历史，可在内部缓存同一递推的 $W,S,Q,n$；该缓存是风险管理器的私有性能实现，不供因子调用。

## 3. 滚动窗口标准差

给定最近 $W$ 个日收益：

$$
\bar r_t=
\frac1{n_t}\sum_{j=0}^{W-1}r_{t-j}
$$

样本标准差为：

$$
\hat\sigma_{t+1|t}
=
\sqrt{
\frac{
\sum_{j=0}^{W-1}(r_{t-j}-\bar r_t)^2
}{
n_t-1
}}
$$

其中 $n_t$ 是窗口内有效观测数。

当前 `risk.py` 正是这种口径：

- 最近 `volatility_lookback` 个时点；
- 忽略 NaN；
- 去均值；
- `ddof=1`；
- 有效观测不足时返回 NaN。

见[risk.py](</D:/量化策略/CTA策略/Multi-factor Trend Following/factors/diagnostic_portfolio/risk.py:116>)。这也与 pandas `Rolling.std(ddof=1)` 的默认口径一致。[pandas 官方文档](https://pandas.pydata.org/pandas-docs/stable/reference/api/pandas.api.typing.Rolling.std.html)

若采用零均值二阶矩口径，则对应的是：

$$
\hat\sigma_{t+1|t}
=
\sqrt{\frac1{n_t}\sum_{j=0}^{W-1}r_{t-j}^2}
$$

它严格来说是 RMS/实现波动率，而不是去均值的样本标准差。

常见窗口大致为：

- 20～21 日：响应快，但噪声和换手较高；
- 60～63 日：CTA 中较常见的折中；
- 120～126 日：更稳定、反应更慢；
- 252 日：长期风险尺度，单独用于快速风险控制通常偏慢。

没有普遍最优窗口。对当前项目，滚动 60 日可以作为简单基准，而 20 日和 120/252 日更适合作为稳健性对照。

## 4. 两种方法的实务差异

| 特征 | EWMA | 滚动标准差 |
|---|---|---|
| 历史权重 | 越近权重越大 | 窗口内等权 |
| 冲击进入 | 立即进入 | 立即进入 |
| 冲击退出 | 平滑衰减 | 到窗口边缘时突然消失 |
| 参数 | 半衰期或 $\lambda$ | 窗口 $W$ |
| 换手 | 通常更平滑 | 可能有窗口边缘跳变 |
| 可解释性 | 稍复杂 | 最直观 |
| 当前项目状态 | 尚未用于 `risk.py` | 已实现 |

对于逆波动率定仓，波动率估计误差会直接进入 $1/\hat\sigma$，因此会放大为仓位和换手误差。基于 OHLC 的 Yang–Zhang 等区间波动率估计能够提高统计效率，并有研究发现可以降低 TSMOM 的波动率驱动换手，但数据和实现复杂度也明显更高。[CME/Baltas & Kosowski](https://www.cmegroup.com/content/dam/cmegroup/education/files/demystifiing-time-series-momentum-strategies.pdf)

## 5. 因子归一与逆波动率定仓的关系

这两处确实都需要 $\sigma$，但经济含义不同：

$$
\underbrace{
\frac{R_{t-L,t}}{\sigma_t\sqrt L}
}_{\text{趋势强度}}
\quad\longrightarrow\quad
\underbrace{
w_t\propto\frac{\text{趋势强度}}{\sigma_t}
}_{\text{把预测转换成风险仓位}}
$$

所以在线性连续信号下，最终仓位对当前波动率可能近似具有 $1/\sigma_t^2$ 的敏感度。这不一定是重复计算：

- 第一遍 $\sigma$：衡量趋势本身有多显著；
- 第二遍 $\sigma$：控制每单位仓位承担的风险。

但它会导致波动率突然上升时，信号和仓位同时收缩，可能较为激进。经典二元 TSMOM 因为只取动量的符号，所以只有定仓阶段的 $1/\sigma$。

另一个常见的连续信号构造是逐日归一后再累计：

$$
m_{t,L}^{path}
=
\frac1{\sqrt L}
\sum_{j=0}^{L-1}
\frac{r_{t-j}}
{\hat\sigma_{t-j|t-j-1}}
$$

它在过去 $L$ 日发生波动率制度变化时，比“整段累计收益除以当前一个 $\sigma_t$”更严谨，也减少了整个历史趋势信号被当前单日波动率完全重标的程度。

## 建议的研究基准

后续制定实施方案时，我建议至少明确比较以下两条，而不是只讨论 EWMA 与滚动标准差：

1. 指南当前方案：累计对数收益除以当前事前波动率和 $\sqrt L$。
2. 路径归一方案：逐日收益先除以当时的事前波动率，再累计并除以 $\sqrt L$。

波动率估计方面，可以把以下作为预先规定的基准：

- 主方案：EWMA，半衰期约 42 日，对应 MOP“重心 60 日”的口径；
- 简单对照：当前 `risk.py` 的滚动 60 日样本标准差；
- 所有波动率都使用展期处理后的真实收益；
- 信号在 $t$ 收盘后生成时，只使用截至 $t$ 的数据，得到 $\hat\sigma_{t+1|t}$；
- 日频/年化单位、均值是否为零、预热期、缺失值规则和波动率下限都必须统一记录；
- 同一个波动率计算组件可以供因子和仓位共同使用，但应分别记录其用途，并检查连续信号下的“双重波动率敏感度”。

## 三、为什么不应该使用现有 Z-score

你的判断基本正确，但更准确地说：

> 对具有天然零点的方向信号，去均值不是单纯改变尺度，而是在改变因子定义。

当前动量的零点表示“过去累计收益为零”，carry 的零点表示“期限结构没有正负 carry”。如果执行

$$
z=(x-\mu)/\sigma
$$

零点会从 `0` 移到历史均值 `μ`。于是“小幅正动量”可能被变成负信号，因子的含义从“上涨还是下跌”变成了“是否强于自己的历史常态”。

现有 `FittedTimeSeriesZscore` 还有两个不匹配之处：

- 它是逐品种拟合均值和标准差，而你需要的是每个因子一个池化尺度；
- 它明确执行 `(x-\mu)/σ`，[会进行中心化](</D:/量化策略/CTA策略/Multi-factor Trend Following/factors/preprocess/scale.py:120>)。

`RollingTimeSeriesZscore` 同样不合适，因为它会把持续的强趋势逐渐变成接近零的“正常状态”。

因此不应把 `FittedTimeSeriesZscore` 改造成 walk-forward 后继续使用；应该新增语义不同的“池化、只缩放、不中心化”组件。

## 四、结构性归一和池化缩放能否互相替代

不能。

### 结构性归一

例如：

$$
m_{t,L}
=
\frac{\sum_{j=0}^{L-1}\log(1+r_{t-j})}
{\hat\sigma_t\sqrt L}
$$

$$
c_t
=
\frac{\text{annualized carry}_t}
{\hat\sigma_t\sqrt{252}}
$$

前提是这里的 \(\hat\sigma_t\) 是日波动率。如果直接使用年化波动率，carry 分母不能再乘 \(\sqrt{252}\)。

它解决的是：

- 不同波动环境下，同样的累计收益代表不同的趋势强度；
- 不同品种间收益尺度的经济可比性；
- 因子成为无量纲的风险调整预测。

当前 `MomentumFactor` 只是累计简单收益，[没有风险调整](</D:/量化策略/CTA策略/Multi-factor Trend Following/factors/library/trend.py:99>)；`RollYieldFactor` 是年化期限价差，[也没有波动率调整](</D:/量化策略/CTA策略/Multi-factor Trend Following/factors/library/term_structure.py:128>)。

这是合理的连续趋势信号方案，但并不是唯一方案。经典 TSMOM 更接近“累计收益符号决定方向，再以逆波动率定仓”，而不是连续信号先除一次波动率。[Moskowitz、Ooi、Pedersen](https://fairmodel.econ.yale.edu/ec439/mosk.pdf)；carry 本身同时具有时序和截面预测意义，[Koijen 等](https://spinup-000d1a-wp-offload-media.s3.amazonaws.com/faculty/wp-content/uploads/sites/3/2019/04/Carry.pdf)。

### 池化缩放

结构归一之后，动量和 carry 的经验分布仍不必相同。因此再对每个因子拟合：

$$
a_f
=
\frac{1}
{\sqrt{\operatorname{mean}_{(t,i)\in train}(x_{f,t,i}^2)}}
$$

$$
\tilde x_{f,t,i}=a_f x_{f,t,i}
$$

它解决的是：“一个典型动量观测”和“一个典型 carry 观测”在合成中具有相近数值幅度。

这里需要纠正指南中的一句表述：RMS 缩放不会“使均值为零”，它只会使二阶矩约为 1。它保留原来的零点、均值符号和所有观测的符号，这正是你需要的性质。

因此：

- 若只想快速修复 EqualWeight 的尺度支配问题，池化缩放最直接；
- 若想建立可迁移、跨品种有经济意义的因子，结构性归一更基础；
- 推荐主方案是两者都做；
- “结构归一 + 池化缩放”并不意味着重复标准化，因为二者估计对象和目的不同。

## 五、池化缩放是否要 walk-forward

是的，只要缩放系数由数据估计，就必须遵守样本外时间边界。但不一定要求标准化器自己内部完成 walk-forward。

更合理的职责划分是：

- `PooledScaler`：表示某一版本的一次 `fit → transform`；
- walk-forward 控制器：决定何时拟合、在哪个 OOS 区间应用、何时更新版本。

推荐第一版采用“扩展训练窗、按年冻结”：

```text
截至 2006 年的数据拟合尺度 → 变换 2007 年
截至 2007 年的数据重新拟合 → 变换 2008 年
截至 2008 年的数据重新拟合 → 变换 2009 年
……
```

测试折内部不更新，下一折开始时才重拟合。这比逐日更新更容易审计，也更接近明确的部署版本。

需要区分：

- 结构性归一中的波动率：每个时点因果滚动/EWMA 更新，不是按折固定；
- 池化尺度：按训练折估计并冻结；
- 仓位波动率：`ts_inv_vol_target_vol` 内部逐时点因果估计。

现有权重机之后还会执行 `signal / vol`，[再做 gross 归一](</D:/量化策略/CTA策略/Multi-factor Trend Following/factors/diagnostic_portfolio/weights.py:465>)。如果信号本身已除过波动率，最终可能表现出近似 $1/\sigma^2$ 的敏感度。这并非逻辑错误，但属于需要显式检验的模型选择：波动率上升时，信号强度和仓位都会同时收缩。

## 六、建议的落地方案

我建议把主基准预先定义为：

1. 先检查 roll yield 的极端值和大量 warning。当前最值约为 ±12，RMS 很容易被少量异常期限结构观测支配；标准化不能代替数据质量检查。
2. 为动量和 carry 增加因果的结构性归一版本，保留原始版本作为对照。
3. 新增 `FittedPooledScaler`：
   - 每个因子只拟合一个正数缩放系数；
   - 默认 RMS 或平均绝对值二选一；
   - 不减均值；
   - 跨品种、跨时间池化；
   - 保存拟合截止日、样本数、原始尺度和 multiplier。
4. 使用扩展训练窗、年度 OOS 折，尺度在每折内冻结。
5. 池化缩放后再截断，然后交给 `EqualWeightCombiner`。
6. 用真正的 `ts_inv_vol_target_vol` 配置运行连续 OOS 诊断。
7. 预先规定四个对照，而不是看结果后选择：
   - 原始因子直接合成；
   - 仅池化缩放；
   - 仅结构性归一；
   - 结构性归一 + 池化缩放（主方案）。
8. 除 Sharpe 外，重点检查：
   - 缩放前后符号完全一致；
   - 每折两个因子的 RMS/平均绝对值；
   - 两个成分对复合信号的实际贡献；
   - 截断比例；
   - 分品种、分板块信号幅度；
   - 缩放系数跨折稳定性；
   - 换手与成本。

一句话概括：不要把问题定义成“如何正确使用 Z-score”，而应定义成“如何构造保留天然零点的、风险调整且可等权合成的连续时序信号”。对应的答案是：因果结构性归一 + walk-forward 池化只缩放 + 截断 + 等权合成，最后再交给独立的仓位风险层。
