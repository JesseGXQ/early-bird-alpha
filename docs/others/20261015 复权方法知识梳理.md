
## 关于前复权和后复权的差异

之前 Gemini 告诉我的“必须使用前复权(backward-adjustment，即保持最新价格不变，向后调整历史价格)”用于量化研究，是错误的！

原因有两点：
1. 前复权会造成可能的 Look-Ahead bias：由于历史价格基于全部未来换月价格跳空计算，所以历史价格水平混入了未来信息。
2. （如果不是执行的 point-in-time 前复权），那么每一次换月，都要调整全部历史复权因子和复权历史价格。这会造成“过一个月，历史复权价格改变->基于历史复权价格计算的因子改变->信号改变->回测中的买卖动作改变（权重变化）”，而这显然和回测的基本逻辑相违背。
    - 当然不是所有因子/信号都会改变，如果一个因子计算具备平移不变性，例如 $f_t = (p_{t-1} - p_{t-5}) - (p_{t-5} - p_{t-10})$，那么这个因子就不会随时间变化，因为所有历史价格中的新换月因子都通过相减被去掉了。

如果想要避免上述两点，必须使用后复权(hfq)。前复权大多数被用于看盘、计算技术指标等。量化研究默认使用后复权计算历史价格，量价因子基于后复权历史价格计算。

## 关于加减法复权和乘法复权

期货应该用加减法复权：加法复权后的历史复权价格，用于计算收益，才能和历史真实收益对的上号，用乘法复权是不对的。见下面的例子。

### 后复权
(hfq， forward-adjustment，即上市初日价格不动，向较新日期方向调整价格)，下表中的$D$是主力合约标记。

|             |    $p_{old}$   |  $p_{new}$     | Adj_Price     |     Adj_Factor  |  Price_Gap     |
|---          | ---            | ---            |   ---         |  ---            |  ---           |
| 2025-06-10  |     $10^{D}$   |    9.2         |      10       |        0        |    0           |
| 2025-06-11  |     $11^{D}$   |     10         |      11       |        0        |    0           |
| 2025-06-12  |      12        |   $11.5^{D}$   |      12.5     |        1        |    1           |  
|             |                |                |               |                 |                |

* 注意 gap 记在换月日这一行
* 这里 $Price\_Gap = p_{old} - p_{new}$ ，且 $p_{old} $ 和 $p_{new}$ 都是换月日前一天的价格。



假设初始资金1000元，6-10日买入10手，价格10元/吨，品种乘数为 10吨/手。6-12日全部卖出。

PnL 6-11： (11-10)\*10\*10 = 100 

PnL 6-12:  (11.5-10)\*10\*10 = 150 

=> 总 PnL  = 100 + 150 = 250

如果用加法后复权计算：PnL = (12.5 - 10)\*10\*10 = 250 



### 前复权

下面我们看看前复权。

|             |    $p_{old}$   |  $p_{new}$     | Adj_Price     |     Adj_Factor  |  Price_Gap     |
|---          | ---            | ---            |   ---         |  ---            |  ---           |
| 2025-06-10  |     $10^{D}$   |    9.2         |      9        |        -1       |    0           |
| 2025-06-11  |     $11^{D}$   |     10         |      10       |        -1       |    -1          | 
| 2025-06-12  |      12        |   $11.5^{D}$   |      11.5     |        0        |    0           |  
|             |                |                |               |                 |                |

* 注意 gap 记在换月日前一行(这是原本 stitching.py::RollGapCalculator.build_master_table 的算法)
* 这里的 $Price\_Gap = p_{new} - p_{old}$ , Adj_Factor 从下至上做累加。

用加法前复权计算： PnL = (11.5 - 9)\*10\*10 = 250 

也是对的。

### 乘法复权 

下面我们看看用乘法后复权：

|             |    $p_{old}$   |  $p_{new}$                        | Adj_Price             |     Adj_Factor  |  $p_{ref}$     |      $r_{t}$     |    
|---          | ---            | ---                               |   ---                 |  ---            |  ---           |     ---          |
| 2025-06-10  |     $10^{D}$   |    9.2                            |    10                 |         1       |    1           |        1         |
| 2025-06-11  |     $11^{D}$   |     10                            |    11                 |         1       |    1           |        1         |
| 2025-06-12  |      12        |   $11.5^{D}$<-假设等同于现金分红    |  11.5*11/10.5=12.0476 |       11/10.5   |   11-0.5=10.5  |       11/10.5    |
|             |                |                                    |                      |                 |                |                  |

此时，如果用 Adj_Price 计算

PnL = (12.0476 - 10)\*10\*10 = 2.0476*100 = 204.76，这个数字就不对了。

**这里的核心原因是期货的盈亏计算公式是**：  

$$ (卖出点数 - 买入点数) × 合约乘数 ×  手数 $$

它是线性的，加法复权保留了线性结构，而乘法复权没有。


### 米筐对于这个问题的处理

可以看到，我们上面例子中的处理方式和米筐的处理方式是一样的：

> IF888 为对价格进行了"前复权平滑"处理，处理规则如下：以主力合约切换前一天（T-1 日）新、旧两个主力合约收盘价做差，之后将 T-1 日及以前的主力连续合约的所有价格水平整体加上或减去该价差，以"整体抬升"或"整体下降"主力合约的价格水平，成交量、持仓量均不作调整，成交额统一设置为 0.

> IF889 为对价格进行“后复权平滑”处理，处理规则如下：以主力合约切换当天（T 日）旧、新两个主力合约开盘价做差， 之后将 T 日及以后的主力连续合约的所有价格水平整体加上或减去该价差，成交量、持仓量均不作调整，成交额统一设置为 0

注意，这里米筐用了T日旧、新合约的**开盘价**之差来计算跳空。这里的假设是T-1日收盘判定的主力切换，在T日开盘做换仓，隔夜持有的是旧合约。而我们前面的例子中，用了用T-1收盘价计算跳空，并调整T日及之后的主力价格，实际上是假设T-1收盘判定到主力合约切换，在收盘换仓，隔夜持有新合约。这两种方法的差异，是**新、旧合约的隔夜涨跌差异**。两种方法没有绝对的对错之分。

> 主力连续合约：合约首次上市时，以当日收盘同品种持仓量最大者作为从第二个交易日开始的主力合约。当同品种其他合约持仓量在收盘后超过当前主力合约 1.1 倍时，从第二个交易日开始进行主力合约的切换。 日内不会进行主力合约的切换。主力连续合约是由该品种期货不同时期主力合约接续而成，代码以 88、888、889 结尾。


## 关于 Dual-Stream Approach

为什么需要双流，即多一条 True_Return 序列？因为只要加法复权，利用 Adj_Price 算出来的收益率是不对的。

以上面的例子为例：

前复权：11.5 / 9 -1 = 0.2778

后复权：12.5 /10 -1 = 0.25 （只是碰巧对了）

如果我们给增加一列 True_Return（后复权表格）

|             |    $p_{old}$   |  $p_{new}$     | Adj_Price     |     Adj_Factor  |  Price_Gap     |  True_Return      | 
|---          | ---            | ---            |   ---         |  ---            |  ---           |     ---           |
| 2025-06-10  |     $10^{D}$   |    9.2         |      10       |        0        |    0           |      .            |
| 2025-06-11  |     $11^{D}$   |     10         |      11       |        0        |    0           |     11/10-1       |
| 2025-06-12  |      12        |   $11.5^{D}$   |      12.5     |        1        |    1           |      11.5/10-1    |
|             |                |                |               |                 |                |                   |

6-10: 买入10手，持仓价值 = 10\*10\*10 = 1000, w = 1

6-11 全仓卖出，本金变为 1000 + (11-10)\*10\*10 = 1100。再购买
10手，持仓价值 = 10\*10\*10 = 1000, w = 1000/1100=10/11。

计算 
$$
NAV  
     = 1 * (1+ 1*(11/10-1)) * (1 + 10/11 *(11.5/10-1))
     = 1.25
$$
