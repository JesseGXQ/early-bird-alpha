# 收益率标签构造：概念辨析

本文是对答疑文档 §19《标签类型详解》的延伸讨论，回答在进入"收益率标签构造"开发前仍存疑的五个问题：

1. 收益方向标签的用途——布尔变量和连续因子值放一起能算什么？
2. 未来实现波动率标签的目的——为什么因子研究中很少见？
3. 风险暴露调整后残差收益——是否对应组合层的板块风险中性约束？
4. 波动率调整后收益——是否对应组合层的波动率仓位归一化？
5. 事件标签——本质是不是因子改性（因子 × I(事件)）？

本文不重复 §19 已有定义和数值例子，只补足"为什么需要、怎么用、和下游怎么对齐"这三层。文中所有公式用 Unicode 表示。

---

## 1. 收益方向标签：连续因子 × 二值标签能算什么？

### 1.1 问题重述

§19.2 给出了方向标签的定义——把未来 h 期收益 `r_h[t]` 映射为 `sign(r_h[t])`（可选加阈值得到三值 {-1, 0, +1}）。疑惑点在于：因子值 `F[t]` 是连续的（z-score、秩百分位等），标签 `y[t] ∈ {-1, +1}` 是离散的，这两者放到一起除了"看一眼正负是否一致"还能算什么？IC、Rank IC、分组多空这些连续标签下的标准评价似乎都对不上。

### 1.2 核心答案：换一套评价维度

连续标签下评价问的是**"相关性"**——因子预测收益幅度有多准。方向标签下评价问的是**"分类质量"**——因子判断涨跌方向有多准。这是两套不同的统计问题，对应不同的指标族。

#### 1.2.1 命中率（Hit Rate / Accuracy）

最直接的一个量。对每个 (品种, 时点) 配对：

```
hit[t, i] = I( sign(F[t, i]) == y_dir[t, i] )
```

面板平均命中率：

```
HitRate = mean over (t, i) of hit[t, i]
```

**注意一个微妙点**：`sign(F[t, i])` 把因子值也二值化了。也就是说命中率这条路径上，因子幅度的信息被丢掉了——只剩"因子正/负"和"未来涨/跌"是否对齐。这恰恰是趋势跟踪策略最朴素的形态：**因子正就做多、因子负就做空，盈亏看方向是否对**。所以命中率直接对应 trend following 信号的"方向胜率"，不需要经过分组或回归。

如果因子本身是连续的、想保留幅度信息但用方向标签，可以做"因子分位数 × 方向标签"的条件命中率——把因子按截面分 5 组，看每组内方向命中率，预期单调（高因子组命中率 > 50%，低因子组 < 50%）。这其实等价于分组多空，只是组内收益被压成 ±1。

#### 1.2.2 二分类指标族：Precision / Recall / F1 / AUC

这是 §19.2 表格里提到但没展开的部分。把"涨"视为正类，"跌"视为负类：

| 量 | 定义 | 因子语境下的含义 |
|---|---|---|
| Precision | TP / (TP + FP) | 因子说"涨"的日子里，真的涨的比例 |
| Recall | TP / (TP + FN) | 真正涨的日子里，因子发出"涨"信号的比例 |
| F1 | 2·P·R / (P+R) | 二者调和平均 |
| AUC | ROC 曲线下面积 | 把因子值本身作为分类器阈值时，区分涨跌的综合能力 |

**AUC 这里特别值得展开**。AUC 的数学定义是"随机抽一个正样本和一个负样本，正样本的因子值高于负样本因子值的概率"。这正好是**用因子连续值预测方向标签的判别力**——因子值越高，未来方向为正的概率越大？AUC = 0.5 表示因子对方向毫无判别力，AUC = 1.0 表示因子值完美分隔涨跌。

AUC 和 Rank IC 有强对应关系：对二值标签，`RankIC ≈ 2 × (AUC - 0.5)`（Mann-Whitney U 统计量与 Spearman 相关的关系）。所以**AUC 本质上就是 Rank IC 在二值标签下的等价表达**，不是说"算不了 IC"，而是 IC 换了件衣服。

#### 1.2.3 信息系数的变体：BPS-IC（Binary Point-Biserial IC）

如果想保留"算 IC"的习惯但用方向标签，可以用 Point-Biserial 相关系数——它就是 Pearson 相关在"一个变量连续、一个变量二值"时的特例：

```
r_pb = (mean(F | y=+1) - mean(F | y=-1)) / std(F) × sqrt(p(1-p))
```

其中 p 是 y=+1 的比例。这个值在数值上等于直接对 (F, y_dir) 算 Pearson 相关——没错，**Pearson 相关完全可以在连续 × 二值上算**，只是它的解释要换成"二值分组下两组因子均值差的标准差倍数"。

所以"因子值和方向标签能不能算 IC"——能，Pearson IC 数值上有效，解释变成"两组因子均值差异的尺度"。但实务上用 AUC 或命中率更多，因为它们更直观对应"方向判断准不准"。

### 1.3 什么时候该用方向标签而不是连续标签

| 场景 | 用连续标签 | 用方向标签 |
|---|---|---|
| 策略形态 | 因子值定仓位大小（线性映射） | 因子符号定方向，仓位由波动率定 |
| 评价焦点 | 预测收益幅度 | 预测涨跌方向 |
| 极端日敏感度 | 高（一天 +15% 拉偏 IC） | 免疫（±1 截断） |
| 样本量 | 需要足够连续分布 | 二分类指标对小样本更稳健 |
| 下游合成算子 | IC 加权、Grinold、回归 | 投票合成（VoteCombiner） |

**对本项目的关键含义**：项目定位是 Multi-factor Trend Following，时序模式下最朴素的策略形态就是"因子正做多、因子负做空、仓位由波动率定"——这正好是方向标签对应的策略形态。所以方向标签不是"为了评价体系完整而硬加的选项"，而是**和时序 trend following 主战场策略形态直接对齐的评价口径**。用连续标签 IC 评价一个最终只用方向的策略，会出现"IC 看起来不错但实盘不赚钱"的情况——因为 IC 被少数大幅度日主导，而策略只吃方向。

### 1.4 一个常被忽略的陷阱：阈值三值化的统计后果

§19.2 提到可以加阈值 |r| > ε 把小波动归为 0（中性）。这在策略层合理（小波动不值得交易），但在评价层要小心：三值化后样本被分成三类，传统的二分类指标（AUC、Precision、Recall）需要变形——要么把 0 类剔除后再算二分类指标，要么用 macro/micro 平均的多分类指标。**阈值 ε 的选择本身是一个研究决策**，它会改变样本数和指标数值，必须进入实验配置并做敏感性分析。否则会出现"ε=0.2% 时命中率 55%、ε=1.0% 时命中率 62%"的虚假改进——其实只是把难判的样本剔除了。

### 1.5 小结

方向标签不是"算不了 IC 的弱化版标签"，而是**切换到分类评价维度**——命中率、AUC、Precision/Recall，这些指标直接对应 trend following "方向胜率"的策略语义。因子连续值和二值标签完全可以放在一起算：Pearson 相关数值有效（即 Point-Biserial），AUC 和 Rank IC 在二值标签下数学等价。本项目以时序 trend following 为主战场，方向标签应被视为**主评价口径之一**，不是辅助评价。

## 2. 未来实现波动率标签：为什么因子研究中很少见？

### 2.1 问题重述

§19 列出了"未来实现波动率"作为 V1 标签类型之一，但实践中因子研报和教科书里很少把它当作"标签"来用——它更像是一个风险度量、一个仓位计算输入，而不是一个被因子预测的"正确答案"。这一节解释它的真正用途。

### 2.2 先厘清：它不是"被因子预测的目标"，而是"第二维评价坐标系"

这是理解未来波动率标签的关键。它的角色和前四类标签不同：

| 标签 | 角色 | 评价问的问题 |
|---|---|---|
| 未来收益 | 被预测的目标 | 因子能预测未来收益吗？ |
| 方向 | 被预测的目标（离散化） | 因子能预测涨跌方向吗？ |
| 残差收益 | 被预测的目标（净化版） | 因子能预测剥离 beta 后的 alpha 吗？ |
| 波动率调整收益 | 被预测的目标（标准化版） | 因子能预测风险调整后的超额收益吗？ |
| **未来实现波动率** | **评价坐标系的一个轴** | **因子预测力是否随市场状态变化？** |

未来波动率标签**本身通常不是被因子预测的对象**（虽然你当然也可以研究"因子能否预测未来波动率"，那是另一个研究问题，属于波动率预测因子，不是趋势跟踪因子的主评价路径）。它的核心用途是**作为评价层的条件变量**——把样本按未来实现波动率分组，看因子在不同波动率环境下的预测力是否稳定。

### 2.3 用途一：市场状态条件化评价

因子 IC 不是常数——趋势因子在高波动环境下的预测力和低波动环境下可能完全不同。传统做法是用历史波动率（t 之前）做条件化分组，但**未来实现波动率**提供了一个"后见之明"的视角：

```
对每个时点 t：
  future_vol_h[t] = std(True_Return[t+1 : t+h]) × sqrt(252)   # 未来 h 期年化波动率

按 future_vol_h 的截面或时序分位数把样本分 3 组（低/中/高波动期）
分别算各组内 因子 × 未来收益 的 IC
```

得到一张条件 IC 表：

```
未来波动率分组    IC    Rank IC    样本数
低波动 (下 1/3)  0.018   0.022     4200
中波动           0.045   0.051     4180
高波动 (上 1/3)  0.072   0.068     4150
```

这种分析能回答的问题：**"动量因子在趋势行情（高波动）中表现更好，在震荡行情（低波动）中失效"**——这是趋势跟踪策略的核心假设之一。用历史波动率分组有循环论证嫌疑（因子计算本身可能用了历史波动率），用未来实现波动率分组则提供独立的市场状态标识。

### 2.4 用途二：波动率调整标签的构造依赖它

§19.3 的波动率调整标签 `r_h / σ`，分母用什么 σ？有两种选择：

1. **历史波动率**（t 之前）：`σ_hist[t] = std(r[t-20:t])`，因果安全，但反映的是"过去波动"
2. **未来实现波动率**（t 之后）：`σ_future[t] = std(r[t+1:t+h])`，反映"实际发生的波动"

实务中**几乎一定用历史波动率**（因为策略只能基于过去定仓位），但未来实现波动率作为"理论上限"有诊断价值——如果用未来波动率调整后 IC 显著高于历史波动率调整后 IC，说明你的因子在"波动率预测"维度上还有可挖掘的 alpha（仓位没调到最优）。

### 2.5 用途三：波动率预测因子评价（次要路径）

虽然趋势跟踪主战场不预测波动率，但项目架构允许定义"波动率预测因子"（如 GARCH 残差、波动率比值等）。对这类因子，未来实现波动率就是它直接的预测目标，评价方式完全平行于收益标签：IC、分组、衰减。这是 V2 路径，V1 可以不展开但接口要留。

### 2.6 为什么因子研报里很少见

券商金工研报的默认框架是"截面多空"——构建因子、按截面分 5 组、看多空收益和 IC。这个框架隐含假设是"因子预测收益方向和幅度"，波动率只是一个风险控制参数，不进入主评价。未来波动率作为条件变量分组评价 IC，属于**策略归因**层面的分析，研报通常在"因子在不同市场状态下的表现"一节里出现，但不会作为标签系统的一等公民。

本项目把它列为 V1 标签之一，反映的是**研究框架而非研报框架**——研究框架要求显式管理"评价在什么条件下成立"，而市场状态是期货策略最重要的条件之一。所以它"少见"是因为研报不写，不是因为业界不做。AHL、Winton 这类管理期货基金的内部研究里，波动率条件化分析是标准动作。

### 2.7 实现注意事项

未来实现波动率标签的构造规则：

```
future_vol_h[t] = sqrt( (1/(h-1)) × Σ_{j=1..h} (r[t+j] - mean(r[t+1:t+h]))² × 252 )
```

- 只用 t 之后的收益，**严格向前看**，不混入 t 及之前。
- h-1 是无偏估计的分母（样本标准差）；如果用 h（总体标准差）要显式声明。
- √252 是年化因子，可配置。
- 窗口内任一期收益缺失，按 §19 标签缺失传播政策处理（V1 默认严格传播 → NaN）。
- 它和 `forward_return_h[t]` 共享同一窗口，可以同时构造。

### 2.8 小结

未来实现波动率标签**不是被因子预测的目标**，而是评价层的条件变量——用于"市场状态条件化 IC 分析"，检验因子在高/低波动环境下预测力是否稳定。它在研报里少见是因为研报用截面多空框架、把波动率当风险参数而非评价维度；在管理期货内部研究中是标准动作。本项目把它列为 V1 标签，是"研究框架优先于研报框架"的设计选择。

## 3. 风险暴露调整后残差收益：和组合层约束是什么关系？

### 3.1 问题重述

§19.4 给出了残差标签的例子——`残差 = 真实收益 - β × 板块收益`，逻辑链是"因子能预测跑赢板块 β 预期的部分才是真 alpha"。你的猜测是：这个标签对应组合层的"板块风险中性约束"（同板块权重和为 0）。这个猜测方向对，但需要分清楚两层关系——**研究层标签**和**策略层约束**是两件事，它们之间的对齐不是"同件事的两面"，而是"研究问题驱动策略约束"或"策略约束反向驱动研究标签"。

### 3.2 残差标签的本质：把"非 alpha 收益"从标签里扣掉

残差标签的核心思想是——一个品种的未来收益可以拆成两部分：

```
r_i[t+1] = β_i × r_benchmark[t+1] + ε_i[t+1]
           └────────────┘   └────┘
           系统性部分        品种特异部分（alpha 候选）
```

`r_benchmark` 可以是板块指数、全市场指数、风险因子组合（如动量 common factor、价值 common factor）。残差标签就是 `ε_i[t+1] = r_i[t+1] - β_i × r_benchmark[t+1]`。

用 `r_i` 算 IC 测的是"因子预测总收益的能力"；用 `ε_i` 算 IC 测的是"因子预测品种特异收益的能力"。两者差异告诉你因子的预测力来自哪里——来自系统性暴露（廉价、可通过板块 ETF 复制）还是品种特异（你的核心选品种能力）。

### 3.3 残差标签和组合层约束的三种可能关系

你的猜测"残差标签对应板块风险中性约束"只覆盖了其中一种关系。完整谱系是：

#### 关系 A：策略约束驱动研究标签（"对齐"关系）

**策略层**已经决定做板块中性（同板块权重和为 0），那么策略的 PnL 实际上等于"品种残差收益的加权和"——板块系统性收益被多空对冲掉了。此时**研究层应该用残差标签评价因子**，因为：

- 策略 PnL = Σ_i w_i × ε_i = Σ_i w_i × (r_i - β_i × r_sector)
- 板块中性约束 → Σ_{i ∈ sector} w_i = 0 → 板块收益部分 Σ w_i × β_i × r_sector = 0
- 实际 PnL = Σ_i w_i × ε_i

用 `r_i` 算 IC 评价出来的"好因子"，在板块中性策略下可能不赚钱——因为它预测的全是板块系统性收益，而你的策略把这部分对冲掉了。**用残差标签评价才是"研究评价 = 策略实际 PnL 来源"**，这正是项目架构设计文档 §88"构造严格向前看的未来收益标签"和 §155-165 标签语义讨论的核心原则：**研究评价的口径要和策略交易的口径一致**。

这种关系下你的猜测是对的：**板块中性约束 → 板块残差标签**。

#### 关系 B：研究标签驱动策略设计（"发现"关系）

**研究层**先用残差标签筛因子——发现某个因子在原始收益标签下 IC=0.05、在板块残差标签下 IC=0.04，说明它的预测力主要来自品种特异部分。这个发现**驱动策略层设计**：既然因子预测的是特异收益，那策略就该把板块暴露对冲掉，否则板块暴露带来的 PnL 噪声会掩盖因子信号。

这种关系下方向反过来：**板块残差标签 → 启发板块中性策略**。

#### 关系 C：两者独立（"不对齐"关系）

研究层用残差标签只是想理解因子来源（**诊断**），策略层并不一定要做板块中性——可能因为成本、容量、流动性原因保留板块暴露。这种情况下残差标签是**纯诊断工具**，不直接对应策略约束。

### 3.4 "风险暴露调整"涵盖的范围比"板块"大

§19.4 的例子用板块做基准，但项目架构设计文档 §232-240 和代码写作方案 §565 提到的"风险暴露调整"是更宽的概念：

| 基准类型 | 残差标签构造 | 对应的策略约束 |
|---|---|---|
| 板块/品种组指数 | `r_i - β_i × r_sector` | 板块中性（同板块权重和 = 0） |
| 全市场等权指数 | `r_i - β_i × r_market` | 市场中性（多空总仓位和 = 0） |
| 动量 common factor | `r_i - β_i × r_mom_factor` | 动量暴露中性（避免因子本身就是动量的循环论证） |
| 波动率 common factor | `r_i - β_i × r_vol_factor` | 波动率暴露中性 |
| 多因子组合 | `r_i - Σ_k β_{i,k} × r_factor_k` | 多重中性化 |

最后一种是**正交化残差标签**——把所有已知风险因子的收益贡献都扣掉，剩下的才是"纯 alpha 候选"。这和预处理层的 `ExposureNeutralizer` 是镜像关系：预处理层对**因子值**做暴露中性化（剔除因子里的系统性暴露），残差标签对**收益**做暴露中性化（剔除收益里的系统性部分）。两者可以同时做，逻辑自洽。

### 3.5 β 的估计窗口是一个研究决策

残差标签构造需要 β，β 怎么估？三种主流选择：

1. **滚动窗口 β**（如过去 60 日）：`β_i = Cov(r_i, r_benchmark) / Var(r_benchmark)`，反映近期关系，但估计噪声大
2. **扩张窗口 β**：用 t 之前所有历史，稳定性好但响应慢
3. **截面 β**：每个时点用截面回归估一次（适合多品种面板）

**β 估计窗口必须显式记录在标签配置里**（项目架构设计文档 §232："残差收益必须记录基准、品种组或风险暴露模型的拟合窗口"）。因为 β 估计方法不同，残差标签数值会变，IC 评价结果也会变——这是可复现性的硬约束。

### 3.6 小结

残差标签的本质是"从收益里扣掉系统性暴露，只留品种特异部分作为评价目标"。它和组合层约束的对齐关系有三种——策略约束驱动研究标签（对齐关系，你的猜测属于这种）、研究标签驱动策略设计（发现关系）、两者独立（诊断关系）。板块只是风险暴露的一种，残差标签的基准可以是板块、全市场、任意风险因子组合。"风险暴露调整后残差收益"这个名字比"板块残差"更宽，是正确的命名。

## 4. 波动率调整后收益：和组合层波动率仓位归一化的对齐

### 4.1 问题重述

§19.3 给出了波动率调整标签 `r_h / σ`，并指出"如果你构建的多因子策略会对每个品种的波动率做仓位归一化，那么波动率调整后的标签和你最终的策略目标才是匹配的"。你的理解是：波动率调整标签对应下游组合层的波动率仓位归一化。这个理解基本正确，但有几个细节需要精确化。

### 4.2 对齐的数学基础

时序 trend following 的标准仓位规则：

```
w_i[t] = F_i[t] / σ_i[t] × risk_budget
```

其中 `F_i[t]` 是因子值（或其符号），`σ_i[t]` 是品种 i 在 t 时刻的波动率估计（通常用历史波动率），`risk_budget` 是组合层分配的风险预算。策略 PnL：

```
PnL_i[t+1] = w_i[t] × r_i[t+1] = (F_i[t] / σ_i[t]) × r_i[t+1] × risk_budget
```

如果我们把"标签"定义为"策略实际吃到的收益"，那它就是：

```
label_i[t] = r_i[t+1] / σ_i[t]
```

这正是波动率调整标签（用历史波动率做分母）。所以"波动率调整标签 = 策略 PnL 的标准化版本"——用这个标签算 IC 等于"因子值和策略实际吃到收益的相关性"，用原始收益标签算 IC 等于"因子值和价格变动的相关性"。

### 4.3 为什么对齐重要：避免"研究好的因子在实盘失效"

设想一个场景：

- 研究阶段：用原始收益标签 `r_i[t+1]` 评价，发现因子 IC=0.06
- 策略层：用波动率仓位归一化 `w_i = F_i / σ_i`
- 实盘表现：低于研究预期

为什么？因为研究阶段 IC=0.06 里面，**高波动品种的贡献被放大了**——高波动品种 |r| 大，(F, r) 的协方差自然大。但策略层把高波动品种的仓位 `1/σ` 缩了，实际吃到的收益是 `r/σ`，高波动品种在策略 PnL 里的贡献被压缩。用原始收益评价出来的"高 IC"，可能是被高波动品种主导的虚假信号。

用波动率调整标签评价，等于预先把"策略层的 1/σ 归一化"反映到评价里——**研究 IC 高 = 策略 PnL 高**，口径一致。

### 4.4 分母用历史波动率还是未来波动率

§2.4 已经讨论过——分母**必须用历史波动率**（t 之前），因为：

1. 策略层实际只能用 t 之前信息定仓位，研究评价要对齐策略，分母也得用 t 之前
2. 用未来波动率有未来函数污染

这是和"未来实现波动率标签"（§2）的关键区别——**波动率调整标签里的 σ 是 t 之前的、因果安全的**；未来实现波动率标签里的 σ 是 t 之后的、纯诊断用的。两者不能混。

### 4.5 波动率调整标签 vs 残差标签：两种独立调整

容易混淆的点：

| 标签 | 调整什么 | 调整方式 |
|---|---|---|
| 波动率调整 | 调整收益的**尺度** | 除以波动率（标准化） |
| 残差调整 | 调整收益的**来源** | 减去系统性暴露（净化） |

两者可以叠加——`残差收益 / σ` 就是"剥离系统性暴露后的 alpha，再除以波动率做尺度归一"。这对应的策略形态是"板块中性 + 波动率仓位归一化"，是 trend following 业界主流配置。项目标签系统支持这种组合（V1 通过 `LabelBuilder` 组合多个标签定义），但要注意叠加后的解释复杂度——标签每经过一次调整，和"原始未来收益"的语义距离就更远一层，归因时要逐层回溯。

### 4.6 小结

波动率调整标签 = `r_h / σ_hist`，对齐组合层的波动率仓位归一化策略（`w_i = F_i / σ_i`）。对齐的本质是"研究评价口径 = 策略 PnL 来源"。分母必须用历史波动率（因果安全），不能用未来实现波动率（未来函数）。它和残差标签是两种独立调整（尺度 vs 来源），可叠加。

## 5. 事件标签：是因子改性还是独立标签？

### 5.1 问题重述

§19.5 给出了三个事件标签例子——换月事件、库存报告、极端事件。你的理解是：事件标签本质上是"因子 × I(事件A)"，相当于在事件窗口里激活因子、非事件窗口里把因子置零，某种程度上是一种因子改性。这个理解触及了一个重要的设计分野，但需要拆清楚——**事件标签有两种形态**，一种确实接近因子改性，另一种是完全独立的标签，两者不能混为一谈。

### 5.2 形态一：事件条件化因子评价（接近你说的"因子改性"）

研究问题：**"同一个因子在事件日 vs 非事件日，预测力是否不同？"**

这种情况下标签本身还是普通标签（如未来 5 日收益），事件的作用是**在评价阶段把样本分两组**：

```
全样本 → 分成两组
  ├─ 事件日子集：{t : event[t] = True}
  └─ 非事件日子集：{t : event[t] = False}

分别算两组 IC：
  IC_event = Corr(F[t], r_5d[t]) on {t : event[t] = True}
  IC_nonevent = Corr(F[t], r_5d[t]) on {t : event[t] = False}
```

这等价于在事件日把因子激活、非事件日把因子置零后再算整体 IC——也就是你说的"因子改性"。数学上：

```
F'[t] = F[t] × I(event[t])

IC_modified = Corr(F'[t], r_5d[t]) over all t
            ≈ weighted average of IC_event 和 IC_nonevent (按事件频率加权)
```

但严格说这不叫"因子改性"而叫"事件条件化评价"——因子本身没改（在策略层用的时候还是 `F[t]`），只是评价时分了组。这种形态下事件标签的角色是**评价层的分组键**，不是真的构造一个新标签。

项目里这种形态更多走 §988"分市场状态归因"的路径，而不是事件标签的路径——因为它本质上还是用普通标签做条件化分析。

### 5.3 形态二：事件专属标签（真正的独立标签）

研究问题：**"事件发生后，价格行为有什么模式？"** 或 **"事件窗口的收益结构是否和因子预测一致？"**

这种情况下**标签本身只在事件日有定义**，非事件日是 NaN：

```
label_event[t] = r[t+1 : t+h]   只在 event[t] = True 的时点构造
                  = NaN          其他时点
```

或者更复杂的事件窗口标签：

```
label_roll[t] = r[t+1 : t+3] - r[t-2 : t]   (换月前后收益差)
                只在 is_roll[t] = True 的时点构造
```

这种标签的特点：

1. **稀疏分布**——只在事件日有值，可能只占全样本 5-10%
2. **样本量小**——统计显著性需要小心，bootstrap/Newey-West 调整更关键
3. **不能用全样本 IC**——直接算 Corr(F, label) 会让大量 NaN 标签稀释有效样本，必须显式丢弃 NaN 后再算
4. **标签语义和普通标签不同**——可能是窗口收益差、可能是事件后累积收益曲线、可能是事件后均值回复指标

这种形态下事件标签是**真正的独立标签类型**，不是因子改性。它服务的评价问题是"事件窗口的价格行为本身"，不是"因子在事件窗口的预测力"。

### 5.4 §19.5 三个例子属于哪种形态

| §19.5 例子 | 研究问题 | 形态 |
|---|---|---|
| 换月事件 | 换月前后是否存在异常价格模式 | 形态二（事件专属标签，标签是窗口收益差） |
| 库存报告 | 同一因子在发布日 vs 非发布日预测效果 | 形态一（条件化评价，标签是普通未来收益，事件做分组键） |
| 极端事件 | 极端上涨后是否均值回复 | 形态二（事件专属标签，标签是事件后累计收益） |

§19.5 把三种例子并列放在"事件标签"下是对的，但它们分属两种形态。项目实现时应该让 `EventLabel` 类支持两种使用方式：

- **作为标签构造器**：输出稀疏标签（只有事件日有值），供评价器算事件窗口统计
- **作为评价分组键**：输出布尔事件序列，供评价器对普通标签做条件化分析

这两种用途的代码路径不同，但共享同一个事件定义（事件触发条件、窗口端点）。`EventLabel` 类应同时输出两者，由评价器决定怎么用。

### 5.5 "因子改性"这个说法的合理性边界

把形态一（事件条件化评价）称为"因子改性"是一种直觉化表达，理解方向是对的——效果上确实等价于把因子在非事件日置零。但严格说不准确，原因有三：

1. **改性发生在评价层而非因子层**。因子值 `F[t]` 没变，是评价时通过分组键过滤的。如果真的改成 `F'[t] = F[t] × I(event)`，这个新因子进预处理链会出问题——非事件日 F'=0 会被 winsorizer、z-score 当成真实值处理，污染截面统计。所以**不能在因子层做事件改性，只能在评价层做事件条件化**。
2. **改性是双向的**。"因子 × I(事件)" 只是激活型改性，还有抑制型——"因子在事件日失效，非事件日有效"，此时事件的作用是剔除事件日样本而非激活。这种情况下"因子改性"的直觉就反过来了。
3. **形态二根本不是因子改性**。事件专属标签服务的"价格行为模式"问题，因子可能根本不参与——研究的是"换月后 3 天平均收益是否非零"，和因子值无关。

所以准确的说法是：**事件标签是标签系统的一个一等公民，支持两种使用形态——事件条件化因子评价（效果上接近因子改性，但发生在评价层）和事件专属标签（和因子预测无关，研究事件窗口价格行为本身）**。

### 5.6 配置化事件标签的实现要求

项目架构设计文档 §240、§370 和代码写作方案 §565 都强调"配置化事件标签"——事件不是硬编码的，而是通过配置定义。一个事件标签配置应包含：

```
event_config = {
    trigger: 换月日 | 库存发布日 | |r| > 3σ | 自定义布尔表达式
    window: 前后窗口端点（如 pre=-3, post=+3）
    label_definition: 窗口内收益的构造方式（如 post_5d_return, post-pre 差, pre-post 累计曲线）
    output_mode: sparse_label | group_key | both
}
```

`trigger` 的可复现性要求（§565"事件标签必须给出可复现的阈值和端点"）：

- 换月日：依赖 `Dominant_Contract` 列变化，可复现
- 库存发布日：依赖外部日历数据，必须在实验 manifest 里记录数据版本
- 极端事件：阈值 |r| > 3σ 中的 σ 怎么算（历史 20 日？全样本？）必须显式声明，不同 σ 定义会导致事件集合不同

### 5.7 小结

事件标签有两种形态：**事件条件化因子评价**（你说的"因子改性"，但改性发生在评价层而非因子层，避免污染预处理）和**事件专属标签**（独立的稀疏标签，研究事件窗口价格行为本身）。§19.5 的三个例子分属两种形态。`EventLabel` 类应支持两种输出模式（稀疏标签 / 分组键），共享同一事件定义。配置化要求事件触发条件、窗口端点、标签构造方式、σ 定义等全部可复现记录。

## 6. 五种标签的统一视角

把五个问题放在一起，可以看到标签系统设计的内在结构：

```
                    ┌─ 被预测的目标（评价"因子能否预测"）
                    │   ├─ 未来收益        （预测幅度）
标签角色 ──────────┤   ├─ 方向            （预测涨跌，分类评价维度）
                    │   ├─ 波动率调整收益  （预测风险归一后幅度，对齐策略仓位规则）
                    │   └─ 残差收益        （预测剥离系统性暴露后的 alpha，对齐策略中性约束）
                    │
                    └─ 评价坐标系轴（评价"因子预测力在什么条件下成立"）
                        └─ 未来实现波动率  （市场状态条件化）
                    
                    + 事件标签（横切两种角色，支持条件化评价和事件专属标签两种形态）
```

**核心设计原则**（贯穿五个问题）：

1. **研究评价口径 = 策略 PnL 来源**（§3.3 关系 A、§4.3）：策略层做什么约束/归一化，研究层就该用什么标签评价。这是"研究可信度驱动"的核心原则在标签层的具体落地。
2. **每种标签回答不同问题，不可相互替代**：连续 IC 高 ≠ 方向命中率高 ≠ 残差 IC 高。五种标签不是冗余设计，是五个不同研究问题的并行评价。
3. **可复现性是硬约束**：β 估计窗口、波动率分母选择、事件阈值定义、方向标签阈值 ε——所有影响标签数值的参数都必须进入实验配置，否则 IC 数值不可复现。
4. **标签只供评价器使用，不进入因子输入**（架构设计文档 §240、§372）：防止未来函数污染因子计算。
5. **未来函数红线**：所有标签只用 t 之后数据构造，波动率调整标签的分母是唯一例外（用 t 之前的历史波动率，因为对齐策略层仓位规则）。

## 7. 对 V1 实现的落点建议

基于以上讨论，对 V1 标签系统代码写作的几个落点建议：

1. **`DirectionLabel` 应同时输出 ±1 二值版和 {−1, 0, +1} 三值版**，阈值 ε 进入配置，评价器按 AUC / HitRate / Precision-Recall / Point-Biserial IC 各自计算。不要只输出一个 sign()。
2. **`FutureVolatilityLabel` 的实现可以是轻量的**——V1 主要用于评价层的条件化分组，不需要复杂的 GARCH 估计，样本标准差 + 年化即可。但接口要预留"波动率预测因子"作为被预测目标的用法。
3. **`ResidualReturnLabel` 的基准类型应可配置**——板块指数、全市场指数、风险因子组合，β 估计窗口显式声明。V1 先实现板块残差和全市场残差两种，多因子残差留 V2。
4. **`ForwardReturnLabel` 的波动率调整应作为一个修饰器**而不是独立类——`VolatilityAdjustedLabel(forward_return_label, vol_window=20, annualize=True)`。这样它可以叠加在残差标签上（"残差 / 波动率"对应"板块中性 + 波动率仓位归一"）。
5. **`EventLabel` 应同时输出稀疏标签和事件布尔序列**——评价器按需选用。事件触发条件、窗口端点、阈值定义全部进入配置。
6. **`LabelBuilder` 应支持标签组合**——给定一组标签定义，输出同索引的标签 DataFrame（每列一个标签），并校验所有标签只用 t 之后数据（未来函数审计）。
7. **标签配置必须进入实验 manifest**——所有影响标签数值的参数（horizons、阈值、β 窗口、波动率窗口、事件定义）序列化记录，这是可复现性的硬约束。

## 8. 追问：因子中性化与标签残差化的替代关系

### 8.1 问题

假设策略大导向是板块中性——完全不想要板块暴露，只想要板块内部的 alpha 选品能力。在此前提下：

1. 是否因子需要做板块中性化、标签也需要做板块残差化？
2. 如果因子已做板块中性化、标签未做残差化，是否属于"错误"的研究执行？

### 8.2 结论

**因子侧中性化和标签侧残差化是替代关系，不是互补关系**——任做其一即可去除板块污染，两个都做对 IC 评价而言是冗余。因子已中性化、标签未残差化**不是错误**，对 IC 评价数学上充分。真正错误的是**两者都不做**。

### 8.3 数学证明

设品种 $i$ 属于板块 $s$。因子在板块内做去均值中性化：

$$\tilde{F}_i = F_i - \bar{F}_s$$

其中 $\bar{F}_s$ 是板块 $s$ 内因子均值，对板块内所有品种相同。标签有两种：原始收益 $r_i$ 和板块残差 $\tilde{r}_i = r_i - \bar{r}_s$（$\bar{r}_s$ 是板块 $s$ 内收益均值，同样对板块内所有品种相同）。

计算两种 IC 的协方差部分：

$$\text{IC}(\tilde{F}, r) = \frac{\text{Cov}(\tilde{F}_i, r_i)}{\sigma_{\tilde{F}} \cdot \sigma_r}$$

$$\text{IC}(\tilde{F}, \tilde{r}) = \frac{\text{Cov}(\tilde{F}_i, \tilde{r}_i)}{\sigma_{\tilde{F}} \cdot \sigma_{\tilde{r}}}$$

考察 $\text{Cov}(\tilde{F}_i, \tilde{r}_i)$ 与 $\text{Cov}(\tilde{F}_i, r_i)$ 的关系：

$$\text{Cov}(\tilde{F}_i, \tilde{r}_i) = \text{Cov}(\tilde{F}_i,\; r_i - \bar{r}_s) = \text{Cov}(\tilde{F}_i, r_i) - \text{Cov}(\tilde{F}_i, \bar{r}_s)$$

因为 $\tilde{F}_i$ 在板块内去均值，而 $\bar{r}_s$ 是板块常量，故 $\text{Cov}(\tilde{F}_i, \bar{r}_s) = 0$，因此：

$$\text{Cov}(\tilde{F}_i, \tilde{r}_i) = \text{Cov}(\tilde{F}_i, r_i)$$

**协方差完全相同。** 相关系数的唯一差异在分母：$\sigma_r \neq \sigma_{\tilde{r}}$（残差方差比原始收益小，因为扣掉了板块波动）。但这只是**尺度差异**，不影响"因子有没有预测力"的判断——它只让 IC 数值整体放大一个常数倍。

直觉理解：$\tilde{F}$ 的板块内均值为零，它和任何板块级常量（包括 $\bar{r}_s$）的协方差都是零。用 $r$ 算 IC 时，$r$ 里的板块收益部分 $\bar{r}_s$ 和 $\tilde{F}$ 正交，不贡献协方差；贡献协方差的只有 $r$ 里的板块内残差部分 $(r_i - \bar{r}_s)$。所以 $\text{IC}(\tilde{F}, r)$ 天然只测"板块内因子预测板块内收益"，板块成分自动被屏蔽。

### 8.4 反向：只做标签残差化、不做因子中性化

$$\text{IC}(F, \tilde{r}) = \frac{\text{Cov}(F_i,\; r_i - \bar{r}_s)}{\sigma_F \cdot \sigma_{\tilde{r}}} = \frac{\text{Cov}(F_i, r_i) - \text{Cov}(F_i, \bar{r}_s)}{\sigma_F \cdot \sigma_{\tilde{r}}}$$

把 $F_i = \tilde{F}_i + \bar{F}_s$ 代入 $\text{Cov}(F_i, \bar{r}_s)$：

$$\text{Cov}(F_i, \bar{r}_s) = \text{Cov}(\tilde{F}_i, \bar{r}_s) + \text{Cov}(\bar{F}_s, \bar{r}_s) = 0 + \text{Cov}(\bar{F}_s, \bar{r}_s)$$

同样地，$\bar{F}_s$（因子的板块成分）和 $\tilde{r}_i$（板块内残差）正交，不贡献协方差。**标签侧残差化也单独足以消除板块污染。**

### 8.5 四种组合的完整谱系

|  | 标签未残差化 ($r$) | 标签已残差化 ($\tilde{r}$) |
|---|---|---|
| **因子未中性化** ($F$) | $\text{Cov}(\tilde{F}, r) + \text{Cov}(\bar{F}_s, \bar{r}_s)$ ★ 污染：含板块 β | $\text{Cov}(\tilde{F}, r)$ ✓ 干净 |
| **因子已中性化** ($\tilde{F}$) | $\text{Cov}(\tilde{F}, r)$ ✓ 干净 | $\text{Cov}(\tilde{F}, r)$ ✓ 干净（冗余） |

- **两个都不做**：污染——IC 里混入 $\text{Cov}(\bar{F}_s, \bar{r}_s)$，即"因子板块成分预测板块收益"的截面协方差，这不是 alpha。
- **只做一个**：干净——任一侧的板块去除都能让 IC 只反映板块内预测力。
- **两个都做**：干净且冗余——IC 协方差和"只做一个"完全相同。

### 8.6 与"研究评价 = 策略 PnL"原则的关系

板块中性策略的 PnL（约束 $\sum_{i \in s} w_i = 0$）：

$$\text{PnL} = \sum_i w_i \cdot r_i = \sum_s \sum_{i \in s} w_i \cdot r_i = \sum_s \sum_{i \in s} w_i \cdot (r_i - \bar{r}_s) + \sum_s \bar{r}_s \cdot \underbrace{\sum_{i \in s} w_i}_{=0}$$

$$\text{PnL} = \sum_i w_i \cdot \tilde{r}_i$$

策略 PnL = 残差收益的加权求和——**板块中性约束本身就把 $r$ 变成了 $\tilde{r}$**。所以即使研究阶段用 $r$ 做标签，只要因子是板块中性化的、且仓位遵守板块中性约束，策略实际赚的就是残差收益。研究评价和策略 PnL 的口径天然一致，不需要额外在标签上做残差化。

### 8.7 什么情况下"两个都做"仍有价值

虽然对 IC 是冗余的，以下场景做双侧仍有意义：

**1. 诊断价值**：比较 $\text{IC}(\tilde{F}, r)$ 和 $\text{IC}(\tilde{F}, \tilde{r})$。若两者数值有显著差异，说明因子中性化不彻底（可能 `ExposureNeutralizer` 用的是回归残差而非精确去均值，或板块定义和标签残差化的基准不一致）。两者接近则验证中性化质量。这是诊断工具，不是必要操作。

**2. 分组多空收益评价**：IC 是全样本点对点相关，数学等价成立。但分组多空收益是"top 组均值 − bottom 组均值"，若分组在全面板上做（而非板块内分组），top/bottom 组的板块暴露只是**近似平衡**而非精确平衡。此时用 $r$ 算的多空收益仍含少量板块残余，用 $\tilde{r}$ 更精确。要完全对齐板块中性策略，正确做法是**板块内分组**（每个板块内独立分 5 组取多空），而非面板分组 + 标签残差化。

**3. 鲁棒性**：因子中性化可能因估计窗口、板块定义变动而不完美，标签残差化提供第二层清洗。

### 8.8 回答两个问题

**Q1：板块中性策略目的下，因子是否需要板块中性化、标签是否需要板块残差化？**

至少做一个。两个都做对 IC 是冗余的但有诊断价值。推荐默认做法：**因子做板块中性化（对齐策略约束），标签不做残差化（避免冗余），但跑一次 $\text{IC}(\tilde{F}, \tilde{r})$ 作为中性化质量诊断。**

**Q2：因子已中性化、标签未残差化，是否"错误"？**

不是错误。对 IC 评价，它数学上充分——板块污染已由因子侧去除。唯一需要警惕的是分组多空收益评价里面板分组的近似性，但该问题的正确解法是改成分板块内分组，而不是给标签做残差化。
