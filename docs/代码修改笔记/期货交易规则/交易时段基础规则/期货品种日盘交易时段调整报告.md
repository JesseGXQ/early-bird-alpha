# 期货品种日盘交易时段调整报告

本报告汇总了中国期货市场历史上，曾发生过基础日盘（早盘或午盘）常规交易时段调整的期货品种。未发生过日盘常规交易时段调整的品种（如所有商品期货品种）不在此列。

## 一、说明
1. **定义限制**：本报告所指的“改变日盘交易时段”专指**基础交易时段的变更**（例如整个品种的所有合约常规开盘/收盘时间整体调整）。不包含合约生命周期内的特殊缩短（如“国债期货在最后交易日仅上午交易”、“股指期货最后交易日提前收盘”）等 override 规则。
2. **date_type**：表示调整日期类型，`calendar_date` 表示调整生效或实施的物理日历日期。

## 三、重大调整事件背景分析

### 1. 2016年股指期货交易时段调整 (IF, IH, IC)
- **生效日期**：2016-01-01（自该日起的首个交易日实施）
- **变更细节**：在此次调整前，股指期货早于现货股票市场15分钟开盘（09:15），并晚于现货股票市场15分钟收盘（15:15）。调整后，早盘开盘及下午收盘时间与沪深证券交易所完全同步。
- **调整作用**：为了防范跨市场极端异常波动、抑制过度投机投机行为，并使衍生品市场与标的指数现货市场的交易逻辑高度贴合。

### 2. 2020年国债期货开盘时间推迟 (TS, TF, T)
- **生效日期**：2020-07-20
- **变更细节**：上午的开盘时间从原本的 `09:15` 整体推迟了15分钟，调整至 `09:30`；下午收盘时间保持 `15:15` 不变。
- **调整作用**：主要为了错开中国人民银行公开市场操作（OMO）结果的每日公布时段（央行通常在 09:20 左右公布逆回购或 MLF 等操作结果）。将国债期货开盘移至操作结果公布之后（09:30），能有效防范信息发布前后的市场异常震荡，维护国债期货开盘价的平稳与合理定价。
