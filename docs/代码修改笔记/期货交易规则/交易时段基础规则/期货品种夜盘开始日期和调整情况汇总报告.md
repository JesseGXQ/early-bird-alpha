# 期货品种夜盘开始日期和调整情况汇总报告

本报告汇总了中国各期货交易所所有现有品种的首个夜盘交易日，以及历史上夜盘时段调整的演变情况。

## 一、夜盘交易基础说明
1. `night_session_start_from`：我们调查到的首个夜盘物理日期（即该晚实际进行交易的日历日）。
2. `date_type`：设为 `calendar_date`，表示该日期为物理日历日。如为 `N/A` 则表示该品种无夜盘。
3. 所有的夜盘首日物理日+1问题及特定历史事件（如 2020 年疫情期间 PG 挂牌后夜盘延迟开始）已在表格下方详细注明。

## 四、特殊品种及历史事件详细说明

### 1. 2020年新冠疫情期间夜盘暂停与恢复（以大商所 PG / 液化石油气为例）
- **历史事实**：为防控疫情，国内商品期货夜盘交易自物理日 **2020-02-03** 起暂停，于物理日 **2020-05-06** 晚起恢复。
- **PG 上市情况**：LPG 期货（`PG`）于 **2020-03-30** 正式上市交易，虽然其合约基础规则设有夜盘交易，但上市时正值全国夜盘暂停期间，因此其上市首日及后续一个多月内均无夜盘。
- **首个实际夜盘**：随 2020-05-06 晚全国商品期货统一恢复夜盘，`PG` 也在当晚迎来了上市以来的首个实际夜盘（属于 **2020-05-07** 交易日）。本表记其物理日为 **2020-05-06**，类型为 `calendar_date`。

### 2. 燃料油（FU）新老合约交替
- **老合约 (180cst)**：燃料油期货最早于 2004-08-25 上市，历史上仅有日盘，从未开通过夜盘连续交易。
- **新合约 (保税380cst)**：2018年7月16日，上期所对燃料油期货进行重大规则修改，推出了新版保税380燃料油合约，并于上市当晚（物理日 **2018-07-16**，属于 **2018-07-17** 交易日）正式开启夜盘。本表记该品种夜盘起始日为 **2018-07-16**。

### 3. 已退市/被替代历史品种说明
- 郑商所的 `WT` (普麦旧)、`WS` (强麦旧)、`RO` (菜油旧)、`ER` (早稻旧)、`ME` (甲醇旧)、`TC` (动力煤旧) 均在夜盘推出前被新合约替代或并未开通夜盘交易，故其夜盘状态记为 `0`。
