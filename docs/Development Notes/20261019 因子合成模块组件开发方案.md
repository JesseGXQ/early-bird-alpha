# 因子合成模块演化式开发方案

## 1. 文档定位

本文是因子合成模块的演化式开发方案。它替代同名旧稿；旧稿保存在
`docs\Development Notes\outdated\20261019 因子合成模块组件开发方案（旧）.md`，仅作为曾经考虑过的问题清单，不再作为代码写作依据。

本文采用“研究驱动的基础设施开发”思路：先实现当前研究马上需要、可以独立验证的最小能力；只有在真实使用暴露出重复劳动、信息缺失或部署需求之后，才增加新的领域概念和框架能力。

当前 `factors/combination.py` 中的 `EqualWeightCombiner` 是这一思路的原型：调用方交付已经准备好的因子值，合成器只完成数值合成。现有代码还不是本方案定义的最终接口，但它确定了首版应坚持的边界。

核心原则如下：

1. **研究问题先于框架设计**：第一阶段先让等权、投票、排名和 IC/ICIR 加权能够用于真实研究。
2. **提前分离职责，延迟复杂抽象**：方向、尺度、品种池和标签准备属于上游；合成器只负责把多个预测变量变成一个预测变量。
3. **具体实现先于统一抽象**：先实现四个简单的具体类；只有多个真实实现出现稳定重复后，才考虑公共协议或结果模型。
4. **语义正确先于功能丰富**：最小可行不等于放松索引、缺失、训练样本和未来信息边界。
5. **为下一步保留替换点，不实现遥远需求**：首版保留清楚的 `fit/transform` 边界，但不建设状态版本、增量重放、实验编排和持久化。

## 2. 演化路线摘要

模块按三个阶段演化：

| 阶段 | 要回答的问题 | 交付重点 |
|---|---|---|
| 第一阶段：最小可用算子 | 几个已准备好的因子，能否按明确规则合成为一列复合因子？ | 四个具体算子、严格数值语义、人工面板测试 |
| 第二阶段：可重复研究 | 多次研究中出现了哪些稳定的配方、拟合记录和比较需求？ | 依据真实重复提取轻量研究契约 |
| 第三阶段：完整框架 | 何时需要规模化实验、部署式重放和下游交付？ | 状态生命周期、统一编排、增量接口和持久化 |

本文的绝对重点是第一阶段。第二、三阶段只说明演化方向和启动条件，不预先规定类名、字段和实现细节。

---

# 第一阶段：语义正确的最小可用合成算子

## 3. 第一阶段目标

第一阶段回答一个直接的研究问题：

> 给定至少两个已经完成方向、尺度、暖机和品种池处理的因子值序列，怎样用一种明确、可手工复算的规则生成单列复合因子？

最短研究链路为：

```text
已完成上游处理的多个 pd.Series
              ↓
      一个具体合成算子
              ↓
名为 composite_factor 的 pd.Series
              ↓
研究者按需调用现有评价或诊断组合组件
```

第一阶段提供三类方法、四个具体算子：

- `EqualWeightCombiner`：等权合成；
- `VoteCombiner`：时序方向投票；
- `RankCombiner`：截面排名合成；
- `ICWeightedCombiner`：训练样本内的 IC 或 ICIR 加权。

投票与排名属于同一类稳健合成思路，但它们回答不同问题，因此分别实现：投票用于同一品种多个预测器的方向共识，排名用于同一时点不同品种的相对强弱。首版不使用一个 `mode` 分支类把两者强行合并。

## 4. 第一阶段职责边界

### 4.1 合成器负责

- 校验多个因子 `Series` 的基本结构；
- 按索引对齐成分；
- 执行指定合成算法和缺失政策；
- 对 IC/ICIR 算子，在调用方提供的训练样本内估计成分评分和权重；
- 返回完整对齐索引上的单列复合因子；
- 保证不原地修改输入。

### 4.2 调用方负责

- 计算基础因子；
- 确定因子经济方向，并把输入统一为“值越大，预期目标越高”；
- 完成缩尾、标准化、排名或其他尺度处理；
- 处理暖机期；
- 按动态品种池把不合格行预先掩码为 NaN，或在传入前筛除；
- 为监督拟合切分训练期，并确保标签在训练边界前已经完整成熟；
- 决定使用何种标签、预测期限和评价模式；
- 使用现有评价函数或诊断组合检查复合因子的研究价值。

### 4.3 明确不做

第一阶段不实现：

- 自动计算基础因子、自动确定方向或执行预处理；
- `FactorResult`、`LabelResult`、`ResearchDataset` 或 `Universe` 的直接接入；
- 训练窗口、标签成熟端点或权重生效日期管理；
- 滚动、扩展窗口或在线重新拟合；
- 批量/增量双接口及重放一致性；
- `ConstituentSpec`、`FactorMatrix`、`CompositeSpec` 等领域模型；
- 独立拟合状态、状态指纹、版本和大型结果对象；
- 结构化警告、配方仓库和持久化；
- 自动统计评价、共同样本比较和诊断组合编排；
- `factors.__init__` 的框架级公共导出；
- 相关矩阵最优 IC、回归、正则化、机器学习或状态条件权重。

这些能力不是被否定，而是尚未被第一阶段的研究问题证明需要。

## 5. 公共输入与输出契约

### 5.1 因子输入

所有算子的 `transform` 均接收可变数量的 `pd.Series`：

```python
combiner.transform(factor_a, factor_b, factor_c)
```

每次调用必须满足：

1. 至少有两个因子序列；
2. 每个输入都是 `pd.Series`；
3. `Series.name` 是非空字符串，且各成分名称互异；
4. 值类型为非布尔数值型；
5. 值允许 NaN，但不允许正负无穷；
6. 索引是名称严格为 `timestamp, product` 的两层 `MultiIndex`；
7. 每个索引唯一且单调递增。

合成器使用外连接对齐各输入，输出索引为全部输入索引的排序后并集。输入索引通常应当与研究面板一致；外连接只是让缺失行为显式化，不代表鼓励调用方交付不同研究总体。

任何输入校验或合成都不得原地排序、填充、改名或修改调用方的对象。

### 5.2 标签输入

只有 `ICWeightedCombiner.fit` 接收标签。标签必须是具有同样索引约束的非布尔数值 `Series`，允许 NaN，不允许无穷值。

标签对象本身不携带训练窗口或成熟度信息。调用方必须只传入：

- 已经限定在训练期内的因子值；
- 截至训练边界已经完整成熟的标签；
- 已应用相同动态品种池的样本。

合成器不会根据时间戳猜测标签是否成熟，也不会接收全样本后自行切分。这个限制使首版接口保持简单，同时避免组件假装掌握它实际并不知道的数据可得性。

### 5.3 输出

所有 `transform` 返回：

```python
pd.Series  # name == 'composite_factor'
```

输出只表示复合预测变量，不是品种权重、目标仓位、订单或收益。缺失或无法形成合法结果的行保留为 NaN，不通过 `dropna` 静默删除。

首版不提供结果包装类。研究者可以直接把返回值与现有标签、品种池或诊断组合接口拼接。

## 6. 最小公共接口

构造器只保存算法规则，不保存因子数据。数据在 `transform` 或 `fit` 时传入：

```python
class EqualWeightCombiner:
    def __init__(
        self,
        missing_policy: Literal['strict', 'renormalize'] = 'strict',
    ): ...

    def transform(self, *factor_values: pd.Series) -> pd.Series: ...


class VoteCombiner:
    def __init__(
        self,
        missing_policy: Literal['strict', 'abstain'] = 'strict',
    ): ...

    def transform(self, *factor_values: pd.Series) -> pd.Series: ...


class RankCombiner:
    def transform(self, *factor_values: pd.Series) -> pd.Series: ...


class ICWeightedCombiner:
    def __init__(
        self,
        mode: Literal['cross_sectional', 'time_series'],
        weighting: Literal['ic', 'icir'],
        correlation: Literal['pearson', 'rank'],
        min_observations: int,
        min_valid_groups: int,
        missing_policy: Literal['strict', 'renormalize'] = 'strict',
    ): ...

    def fit(
        self,
        *training_factors: pd.Series,
        label: pd.Series,
    ) -> ICWeightedCombiner: ...

    def transform(self, *factor_values: pd.Series) -> pd.Series: ...

    @property
    def scores_(self) -> pd.Series: ...

    @property
    def weights_(self) -> pd.Series: ...
```

选择这种形态的原因是：固定算子天然只有 `transform`；监督算子需要明确分开训练数据与应用数据。若像当前原型一样在构造器中绑定数据，IC 算子的样本外应用会迫使接口出现额外分支。

四个类保持独立，不建立 `ABC`、`BaseCombiner` 或统一配置对象。若实现中确实出现完全相同的输入校验和对齐代码，可以提取模块内私有函数；私有函数只是消除已发生的重复，不代表建立公共领域抽象。

## 7. 等权合成

### 7.1 数值定义

对方向和尺度已经对齐的第 `k` 个成分值 `z_k`，完整样本上的等权结果为：

$$
s=\frac{1}{K}\sum_{k=1}^{K}z_k.
$$

这里的“等权”只表示数值系数相同。若上游输入尺度不同，数值贡献就不会相等；合成器不自动修正这一问题。

### 7.2 缺失政策

- `strict`：任一成分缺失，该行输出 NaN；
- `renormalize`：只对当前有限成分取等权平均；只有一个成分有效时返回该成分值；全部缺失时返回 NaN。

`renormalize` 会使不同样本实际使用不同的成分集合。首版只执行该规则，不额外记录逐行有效成分；研究者若发现这种配方变化影响结论，再在第二阶段增加诊断信息。

### 7.3 手算基准

两个已对齐成分为 `(2, 4)` 时，结果为 `3`。输入为 `(2, NaN)` 时，`strict` 返回 NaN，`renormalize` 返回 `2`。两个成分均缺失时，两种政策都返回 NaN。

## 8. 投票合成

### 8.1 数值定义

投票只保留方向信息：

$$
v_k=\operatorname{sign}(z_k),\qquad
s=\frac{1}{K}\sum_{k=1}^{K}v_k.
$$

有限正值投 `+1`，有限负值投 `-1`，精确零投 `0`。零是有效的中立票，不是缺失值。输出位于 `[-1, 1]`，正负票完全抵消时输出零。

投票发生在每个 `(timestamp, product)` 行内，不跨品种排名或去中心。因此，同一天所有品种都得到正值是合法结果。

### 8.2 缺失政策

- `strict`：任一成分缺失，该行输出 NaN；
- `abstain`：缺失成分不投票，分母改为有效票数；全部成分缺失时输出 NaN。

首版不增加最低票数、置信阈值或弱信号区间。这些规则只有在真实研究表明精确零附近的噪声需要特殊处理时才扩展。

### 8.3 手算基准

- `(+2, -3)` 的结果为 `0`；
- `(+2, NaN)` 在 `strict` 下为 NaN，在 `abstain` 下为 `+1`；
- `(0, NaN)` 在 `abstain` 下为 `0`；
- `(NaN, NaN)` 在 `abstain` 下仍为 NaN。

## 9. 截面排名合成

### 9.1 适用问题

排名合成回答同一决策时点上“哪些品种相对更强”。它不是时序方向投票，也不应逐品种独立调用。

### 9.2 共同完整截面

对每个时间戳：

1. 只保留所有成分均有限的品种；
2. 共同完整品种少于两个时，该时点全部输出 NaN；
3. 每个成分只在同一个共同完整截面内排名；
4. 不完整行保留在输出中，但值为 NaN。

使用共同完整截面可以避免不同成分依据不同品种集合形成不可比的排名。首版不提供排名时的缺失重归一。

### 9.3 排名映射

对当期 `N` 个共同完整品种，每个成分使用升序平均秩：

$$
q^{(k)}_i
=\frac{2(\operatorname{rank}^{(k)}_i-1)}{N-1}-1,
\qquad
s_i=\frac{1}{K}\sum_k q^{(k)}_i.
$$

最小值映射为 `-1`，最大值映射为 `+1`，重复值使用平均秩。同一成分当期全部并列时，所有品种的平均秩位于中点，映射结果为零。

### 9.4 手算基准

同一时点三个品种 `P1, P2, P3` 的两个成分分别为：

```text
成分 A:  2, 1, 0
成分 B:  0, 2, 1
```

映射后的排名为：

```text
成分 A:  1, 0, -1
成分 B: -1, 1,  0
```

复合结果为 `(0, 0.5, -0.5)`。这个结果仍是因子值；下游若使用排名多空收获规则，可以对复合值再次排名形成品种权重，两次排名属于不同层次。

## 10. IC/ICIR 加权

### 10.1 生命周期

IC/ICIR 加权是第一阶段唯一有拟合步骤的算子：

```python
combiner = ICWeightedCombiner(
    mode='cross_sectional',
    weighting='icir',
    correlation='rank',
    min_observations=5,
    min_valid_groups=20,
    missing_policy='strict',
)

combiner.fit(train_a, train_b, label=train_label)
scores = combiner.scores_
weights = combiner.weights_
composite = combiner.transform(test_a, test_b)
```

`fit` 返回自身，允许链式调用。再次显式调用 `fit` 会替换实例内原有评分和权重；首版不保留历史版本。`transform` 从不接收或读取标签。

拟合前调用 `transform`、`scores_` 或 `weights_`，必须明确报错，不能假定等权或产生未初始化结果。

### 10.2 训练联合样本

`fit` 先按索引对齐全部训练成分与标签，然后只保留以下联合完整行：

- 标签有限；
- 每个成分均有限。

所有成分必须使用同一批训练行，不能让覆盖率较低的成分在另一套更有利的样本上估计质量。

由于品种池和标签成熟度已经由调用方处理，`fit` 不再接收 `universe` 或日期窗口，也不尝试从 NaN 推断缺失原因。

### 10.3 分组与相关系数

`mode` 决定相关系数的研究维度：

- `cross_sectional`：每个 `timestamp` 是一个组，在同日品种之间计算因子与标签的相关；
- `time_series`：每个 `product` 是一个组，在该品种的训练历史上计算因子与标签的相关。

每组联合完整观测数必须不少于 `min_observations`。`correlation` 的定义为：

- `pearson`：直接计算成分值与标签的 Pearson 相关；
- `rank`：先在组内分别使用平均秩，再计算 Pearson 相关，即 Spearman Rank IC。

若某组样本不足、标签零方差、任一成分零方差或任一相关系数非有限，该组对所有成分共同无效。只有每个成分都能计算质量的共同有效组才进入后续汇总。

共同有效组数量少于 `min_valid_groups` 时，整个拟合失败。`min_observations` 必须是至少为 2 的整数；`weighting='ic'` 时 `min_valid_groups` 至少为 1，`weighting='icir'` 时至少为 2。

### 10.4 IC 与 ICIR 评分

设共同有效组上的第 `k` 个成分相关序列为 `IC[k, g]`。

使用 IC 加权时：

$$
Q_k=\operatorname{mean}_g(IC_{k,g}).
$$

使用 ICIR 加权时：

$$
Q_k=\frac{\operatorname{mean}_g(IC_{k,g})}
{\operatorname{sd}_g(IC_{k,g})},
$$

标准差使用样本标准差 `ddof=1`。任一成分的标准差为零或非有限时，ICIR 拟合整体失败；不把除零结果设为无穷，也不只删除失败成分。

在截面模式下，ICIR 描述逐日截面 IC 的时间稳定性。在时序模式下，组是品种，因此首版 ICIR 明确表示“分品种时序 IC 的跨品种均值除以跨品种标准差”，用于描述跨品种一致性。它不表示时间稳定性，也不年化。

若后续研究确实需要时序预测关系随时间的稳定性，应在第二阶段研究时间分块或滚动窗口，而不是在第一阶段暗中加入一个默认块长。

### 10.5 从评分映射到权重

成分方向已经由上游对齐，因此负评分不用于自动翻转历史方向。首版采用简单的非负映射：

$$
\tilde a_k=\max(0,Q_k),
\qquad
a_k=\frac{\tilde a_k}{\sum_j\tilde a_j}.
$$

要求：

- 每个 `Q_k` 都必须有限；
- 允许部分成分评分非正并获得零权重；
- 若所有成分评分均非正，拟合失败；
- 不在失败时隐式退回等权。

拟合成功后：

- `scores_` 返回以训练成分名为索引的评分副本；
- `weights_` 返回以训练成分名为索引、和为 1 的权重副本；
- 调用方修改返回对象不得改变算子内部拟合结果。

不建立 `FittedCombinationState`。评分与权重已足以支持首轮研究和人工审计；训练窗口、标签身份及状态版本由调用研究代码自行记录。

### 10.6 样本外变换

`transform` 要求应用期成分名称集合与训练时完全一致。传入顺序可以不同，算子必须按名称匹配并恢复训练时的稳定顺序；缺少成分、增加成分或名称重复都直接报错。

对每一行：

$$
s=\sum_k a_kz_k.
$$

缺失政策为：

- `strict`：任一声明成分缺失，该行输出 NaN，包括训练后权重为零的成分；
- `renormalize`：只保留当前有限且训练权重为正的成分，并把这些权重重新归一；当前没有任何有效正权重成分时输出 NaN。

`renormalize` 下只剩一个正权重成分是允许的。第一阶段不额外输出逐行实际权重；如果真实研究需要区分“完整复合”和“退化为单因子”的样本，这将成为第二阶段增加诊断结果的明确驱动。

## 11. 错误与 NaN 边界

### 11.1 直接报错

下列情况属于调用契约错误，应直接抛出 `TypeError` 或 `ValueError`：

- 输入不足两个因子；
- 输入不是 `Series`；
- 成分名称为空、非字符串或重复；
- 索引不是 `MultiIndex(timestamp, product)`、不唯一或非升序；
- 数据为布尔型、非数值型或含无穷值；
- 缺失政策、模式、加权口径或相关口径非法；
- `min_observations` 或 `min_valid_groups` 不符合约束；
- 训练标签结构非法；
- 共同有效组不足；
- ICIR 标准差无效；
- 成分评分非有限或全部非正；
- IC 算子拟合前变换；
- 应用期成分名称集合与训练期不一致。

首版不建立自定义异常类。

### 11.2 返回 NaN

下列情况是数据层面的可预期结果，不必建立结构化警告：

- 严格缺失政策下某行有成分缺失；
- 重归一时没有有效成分或有效正权重成分；
- 投票弃权时没有有效票；
- 排名时共同完整截面不足两个品种；
- 排名输入行不属于当期共同完整截面。

全并列排名和投票平票返回数值零，不返回 NaN。

## 13. 第一阶段测试计划

测试只使用小型确定性人工面板，不依赖 `db/`、外部 `RAW_DATA` 或诊断组合。

### 13.1 公共输入契约

- 少于两个成分报错；
- 空名称、重复名称、非数值、布尔值和无穷值报错；
- 错误索引层级名、重复索引和非升序索引报错；
- 不完全相同的合法索引按外连接形成排序并集；
- 调用前后原始 `Series` 的值、索引、名称和顺序不变；
- 输出名称固定为 `composite_factor`。

### 13.2 等权与投票

- 手算完整行的等权结果；
- 验证等权 `strict`、`renormalize`、单个有效成分和全缺失；
- 验证正票、负票、中立票和平票；
- 验证投票 `strict`、`abstain` 和全部弃权；
- 构造同日多个品种均为正票的样本，确认没有误用横截面去中心。

### 13.3 排名

- 使用第 9.4 节三品种例子验证映射和复合结果；
- 验证重复值使用平均秩；
- 验证某一成分全并列时该成分映射为零；
- 验证共同完整截面，而不是各列分别删除缺失后排名；
- 验证共同品种不足两个时返回 NaN；
- 验证不同时间戳相互独立，不能把跨日样本混在同一排名中。

### 13.4 IC/ICIR 拟合

- 构造至少三个品种、多个日期的截面面板，手算 Pearson IC 和 Rank IC；
- 构造至少两个品种、多个日期的时序面板，手算分品种 Pearson IC 和 Rank IC；
- 验证所有成分只使用联合完整行和共同有效组；
- 验证 `min_observations` 与 `min_valid_groups`；
- 验证 IC 使用组均值，ICIR 使用样本标准差；
- 验证负评分截断为零、正评分归一化及权重和为 1；

- 验证重新 `fit` 会明确替换评分和权重。

- 拟合前调用 `transform`、`scores_` 或 `weights_` 报错；
- 应用成分换序不改变结果；
- 缺失、增加或重命名成分时报错；
- 验证固定权重加权和；
- 验证 `strict` 与 `renormalize`，包括只剩一个正权重成分及没有有效正权重成分；
- 修改 `scores_` 或 `weights_` 的返回值不改变内部结果；
- `transform` 的接口不允许传入标签；改变任何未传入的应用期标签都不可能影响结果。

# 第二阶段：从可用算子到可重复研究

## 14. 启动条件

第二阶段不因第一阶段完成而自动启动。只有真实研究反复出现以下问题时才推进：

- 多个实验都要手工记录相同的成分、方向、预处理和拟合信息；
- 研究者难以复核某次结果使用了哪组评分和权重；
- 多个算子已经出现稳定、相同的校验或生命周期；
- 重归一或弃权样本足够多，需要查看逐行有效成分；
- 不同训练窗口的评分和权重需要系统比较；
- 手工调用现有评价组件形成明显重复且容易出错的代码。

## 15. 演化方向

这一阶段的思维模型从“一个算子得到一列值”扩展为“一次合成研究能够被复核”。可能增加轻量配方、拟合快照、有效成分诊断和对现有评价函数的薄封装。

是否需要公共协议、结果对象或与 `FactorResult` 对接，应从第一阶段四个实现的真实重复中归纳。不要直接恢复旧稿中的完整对象清单，也不要同时引入实验编排、诊断组合和持久化。

时间分块 ICIR、固定自定义权重或有限的重新拟合规则，也应分别由具体研究问题驱动，而不是组成一个必须一次交付的 V2 功能包。

# 第三阶段：从研究工具到完整因子合成框架

## 16. 启动条件与方向

当合成方法已经通过多轮研究，且出现规模化实验、部署式重放或下游交付需求时，才进入第三阶段。届时思维模型扩展为“复合因子具有可管理的训练与应用生命周期”。

可能涉及：

- 数据集、动态品种池和标签成熟度的正式接入；
- 冻结拟合状态、版本、生效时点与重新拟合事件；
- 批量与增量变换的一致性；
- 成分、等权基线和复杂合成的统一公平比较；
- 诊断组合、候选交付和研究证据链；
- 配方、权威输入快照及持久化。

这些方向构成未来问题地图，不是已经批准的接口。第三阶段开始前，应根据前两阶段积累的调用代码、失败案例和研究证据重新撰写详细方案；旧稿中的 `FactorMatrix`、`CompositeSpec`、冻结状态和 `CombinationStudyRunner` 等概念可以重新评估，但不得直接视为既定答案。

## 17. 最终原则

因子合成模块的演化顺序应始终是：

```text
明确研究问题
  → 实现最小算子
  → 用真实研究验证
  → 识别重复与不足
  → 局部扩展
  → 稳定重复出现后再抽象
```

第一阶段的价值不在于模拟一个完整框架，而在于尽快获得可靠的研究工具和真实反馈。后续架构应从这些反馈中生长，而不是从对未来的想象中一次性展开。

# 附录 A：岭回归合成算子开发方案

## A.1 附录定位

本附录规划 `RidgeRegressionCombiner`，用于研究若干相关成分在共同给定时对目标标签的条件预测关系。它是第一阶段基础算子稳定后的**独立实验性扩展**，不改变正文的三个阶段，也不纳入第一阶段“四个最小算子”的完成标准。

岭回归不是等权或 IC 加权的替代默认项。它比前述方法估计更多参数、直接依赖标签幅度，并且对输入尺度和正则强度敏感。开发它的前提是研究者已经拥有单因子、等权及 IC/ICIR 基线，并希望回答：

> 当成分之间存在明显相关性时，一组经过收缩的共享线性系数，能否在样本外提供比简单合成更稳定的条件预测增量？

首版只回答这个最小问题，不同时引入超参数搜索、面板固定效应、滚动训练或完整实验编排。

## A.2 最小职责边界

### A.2.1 算子负责

- 接收调用方已经切分好的训练因子和成熟标签；
- 在所有成分与标签共同有效的训练行上拟合一套共享岭回归系数；
- 使用训练期统计量标准化成分，并在应用期冻结复用；
- 保存足以复算预测的系数、截距、特征均值和尺度；
- 对应用数据产生与目标标签同量纲的单列预测值；
- 保证拟合和变换不原地修改输入。

### A.2.2 调用方负责

- 基础因子计算、方向判断、异常值处理和动态品种池掩码；
- 训练期、验证期和测试期的时间切分；
- 确保训练标签在训练截止时已经完整成熟；
- 在查看测试结果前确定 `alpha`；
- 使用相同样本与评价口径比较单因子、等权、IC/ICIR 和岭回归结果；
- 判断共享系数的池化假设是否适合实际研究任务。

`fit` 不接收 `ResearchDataset`、`LabelResult`、时间窗口或品种池对象，也不根据时间戳猜测标签是否成熟。该边界与 `ICWeightedCombiner` 的首版训练责任保持一致。

## A.3 公共接口

计划接口为：

```python
class RidgeRegressionCombiner:
    def __init__(
        self,
        alpha: float,
        min_observations: int = 2,
    ): ...

    def fit(
        self,
        *training_factors: pd.Series,
        label: pd.Series,
    ) -> RidgeRegressionCombiner: ...

    def transform(self, *factor_values: pd.Series) -> pd.Series: ...

    @property
    def coef_(self) -> pd.Series: ...

    @property
    def intercept_(self) -> float: ...

    @property
    def feature_means_(self) -> pd.Series: ...

    @property
    def feature_scales_(self) -> pd.Series: ...

    @property
    def n_observations_(self) -> int: ...

    @property
    def config(self) -> dict[str, Any]: ...
```

调用示例：

```python
ridge = RidgeRegressionCombiner(
    alpha=0.1,
    min_observations=100,
)

ridge.fit(train_momentum, train_carry, label=train_return)
prediction = ridge.transform(test_momentum, test_carry)
```

构造器只保存事前给定的规则；`fit` 保存训练结果；`transform` 只使用已经冻结的训练结果。输出是名称为 `composite_factor` 的 `pd.Series`。

首版不提供 `mode`、`missing_policy`、`positive`、`fit_intercept` 或 `standardize` 参数。共享池化、严格缺失、允许负系数、包含截距和训练期标准化都是该算子的固定语义，而不是首版研究者可以任意组合的超参数。

## A.4 输入与联合训练样本

因子和标签沿用正文第 5 节的公共契约：

- 至少两个名称非空且互异的数值型因子 `Series`；
- 唯一、升序的 `MultiIndex(timestamp, product)`；
- 允许 NaN，不允许布尔值或正负无穷；
- 标签是具有相同索引语义的数值 `Series`。

`fit` 按索引对齐全部训练成分与标签，只保留所有成分和标签均有限的联合完整行。样本总数记为 `n`，必须不少于 `min_observations`；`min_observations` 必须是至少为 2 的整数。

首版把每个有效 `(timestamp, product)` 观察视为一个等权训练样本。对于 ragged 面板，拥有更多有效品种的日期会贡献更多训练行；观察期更长的品种也会贡献更多训练行。算子不暗中按日期或品种重新加权，研究者必须在解释结果时承认这一池化口径。

该模型不区分 `cross_sectional` 和 `time_series` 模式。两类任务的差异由上游因子处理、标签定义和下游评价体现；首版 Ridge 只估计一套跨品种、跨时点共享的线性系数。若研究证据表明需要逐期截面系数、逐品种模型或固定效应，应另行设计，而不是给本类增加含义模糊的 `mode` 分支。

## A.5 训练期标准化

岭回归惩罚直接作用于系数大小，因此特征尺度会改变收缩强度。即使调用方已经做过业务上的尺度对齐，算子仍使用共同训练样本计算每个成分的均值与样本标准差：

$$
\mu_k=\frac{1}{n}\sum_{j=1}^{n}x_{j,k},
\qquad
\sigma_k=\operatorname{sd}(x_{\cdot,k};\,ddof=1),
$$

并形成：

$$
z_{j,k}=\frac{x_{j,k}-\mu_k}{\sigma_k}.
$$

任一特征的样本标准差为零或非有限时，拟合失败；算子不静默删除该成分。标签不做尺度标准化，只减去训练均值：

$$
y_j^c=y_j-\bar y.
$$

标签样本方差为零或非有限时，拟合失败。训练期得到的 `feature_means_` 与 `feature_scales_` 在应用期冻结，不使用应用样本重新估计。

内部标准化服务于 Ridge 惩罚的可比性，不替代上游的业务预处理。异常值、因果缩尾、时序或截面标准化仍应在进入算子前完成。

## A.6 岭回归目标与数值求解

设 `Z` 是共同训练样本标准化后的 `n × K` 成分矩阵，`y^c` 是中心化标签。首版最小化归一化平方误差与 L2 惩罚之和：

$$
\min_{\beta}
\frac{1}{n}\lVert y^c-Z\beta\rVert_2^2
+\alpha\lVert\beta\rVert_2^2,
\qquad \alpha>0.
$$

相应正规方程为：

$$
\left(\frac{Z^\mathsf{T}Z}{n}+\alpha I\right)\beta
=\frac{Z^\mathsf{T}y^c}{n}.
$$

实现使用 `numpy.linalg.solve` 求解线性方程，不显式计算矩阵逆，也不新增 scikit-learn 等依赖。`alpha` 必须是调用方显式给出的有限正数；不允许用 `alpha=0` 把该类退化为普通最小二乘。

损失函数除以 `n`，因此 `alpha` 不会仅因训练行数扩大而机械改变相对惩罚强度。这个定义与某些库使用的“残差平方和加惩罚”口径不同，测试必须依据本文公式，而不能只比较参数名称。

截距不受惩罚。由于 `Z` 已中心化，标准化坐标下的截距为训练标签均值：

$$
\beta_0=\bar y.
$$

应用行 `x` 的输出为：

$$
s(x)=\beta_0+
\sum_{k=1}^{K}\beta_k\frac{x_k-\mu_k}{\sigma_k}.
$$

因此输出与标签具有相同量纲。例如标签是未来收益率时，输出可解释为该模型给出的未来收益预测值，但仍只是因子层预测变量，不是组合权重或账户收益。

## A.7 系数语义

`coef_` 记录标准化成分空间中的有符号斜率，并以训练成分名称为索引。它具有以下明确语义：

- 系数允许为负；
- 系数不截断；
- 系数不要求和为 1；
- 系数不是 IC 权重，也不应命名为 `weights_`；
- 负系数可能表示其他成分给定后的条件贡献，也可能暴露共线性、样本不稳或方向假设失效，需要研究者解释。

若需要在原始输入坐标中复算，等价斜率和截距为：

$$
\gamma_k=\frac{\beta_k}{\sigma_k},
\qquad
\gamma_0=\beta_0-\sum_k\frac{\beta_k\mu_k}{\sigma_k}.
$$

首版不额外暴露 `raw_coef_`。`coef_`、`feature_means_` 和 `feature_scales_` 已足以恢复上述量；减少重复状态也能避免两个坐标系的参数在重拟合后失去同步。

## A.8 拟合状态与属性

一次成功拟合至少保存：

- 稳定的训练成分名称及顺序；
- 标准化空间系数；
- 截距；
- 训练特征均值；
- 训练特征样本标准差；
- 联合完整训练样本数。

属性行为为：

- `coef_`、`feature_means_` 和 `feature_scales_` 返回副本，外部修改不得改变内部模型；
- `intercept_` 返回浮点数；
- `n_observations_` 返回整数；
- `config` 返回 `{'alpha': ..., 'min_observations': ...}` 的新字典；
- 未拟合时访问任何拟合属性均明确报错。

再次调用 `fit` 表示研究者显式要求替换当前模型。`fit` 开始时先使旧状态失效，全部校验和求解成功后再一次性写入新状态；若重拟合失败，实例保持未拟合状态，不能继续使用陈旧参数生成看似有效的预测。

首版不保存标签名称、训练起止日期或历史状态版本。调用实验代码需要自行记录这些研究事实；当这种记录在多次实验中形成稳定重复时，再按正文第二阶段的思路提取拟合快照。

## A.9 样本外变换

`transform` 不接收标签，只读取应用期成分和已经拟合的状态。其步骤为：

1. 使用正文公共规则校验并按外连接对齐应用成分；
2. 要求应用成分名称集合与训练期完全一致；
3. 允许调用方改变参数顺序，但内部按训练名称顺序重排；
4. 使用冻结的训练均值和尺度标准化完整行；
5. 使用冻结系数和截距计算预测；
6. 返回完整对齐索引上的 `composite_factor`。

应用期任一成分缺失时，该行输出 NaN。首版不提供重归一，因为回归系数、截距和标准化参数共同定义了一套联合模型，删除一个成分后简单归一并不能保持原模型语义；也不使用训练均值填补，因为这会额外假设“缺失成分等于训练期平均状态”。

增加、减少或重命名成分均直接报错。应用期成分含无穷值、索引非法或名称重复时，沿用公共输入错误。`transform` 不重新拟合、不更新均值和尺度，也不读取任何应用期标签。

## A.10 错误边界

下列情况直接失败：

- `alpha` 是布尔值、非数值、非有限值或不大于零；
- `min_observations` 不是至少为 2 的整数；
- 因子或标签违反公共输入契约；
- 联合完整训练样本少于 `min_observations`；
- 任一训练特征或标签的样本方差为零或非有限；
- 正规方程求解失败，或得到非有限系数、截距、均值或尺度；
- 拟合前访问拟合属性或调用 `transform`；
- 应用期成分名称集合与训练期不一致。

应用期合法 NaN 不属于接口错误：只要输入结构合法，对应行返回 NaN，并保留在输出索引中。

首版不建立自定义异常、结构化警告或训练诊断结果对象。负系数本身不触发失败或自动警告；它是需要结合样本外结果解释的模型输出。

## A.11 明确排除

首版 Ridge 不实现：

- 自动搜索、网格搜索或交叉验证 `alpha`；
- 使用测试期结果选择 `alpha`；
- 非负系数约束、系数截断或系数和归一；
- 逐日期截面回归、逐品种模型、固定效应或层级模型；
- 日期平衡、品种平衡或调用方自定义样本权重；
- 缺失值填补和部分成分预测；
- 标签标准化、分类目标或概率校准；
- 滚动与扩展窗口重估、状态版本及生效时点；
- Lasso、Elastic Net、主成分回归或非线性模型；
- 自动评价、基线比较、诊断组合和持久化。

这些排除项不组成预定的下一版清单。只有共享系数 Ridge 在样本外展现稳定价值，并且具体限制阻碍了新的研究问题时，才单独规划相应扩展。

## A.12 实现顺序

未来开发该算子时，保持改动集中在 `factors/combination.py` 和 `tests/factors/test_combination.py`：

1. 在构造器中校验并保存 `alpha` 与 `min_observations`；
2. 复用已经稳定的公共输入校验与对齐函数，不借机重构其他算子；
3. 实现联合完整训练样本与训练期均值、尺度计算；
4. 按本文归一化目标使用 `numpy.linalg.solve` 求解；
5. 实现拟合属性的防御性复制和失败重拟合失效语义；
6. 实现严格缺失的样本外 `transform`；
7. 补齐人工黄金路径和失败边界测试。

实现过程中不修改 `factors.__init__`，暂时继续从 `factors.combination` 显式导入。也不同时为现有 IC 算子补建统一状态对象；是否抽象共同的可拟合算子协议，应等待两个实现稳定使用后再判断。

## A.13 测试计划

### A.13.1 解析结果与缩放

- 构造两个成分的小型完整面板，按本文公式手工计算均值、样本标准差、系数、截距和预测；
- 验证实现使用归一化损失，而不是其他库默认的未归一化 `alpha` 口径；
- 验证标签只中心化、不标准化，输出保持标签量纲；
- 验证原始坐标公式与标准化坐标预测完全一致；
- 验证截距不受惩罚。

### A.13.2 收缩与相关成分

- 在同一训练样本上提高 `alpha`，验证系数 L2 范数不增；
- 构造高度相关或完全重复的成分，验证 `alpha>0` 时仍能得到有限解；
- 构造条件贡献为负的成分，验证负系数被保留而非截断；
- 验证系数不被错误归一化为和为 1。

### A.13.3 样本、名称与缺失

- 验证所有成分与标签只使用联合完整训练行；
- 使用 ragged 人工面板验证每个有效行等权，没有日期或品种平衡；
- 应用成分换序不改变预测；
- 缺少、增加、重复或重命名成分时报错；
- 应用期任一成分缺失时该行输出 NaN，其他完整行不受影响；
- 输出保留对齐后的完整索引且名称为 `composite_factor`；
- `fit` 和 `transform` 前后所有输入对象保持不变。

### A.13.4 状态与失败

- 拟合前访问属性或调用 `transform` 报错；
- 属性返回值被外部修改后，内部预测保持不变；
- 成功重拟合完整替换系数、截距、尺度和样本数；
- 失败重拟合后旧模型不可继续使用；
- 非法 `alpha`、非法最小样本数、样本不足、特征零方差和标签零方差均明确失败；
- `transform` 不接收标签，修改任何未传入的应用期标签都不影响预测。

## A.14 研究验收标准

代码测试通过只表示算子正确实现了指定数学模型，不表示岭回归值得采用。一次研究至少应在相同成分、训练/测试切分、标签、品种池和下游评价口径下，同时报告：

- 各单因子；
- 等权基线；
- IC/ICIR 加权基线；
- 岭回归合成。

重点比较样本外预测关系、覆盖、系数符号与稳定性，以及固定诊断组合下的经济增量。训练期 R² 或训练误差下降不得作为采用岭回归的依据；`alpha` 若经过选择，只能使用预先约定的训练/验证流程，最终测试期不得参与选择。

若岭回归只在个别窗口胜出、系数随训练区间剧烈变化、优势来自少数品种或无法稳定超过等权基线，合理结论是保留简单算子，而不是继续增加模型复杂度。
