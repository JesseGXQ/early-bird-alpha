# 数据库说明

本文档初稿写于2026年7月19日。本日数据引擎已通过全部测试。现在我将写下本项目的期货数据库的相关说明，包括各子数据库来源，变量编排和入库的*简要*说明。

## 行情数据

## 1min 数据
来源为淘宝。后续可以考虑从新增的TICK数据中拉取。可以更好地保证数据一致性。

## TICK数据
来源为淘宝。后续仍可以考虑从淘宝继续购买。bigquant有但很贵，tushare估计也不便宜。还有一种方法是从openctp获取，但是需要每天挂机请求。

## 日频快照
来源为tushare的`期货日线行情`。
关于从tscode到本地代码的mapping，见`db\rules_ingestion\data\derived\20260624\instrument_code_source_local_mapping.parquet`。

##  master tables
由脚本`scripts\build_product_master_table.py`制作而来。

## 交易所交易日历
数据来源为tushare `交易日历`。但修正了其中的一些错误，例如CFFEX。

## 期货交易规则数据库
数据来源，数据库组织/设计方案，以及编排入库流程，见`db\rules_ingestion\variable_ingestion_plan.md`。
