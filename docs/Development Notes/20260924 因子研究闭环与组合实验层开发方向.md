# 因子研究闭环与组合实验层开发方向

## 1. 文档定位

本文记录因子研究模块下一阶段开发方向的讨论结论。

当前系统已经具备若干基础因子、预处理能力和因子诊断统计量。原开发规划还包括因子合成、衰减、换手、归因、稳健性、冗余、统一实验编排和报告等能力。本次讨论认为，后续开发不宜继续只按功能清单线性推进，而应首先建立一条以经济结果为导向的单因子研究闭环，再让其他能力围绕该闭环迭代生长。

本文主要确定概念边界、架构方向和建议的开发顺序，不确定具体 dataclass 字段、公共 API 和文件拆分方案。正式编码前仍需编写对应的详细设计和迁移方案。

## 2. 问题的重新定义

本次讨论关注的并不是“下一项统计量应该开发什么”，而是如何重新定义因子研究模块后续开发的牵引方式。

过去的开发路线接近于按能力列表依次补齐：

```text
因子合成
→ 衰减
→ 换手
→ 归因
→ 稳健性
→ 冗余
→ 实验编排
→ 策略衔接
```

新的目标是先建立一条足够轻量、但能够回答经济问题的纵向闭环：

```text
单因子
→ 因果预处理
→ 信号映射
→ 连续研究权重
→ 组合代理收益
→ 诊断净值
→ 年化收益、Sharpe 和回撤
```

然后让换手、成本、归因、稳健性、冗余和多因子合成围绕这条可运行链路逐步扩展。

该闭环的目的不是提前建设完整策略回测，而是补上“统计预测关系”与“完整可交易策略”之间缺失的经济验证环节。

## 3. 核心结论

因子研究模块需要明确区分三层研究证据：

| 层次 | 回答的问题 | 主要输出 |
|---|---|---|
| 因子统计诊断 | 信号是否包含预测信息，信息以什么形式存在 | 覆盖率、IC、回归、命中率、分组、衰减 |
| 诊断组合实验 | 信息能否被指定的固定仓位规则收获 | 连续权重、signal PnL、代理净值、换手、暴露、风险、贡献、Sharpe |
| 完整策略回测 | 收益能否在真实交易制度下实现 | 合约张数、订单、成交、账户权益、保证金和真实成本 |

证据链应表达为：

```text
统计相关
→ 可收获预测
→ 诊断组合
→ 完整回测
```

因此，“组合实验层”不是因子模块全部开发完成后的附属功能，而应成为下一阶段组织其他开发工作的集成骨架。

## 4. 组合实验层与完整回测的边界

### 4.1 组合实验层负责

- 使用动态有效品种池和联合有效样本。
- 接收原始或明确记录预处理配方的因子信号。
- 按固定、透明、因果的规则将信号映射为连续研究权重。
- 执行研究层的风险缩放、风险预算、gross 归一化、简单仓位上限和目标波动率控制。
- 使用连续合约研究收益计算毛收益和累计诊断净值。
- 计算研究权重换手和透明的线性成本代理。
- 输出代理净收益、暴露、风险、杠杆和收益贡献。
- 计算年化收益、年化波动率、Sharpe、最大回撤等研究绩效指标。
- 保存权重生成配方、配置、数据指纹、警告和中间结果，保证实验可复现。

### 4.2 组合实验层不负责

- 连续合约信号到真实交易合约的精确映射。
- 主力合约切换和真实移仓路径。
- 合约乘数、最小变动价位和张数取整。
- 订单生成、订单生命周期和成交撮合。
- 涨跌停、停牌、无成交和盘口流动性限制。
- 真实手续费、滑点和非线性冲击。
- 保证金、现金、资金占用、账户状态和强平。
- 输出最终 `TargetPosition` 或账户权益曲线。

组合实验层中的“仓位”必须理解为连续研究权重，而不是合约数量；其中的“净值”必须理解为诊断组合净值，而不是实盘净值或真实策略账户权益。

推荐使用下列命名：

- `research_weight` 或 `diagnostic_weight`
- `gross_return`
- `signal_pnl`
- `proxy_net_return`
- `diagnostic_nav`

不得将其直接命名为真实策略净收益、实盘净值或账户权益。

## 5. 为什么组合实验层不可缺少

因子统计量与组合收益之间存在一个不能自动跨越的断点：

```text
因子具有预测关系
    ?
因子可以产生组合收益
```

IC、回归系数、命中率和分组收益无法完整回答第二个问题，因为下游能否收获预测信息还取决于：

- 使用方向映射、线性映射、deadband、clip 还是饱和映射；
- 是否进行逆波动率缩放；
- 使用等品种、等板块还是风险贡献预算；
- 是否要求市场或板块中性；
- 是否限制单品种权重和总 gross exposure；
- 是否进行目标波动率缩放；
- 权重调整产生多少换手和成本；
- 收益是否集中于少数品种、板块或共同方向暴露。

因此，“因子是否有信息”和“该信息能否在指定持仓规则下成为收益”是两个不同但连续的研究问题。

组合实验层的价值还在于帮助定位失败来源：

- 统计诊断失败，问题主要在因子定义、标签或数据。
- 统计诊断有效但诊断组合失败，问题主要在信号映射、风险配置、换手或成本。
- 诊断组合有效但完整回测失败，问题主要在真实合约映射、执行约束和交易摩擦。

这种分层能够避免研究者在完整回测器中不断调整执行细节，并无意中用执行复杂度创造或过拟合信号。

## 6. 建议的组件关系

建议在概念上形成以下关系：

```text
FactorEvaluator
    └─ 预测关系与信号性质诊断

DiagnosticPortfolioExperiment
    └─ 信号 → 连续研究权重 → 代理收益

ResearchExperimentRunner
    └─ 编排数据、因子、标签、统计诊断和诊断组合实验

FullBacktestHandoff
    └─ 向 strategy / portfolio / backtester 交付候选因子及研究证据
```

`FactorEvaluator` 与 `DiagnosticPortfolioExperiment` 应是两个职责独立的兄弟组件，由 `ResearchExperimentRunner` 统一编排。诊断组合不应被隐藏在某个普通评价统计量内部，也不应依赖订单、账户和回测引擎。

初期可将该组件放在 `factors` 研究域内，例如：

```text
factors/
    evaluation/...
    diagnostic_portfolio.py
    experiment.py
```

具体是否进一步拆分为子包，应由第一条真实闭环暴露出的复杂度决定，不提前建设空壳。为避免与仓库顶层负责真实仓位和订单的 `portfolio/` 混淆，不建议使用含义不明确的 `factors/portfolio/` 名称。

当前 `BacktestEngine` 是单品种 Bar 级最小闭环，`TargetPosition` 表示整数合约目标数量。它不适合作为多品种向量化 signal PnL 的直接执行器。诊断组合层应保持向量化、透明和无账户状态；未来完整回测再负责真实执行语义。

## 7. HarvestProfile 与可执行实验配置

现有 `HarvestProfile` 已经能够表达策略家族、信号映射、风险缩放、中性约束、风险分配、组合目标、仓位限制和成本代理等组合收获语义，并定义了六种主流收获范式。

但 `HarvestProfile` 目前描述的是“采用哪类收获范式”，并不足以直接执行一次组合实验。例如：

- `clip` 没有具体截断值；
- `inverse_volatility` 没有波动率窗口和最少样本；
- `target_volatility` 没有目标值；
- `position_limit` 没有数值上限；
- `linear_turnover` 没有成本率；
- 协方差感知配置没有估计器和估计窗口；
- 尚未表达调仓频率、缺失信号政策和品种池退出政策。

建议保留两层配置：

1. `HarvestProfile`：描述组合收获范式和研究语义。
2. `DiagnosticPortfolioSpec`：引用某个 `HarvestProfile`，并绑定一次可执行实验所需的数值参数和时间约定。

后者至少需要考虑：

```text
harvest_profile
rebalance_frequency
signal_mapping_parameters
volatility_window
covariance_estimator
covariance_window
target_volatility
max_product_weight
max_gross
cost_rate
annualization_factor
missing_signal_policy
universe_exit_policy
```

不建议将所有数值参数继续堆入 `HarvestProfile`，否则“研究范式”和“一次具体实验”会再次混为一体。

## 8. 诊断组合的输入与输出契约

### 8.1 建议输入

- `ResearchDataset`：主面板、动态品种池和所需辅助数据。
- 明确阶段的因子值：原始因子、预处理后因子或复合因子必须显式区分。
- `HarvestProfile`：组合收获语义。
- `DiagnosticPortfolioSpec`：可执行数值参数和时间约定。
- 必要的事前波动率、协方差、分类和风险暴露数据。

诊断组合不应直接把多期 `LabelResult` 当作逐期策略收益。用于形成净值的收益序列应具有独立、明确的时间语义。

### 8.2 建议输出

诊断组合结果至少应保存：

| 输出 | 含义 |
|---|---|
| target_weights | 每个时点、每个品种的连续研究权重 |
| gross_return | 研究权重乘下一期研究收益得到的组合毛收益 |
| cost | 与换手口径匹配的透明成本代理 |
| proxy_net_return | 扣除代理成本后的收益 |
| gross_nav / proxy_net_nav | 毛收益与代理净收益累计净值 |
| turnover | 研究目标权重变化 |
| gross/net exposure | 总名义敞口与方向敞口 |
| risk_estimate | 事前组合风险估计 |
| leverage | 目标波动率缩放后的杠杆 |
| contribution | 品种、板块和多空方向收益贡献 |
| constraint_status | 约束是否绑定或违反 |
| performance_summary | 年化收益、波动率、Sharpe、回撤等 |
| metadata/warnings | 时间约定、配置、指纹、异常和降级信息 |

只输出一条净值曲线而不保留权重、贡献和约束状态的实现是不完整的，因为它无法解释收益来自哪里，也无法验证组合规则是否被正确执行。

## 9. 推荐的迭代开发路径

### 9.1 第一轮：最小单因子闭环

先实现一条明确且容易手工复算的时序因子路径：

```text
单个时序因子
→ 已有因果预处理结果
→ sign、continuous 或 clip 映射之一
→ 逆波动率缩放
→ 等品种风险预算
→ gross 归一化
→ 下一期 True_Return
→ 毛收益与诊断净值
→ 年化收益、波动率、Sharpe、最大回撤
```

第一轮可以暂不实现完整协方差矩阵和目标波动率，优先证明：

- 因子可以稳定地产生连续研究权重；
- 权重和下一期收益严格对齐；
- 毛收益、净值和绩效统计量可手工复算；
- 修改未来数据不会改变历史权重和收益；
- 动态品种池退出会形成归零权重，并进入换手计算；
- 缺失信号和暖机期按显式政策处理。

### 9.2 第二轮：形成完整 signal PnL

在最小闭环上增加：

- 目标波动率；
- 协方差或其他事前组合风险估计；
- 单品种与 gross 上限；
- 权重换手；
- 线性成本代理；
- proxy net return；
- break-even cost；
- 品种、板块和多空方向贡献；
- 风险贡献、相关性集中和杠杆使用。

完成这一轮后，现有 `ts_inv_vol_target_vol` 等组合收获范式才真正具备可执行含义。

### 9.3 第三轮：稳健性、实验身份与报告

把诊断组合接入：

- 样本内、验证集和样本外划分；
- walk-forward；
- 参数邻域而非孤立最优点；
- 分时期、分品种、分板块和分市场状态检验；
- leave-one-product-out 和 leave-one-sector-out；
- 成本与流动性压力情景；
- 实验 ID、配置哈希、数据指纹、持久化和缓存；
- 统一结构化表格和 tear sheet。

报告应同时展示预测证据和组合收获证据，避免形成两套互不关联的研究结果。

### 9.4 第四轮：因子合成与冗余分析

因子合成与组合构建必须保持概念独立：

```text
多个因子 → 一个复合预测变量
```

不同于：

```text
一个预测变量 → 多品种研究权重 → 组合收益
```

单因子闭环成熟后，`CompositeFactor` 应像普通单因子一样进入相同的诊断组合实验，从而公平比较：

- 最优单因子与复合因子；
- 合成前后研究权重和换手；
- 合成前后成本后 Sharpe；
- 新因子是否提供边际预测能力和增量组合收益；
- 改善是否仅来自风险尺度变化；
- 合成权重是否稳定且仅在训练窗口拟合。

### 9.5 第五轮：完整策略回测交付

只有在冻结的诊断组合已经显示出经济价值后，才进入：

```text
CandidateFactor
→ strategy factor adapter
→ 真实目标仓位
→ 合约映射和移仓
→ 订单与成交
→ 保证金和账户
→ 真实策略净值
```

完整回测的主要任务应是测量实现折损，而不是依靠执行复杂度创造信号。

## 10. 与待开发模块的关系

组合实验层建立后，原待开发模块应重新明确其落点。

### 10.1 衰减

衰减仍属于预测关系诊断，回答因子的有效期限和相邻期限结构。它用于指导组合实验选择合理的信号更新和持仓假设，但不能直接替代实际持仓实验。

### 10.2 换手

必须区分至少两类换手：

- 因子或分组换手：描述因子排序、方向或分组成员的稳定性。
- 研究权重换手：描述信号映射、风险缩放、组合约束共同作用后的目标权重变化。

两者不能共用含义模糊的 `turnover` 定义而不记录口径。成本代理必须使用研究权重换手。

### 10.3 归因

必须区分：

- 预测能力归因：IC、回归和命中率在品种、时期和状态中的差异。
- 组合 PnL 归因：实际研究权重形成的品种、板块、方向和风险贡献。

预测能力稳定不必然意味着组合贡献分散；组合收益也可能主要来自少数市场或共同多头暴露。

### 10.4 稳健性

稳健性不应只作用于 IC，也应覆盖 signal PnL、成本后收益、参数邻域、收益广度和风险集中。

### 10.5 冗余

冗余分析不仅要判断因子值或预测信息是否相关，还应判断新因子在固定收获范式下能否改善组合结果。统计增量与组合增量应分别报告。

### 10.6 因子合成

因子合成应在单因子闭环可运行后开发。所有复合因子都应复用与单因子相同的诊断组合路径，避免为复合因子另建一套无法比较的收益逻辑。

## 11. 必须提前冻结的时间与收益语义

### 11.1 权重生效时点

若因子在时点 (t) 收盘后才完整可见，则其研究权重只能赚取下一期收益：

$$
R_{t+1}^{gross}
=
\sum_i w_{i,t}r_{i,t+1}.
$$

在当前数据契约下，时点 (t) 形成的权重应与 `True_Return[t+1]` 对齐。若完整策略假设次日开盘成交，则必须在第三层使用与次日开盘以后持有区间一致的真实合约收益重新计算。

### 11.2 多期标签不能直接形成逐日净值

用于预测诊断的重叠 (h) 期标签不能逐日连乘。否则同一底层收益会被重复计算约 (h) 次。

signal PnL 应使用真实更新频率下的一期、非重叠收益。若要表达多日持有，应显式实现：

- 再平衡日程；或
- 多个错峰建立的重叠子组合；或
- 每日根据持仓规则生成新的总目标权重。

### 11.3 预测期限不等于持有期

一个预测未来 20 日收益的因子，不代表每天都可以把未来 20 日标签作为当天的组合收益。预测期限、信号更新频率、调仓频率和持有期必须分别定义。

### 11.4 连续研究收益不等于真实交易收益

`True_Return` 可以作为诊断组合中的连续合约研究收益，但它不能表示次日开盘成交、张数取整、真实移仓价差、涨跌停限制和滑点后的账户收益。

### 11.5 动态品种池退出必须进入换手

当品种退出有效品种池时，其研究目标权重应按明确政策归零。该变化应计入权重换手和成本代理，不能通过删除该行静默消失。

## 12. 测试重点

第一条闭环应优先使用极小人工面板进行黄金路径测试，而不是直接依赖大规模真实行情。

至少应覆盖：

- 两至三个品种、若干时点的研究权重手工复算。
- `w_t` 与 `True_Return[t+1]` 的严格对齐。
- 未来数据修改不改变历史信号、风险估计和权重。
- 波动率和协方差估计只使用当时可见数据。
- gross 归一化和单品种上限的执行顺序。
- 品种进入、退出以及因子缺失时的权重处理。
- 方向翻转产生正确的单边权重换手。
- 成本率与换手口径一致。
- 品种贡献之和等于组合毛收益。
- 毛收益和代理净收益的净值可手工复算。
- 年化收益、波动率、Sharpe 和最大回撤公式与频率一致。
- 重叠多期标签不会被误用于逐日净值。

## 13. 研究流程与接受原则

新的迭代节奏不是用净值曲线取代统计诊断，而是让不同层次的证据相互解释：

```text
研究假设
→ 数据与时间审计
→ 预测关系诊断
→ 诊断组合实验
→ 稳健性与选择偏差检查
→ 完整策略回测
```

单一 IC、单一 Sharpe、单一最优参数点或漂亮净值都不足以单独接受一个因子。

从统计诊断进入组合实验，至少应满足：

- 数据和时间对齐因果正确；
- 覆盖率足以代表目标机会集；
- 至少一种与预定信号映射匹配的诊断表现出稳定方向；
- 结果不完全由单个品种或单个时期驱动；
- 相邻预测期限具有可解释的衰减结构。

从诊断组合进入完整回测，至少应满足：

- 固定映射下的毛收益和代理净收益均可解释；
- break-even cost 对现实交易摩擦有合理余量；
- 收益在品种、板块和方向上具有足够广度；
- gross、net、杠杆和风险贡献没有隐藏集中；
- 参数邻域、样本外和 walk-forward 结果不依赖孤立最优点；
- 所有试验和选择规则均被记录。

## 14. 建议调整后的开发顺序

建议将原来按功能清单推进的顺序调整为：

```text
现有单因子统计诊断
→ 最小诊断组合闭环
→ 研究权重换手、成本和 PnL 归因
→ 稳健性、实验身份和报告
→ 单因子筛选与候选交付
→ 冗余和增量价值分析
→ 多因子合成
→ 完整策略回测
```

其中，衰减等与当前单因子研究直接相关的诊断可以与最小闭环并行补充，但不应因为追求一次性补齐所有评价指标而推迟闭环的形成。

## 15. 最终原则

本次讨论形成的最终原则是：

> 从现在开始，因子研究模块应以“预测关系能否通过明确、透明、因果的连续权重规则转化为经济收益”为开发主线。

组合实验层应成为统计诊断与完整回测之间的正式连接层。它允许因子模块计算研究权重、代理收益和诊断净值，但必须严格排除真实合约执行、订单、成交、保证金和账户状态。

换言之，架构上需要避免的不是“因子研究中出现仓位和净值”，而是把研究权重冒充真实仓位、把代理净值冒充可交易账户收益。

只要这一边界被领域对象、命名、时间契约、结果元数据和测试共同保护，以单因子组合闭环牵引后续迭代既符合研究需求，也与系统分层架构一致。
