# 因子合成模块组件开发方案

## 1. 文档定位与决策摘要

本文是日频因子合成组件首版的详细设计与代码写作依据，承接[《因子研究模块系统架构设计》](<./20260723 因子研究模块系统架构设计.md>)、[《因子研究闭环与组合实验层开发方向》](<./20260924 因子研究闭环与组合实验层开发方向.md>)、[《组合实验层组件开发方案》](<./20260924 组合实验层组件开发方案.md>)和[《CTA 因子合成框架与方法论》](<../others/20261019 CTA因子合成框架与方法论.md>)。

核心决策：

1. 合成输入是**已经计算并完成单因子预处理的多列矩阵**，不是基础 `Factor` 对象。`CompositeFactor` 持有成分说明、合成规则和冻结拟合状态，不执行原始数据加载、基础因子计算或预处理。
2. 首版提供等权、时序投票、截面排名、IC 与 ICIR 加权。相关矩阵最优 IC 和回归合成列入后续扩展，不建立空类。
3. 一个复合因子输出一列预测变量，之后使用现有统计函数与诊断组合实验对照成分因子和等权基线。合成系数是**因子维度**权重；诊断组合权重是**品种维度**权重。
4. 首版提供批量合成和接收完整当期截面的增量变换；可拟合算子只在训练期读取完整成熟的标签，之后使用冻结参数。
5. 结果与配方先保存在内存；本轮不建立合成实验持久化仓库，不承诺已有诊断组合存储能完整复跑合成过程。

本文描述**拟开发能力**。以下现状是写作时对仓库的核查，不应将旧方案中的计划文件误认为现有代码：

| 已存在 | 当前局限 |
|---|---|
| `ResearchDataset.main_panel`、`universe.eligible`、`LabelSpec/LabelResult` | 尚无统一多成分矩阵和复合结果对象 |
| 基础 `Factor.compute/update` 与 `factors/preprocess/` 的单因子批量处理 | 预处理没有统一增量接口；合成组件不得假定它能逐 Bar 重放预处理 |
| `coverage_stats`、`ic_details`、`grouped_details`、回归和命中率等函数 | 尚无统一的 `FactorEvaluator` 或完整 `ResearchExperimentRunner` |
| `DiagnosticSignal`、三种可执行的 `HarvestProfile`、`DiagnosticPortfolioExperimentRunner` | `source_stage` 当前只有 `raw/preprocessed`，缺少复合来源；当前组合运行器一次消费一列信号 |
| `CandidateFactor` 数据对象与诊断组合存储 | 尚无复合因子的候选交付和独立持久化契约 |

## 2. 开发目标与能力边界

首版回答一个可复核的问题：

> 在相同动态品种池、标签、时间划分和收获范式下，把若干已处理单因子合成一列信号，是否比事前固定的简单基线和单因子带来稳定的预测与诊断组合增量？

固定链路：

~~~text
ResearchDataset + 已处理成分矩阵 + 成分配方 + LabelResult
      ↓ 输入与历史可得性校验
方向对齐、训练窗口/成熟标签筛选、合成规则拟合
      ↓ 冻结合成状态
批量 transform / 逐时点 update
      ↓ 单列 CompositeFactorResult.values
统计对照 + DiagnosticSignal(source_stage='composite')
      ↓ 现有 DiagnosticPortfolioExperimentRunner
合成实验结果：完整样本与共同样本比较、警告、配方
~~~

### 2.1 首版支持

- 日频、唯一升序 `MultiIndex[timestamp, product]` 的 ragged 多品种长表。
- 两个及以上基础成分；成分可以来自不同 `Factor`，但在进入合成组件前均已完成各自预处理。
- 两种评价/应用模式：时序 CTA 与截面多空。模式影响算子合法性、IC 拟合口径和评价口径，不改变研究面板的索引格式。
- 等权、时序方向投票、截面平均秩合成、训练期 IC/ICIR 加权。
- 显式成分方向、默认严格缺失；算术加权可选择可用成分重归一，投票可选择缺失弃权。
- 一次训练后冻结参数；独立的训练期、验证期和样本外比较，及显式触发的重新拟合。重新拟合生成新的状态版本。
- 单因子、等权和拟议复合因子的统计与诊断组合公平对照；合成专属的覆盖、相关、边际增量和拟合权重诊断。
- 结果内保留成分配方、拟合来源、有效成分数、有效系数、警告和可复核的时间边界。

### 2.2 首版不支持

- 在合成组件内部计算基础因子、加载数据或执行单因子预处理；不要求改造现有预处理器为增量状态机。
- 复合因子嵌套、自动因子挖掘、自动批准 `CandidateFactor`。
- 回归、Grinold/相关矩阵最优 IC、贝叶斯、机器学习和在线动态权重。
- 交易中途自动重估；完整策略仓位、订单、移仓、成交和账户核算。
- 独立持久化、报告网页或统一研究编排器。本组件独立可运行，未来编排器只调用其公共入口。
- 非日频或 Tick 因子合成。

## 3. 系统边界和依赖方向

合成组件位于 `factors` 内，依赖 `factors.models`、现有研究数据和标签对象，以及 pandas/NumPy。统计评价可调用 `factors.evaluation` 的纯函数；经济评价只调用现有诊断组合运行器。组件不能依赖 `strategy/portfolio/backtester/executor/account`，也不能把诊断组合代理收益命名为真实账户收益。

`CompositeFactor` 与旧架构的差异是**输入边界**：旧稿设想直接持有基础 `Factor` 和预处理链；本方案把这些工作留在上游，只持有可审计的成分配方及已处理数值。这个修订避免在首版合成时一并重做预处理的增量协议，但要求上游在交付矩阵时声明自身时间可得性。成分的 `Factor.update`、预处理的重放等价性属于其各自模块，不由合成测试冒充已证明。

合成实验入口与统计函数、诊断组合运行器的关系：

~~~text
已处理矩阵 ─→ CompositeFactor ─→ 复合单列信号
                                   ├─→ 现有统计函数
                                   └─→ DiagnosticPortfolioExperimentRunner
成分单列信号 ─────────────────────┴─→ 同条件基线比较
~~~

同一候选进入不同 `HarvestProfile` 时可以得到不同经济结论；合成模块只负责产出预测变量和研究证据，不固定策略仓位映射。

## 4. 必须由测试保护的不变量

1. **索引与样本**：矩阵索引与 `ResearchDataset.main_panel.index` 完全相同，名称严格为 `timestamp, product`，唯一且按时间/品种稳定排序；列是有序且互异的成分名称。输出保留完整索引，不通过 `dropna` 静默删除行。
2. **准入**：只有 `universe.eligible=True` 的行参与合成和拟合。不合格行复合值为 NaN，排除原因保留在数据集；矩阵原值不被原地修改。
3. **信息集**：`transform/update` 不读取标签。拟合只读取训练截止时已完整成熟的标签与训练期成分，方向和系数的任何数据驱动决定都不能看验证/测试标签。
4. **冻结状态**：拟合状态含有确定的训练边界与生效时点；应用期参数不因新标签出现而改变。新一轮拟合是显式研究事件，产生新状态。
5. **双接口**：用相同冻结状态、同一批当期矩阵和品种池，批量与逐时点合成在样本外逐行相等；截面排名的增量输入必须包含当期完整研究截面。
6. **结果可解释**：成分输入、配置、有效成分数、有效系数与输出能够逐行重建；合成不会反向改变成分矩阵或其元数据。
7. **收益语义**：合成时点 $t$ 的预测变量只配对 $t$ 之后标签；诊断组合中 $w_t$ 只配对下一全局研究期的 `True_Return[t+1]`，不得把重叠的多期标签连乘为净值。

## 5. 输入矩阵与成分配方

### 5.1 FactorMatrix

以下两个类为**待开发定义**。导入项与后文第 6 节代码块合并后构成同一个 `factors/combination.py` 模块；`INDEX_NAMES` 已在现有 `factors.models` 定义。

~~~python
from __future__ import annotations

from dataclasses import dataclass, field
from typing import Any, Literal, Mapping

import numpy as np
import pandas as pd

from factors.models import INDEX_NAMES


@dataclass(frozen=True)
class ConstituentSpec:
    """单个已预处理成分的来源与方向配方。"""

    name: str
    factor_name: str
    direction: Literal[-1, 1]
    factor_params: Mapping[str, Any] = field(default_factory=dict)
    preprocess_steps: tuple[Mapping[str, Any], ...] = ()
    warmup_periods: int | None = None
    value_stage: Literal['preprocessed'] = 'preprocessed'
    source_warnings: tuple[str, ...] = ()

    def __post_init__(self) -> None:
        if (not isinstance(self.name, str) or not self.name.strip() or
            not isinstance(self.factor_name, str) or not self.factor_name.strip()):
            raise ValueError('成分名与来源因子名不能为空')
        if type(self.direction) is not int or self.direction not in (-1, 1):
            raise ValueError('成分方向必须为 +1 或 -1')
        if self.warmup_periods is not None and self.warmup_periods < 0:
            raise ValueError('暖机期数不能为负')


@dataclass(frozen=True)
class FactorMatrix:
    """已计算、已预处理的多成分矩阵及其有序配方。"""

    values: pd.DataFrame = field(repr=False)
    constituents: tuple[ConstituentSpec, ...]

    def __post_init__(self) -> None:
        if not isinstance(self.values, pd.DataFrame) or self.values.empty:
            raise ValueError('成分矩阵必须是非空 DataFrame')
        index = self.values.index
        names = tuple(item.name for item in self.constituents)
        if not isinstance(index, pd.MultiIndex) or tuple(index.names) != INDEX_NAMES:
            raise ValueError('成分矩阵索引必须为 (timestamp, product)')
        if not index.is_unique or not index.is_monotonic_increasing:
            raise ValueError('成分矩阵索引必须唯一且升序')
        if len(names) < 2 or len(set(names)) != len(names):
            raise ValueError('至少需要两个名称互异的成分')
        if tuple(self.values.columns) != names:
            raise ValueError('矩阵列名与成分配方的名称及顺序必须完全一致')
        if any(not pd.api.types.is_numeric_dtype(dtype)
               or pd.api.types.is_bool_dtype(dtype)
               for dtype in self.values.dtypes):
            raise ValueError('成分矩阵必须为非布尔数值列')
        if np.isinf(self.values.to_numpy(dtype='float64',
                                          na_value=np.nan)).any():
            raise ValueError('成分矩阵不能包含正负无穷')
~~~

`ConstituentSpec` 记录稳定名称、来源基础因子及参数、预处理链与参数、`direction`（+1/-1）、暖机说明、输入值的阶段标记及来源警告。方向取经济假设或在更早的独立训练过程确定；首版不根据本次拟合标签自动翻转方向。方向乘在合成边界，原始输入矩阵保持不变。若上游已经完成方向对齐，`direction=+1` 并在配方中说明。

输入要求：非空、至少两列、数值型、不能含正负无穷；允许 NaN。矩阵列不得伪装成标签，且标签单独通过 `LabelResult` 提供。矩阵行必须覆盖完整研究面板；上市前不存在的行可为 NaN。因子值在品种池之外仍可保留以便审计，但不进入拟合与复合值。

### 5.2 联合输入面板

合成内部按索引把方向对齐后的矩阵、`universe.eligible` 和指定标签列组成临时联合面板。矩阵为基准索引；标签必须与之同索引，不能通过外连接生成新的历史行。标签仅用于 `fit` 和评价。输出结果应记录每时点合格行数、有效成分数，以及因缺失或品种池排除而无法合成的行数。

不要把“未上市”“池外”“成分暖机”和“原始缺失”都变成同一种零值。上游若没有详细缺失原因，组件至少保留每列原始 NaN 掩码、资格掩码与本组件产生的降级原因；不得伪造原因。

### 5.3 标签与训练成熟时点

首版监督加权仅接受 `LabelSpec.type='forward_return'`、`horizon=h>=1`，并显式指定 `LabelSpec.name`。`LabelBuilder` 当前按**每个品种后续 $h$ 条观测**构造未来收益；因此成熟时点不是简单的自然日 $t+h$，而应由该品种第 $h$ 条后续研究观测的时间戳确定。样本 $(i,t)$ 只有在该终点存在、完整 $h$ 期收益所需观测均有效、且终点不晚于训练截止时，才能进入 `fit`。监督状态在训练截止后才可应用：生效时点取全局研究时间轴上严格晚于 `train_end` 的首个决策时点；若当前数据集没有该时点，比较实验应报错并要求提供包含应用期的数据集。

现有 `LabelSpec.min_valid_obs` 可能小于 $h$，使部分未来期数仍产生非空标签。拟合不能仅以“标签非 NaN”判定成熟；本组件对监督拟合要求完整 $h$ 期端点及完整有效收益，并在元数据中报告因成熟度与缺失被剔除的数量。标签构造口径和 `ResearchDataset.spec.view`（`scheduled/realized`）都进入配方。单因子统计评价可保留其原有口径，但合成拟合绝不把部分标签当作完整 $h$ 期训练目标。


## 6. 核心配置、状态与公共接口

### 6.1 配置对象

配置类沿用仓库的 `frozen dataclass`。以下为**待开发的具体定义**，其中 `EvaluationConfig`、`LabelSpec` 与 `DiagnosticPortfolioSpec` 均是现有类；`CompositeSpec` 与实验配置是新类。

~~~python
from factors.models import EvaluationConfig, LabelSpec
from factors.diagnostic_portfolio.models import DiagnosticPortfolioSpec


@dataclass(frozen=True)
class TimeWindow:
    """闭区间研究时间窗，决策时点均取自全局研究时间轴。"""

    start: pd.Timestamp
    end: pd.Timestamp

    def __post_init__(self) -> None:
        if self.start > self.end:
            raise ValueError('时间窗起点不能晚于终点')


@dataclass(frozen=True)
class ICFitSpec:
    """监督合成仅在该窗口内估计成分质量。"""

    label_name: str
    train_start: pd.Timestamp
    train_end: pd.Timestamp
    min_observations: int
    min_valid_groups: int
    score: Literal['ic', 'icir'] = 'ic'
    correlation: Literal['pearson', 'rank'] = 'pearson'
    ts_block_size: int | None = None

    def __post_init__(self) -> None:
        if (not isinstance(self.label_name, str) or not self.label_name.strip()
            or self.train_start > self.train_end):
            raise ValueError('标签名或训练时间窗无效')
        for name in ('min_observations', 'min_valid_groups'):
            value = getattr(self, name)
            if type(value) is not int or value < 2:
                raise ValueError(f'{name} 必须是至少为 2 的整数')
        if self.score not in ('ic', 'icir'):
            raise ValueError('score 只能为 ic 或 icir')
        if self.correlation not in ('pearson', 'rank'):
            raise ValueError('correlation 只能为 pearson 或 rank')
        if self.ts_block_size is not None and (
            type(self.ts_block_size) is not int or self.ts_block_size < 2
        ):
            raise ValueError('ts_block_size 必须是至少为 2 的整数')


@dataclass(frozen=True)
class CompositeSpec:
    """一个复合预测变量的合成规则。"""

    name: str
    mode: Literal['time_series', 'cross_sectional']
    operator: Literal['equal_weight', 'vote', 'rank', 'ic_weighted']
    missing_policy: Literal['strict', 'renormalize', 'abstain'] = 'strict'
    ic_fit: ICFitSpec | None = None

    def __post_init__(self) -> None:
        if not isinstance(self.name, str) or not self.name.strip():
            raise ValueError('复合因子名称不能为空')
        allowed = {
            'equal_weight': {'strict', 'renormalize'},
            'vote': {'strict', 'abstain'},
            'rank': {'strict'},
            'ic_weighted': {'strict', 'renormalize'},
        }
        if self.mode not in ('time_series', 'cross_sectional'):
            raise ValueError('非法合成模式')
        if self.operator not in allowed:
            raise ValueError('非法合成算子')
        if self.missing_policy not in allowed[self.operator]:
            raise ValueError('算子不支持该缺失政策')
        if self.operator == 'vote' and self.mode != 'time_series':
            raise ValueError('投票只支持时序模式')
        if self.operator == 'rank' and self.mode != 'cross_sectional':
            raise ValueError('排名只支持截面模式')
        if (self.operator == 'ic_weighted') != (self.ic_fit is not None):
            raise ValueError('仅 IC 加权算子需要 ic_fit')
        if self.ic_fit is not None:
            if self.mode == 'time_series' and self.ic_fit.ts_block_size is None:
                raise ValueError('时序 IC 加权必须指定时间块长度')
            if self.mode == 'cross_sectional' and self.ic_fit.ts_block_size is not None:
                raise ValueError('截面 IC 加权不能指定时间块长度')


@dataclass(frozen=True)
class CombinationStudySpec:
    """统一统计口径和诊断组合口径的一次研究对照。"""

    train: TimeWindow
    test: TimeWindow
    label_name: str
    evaluation: EvaluationConfig
    portfolio: DiagnosticPortfolioSpec
    validation: TimeWindow | None = None

    def __post_init__(self) -> None:
        if not isinstance(self.label_name, str) or not self.label_name.strip():
            raise ValueError('评价标签名不能为空')
        if self.validation is None:
            if self.train.end >= self.test.start:
                raise ValueError('训练期与样本外期必须分离')
        elif not (self.train.end < self.validation.start
                  and self.validation.end < self.test.start):
            raise ValueError('训练、验证和样本外时间窗必须有序且不重叠')
~~~

`ICFitSpec.ts_block_size` 与标签期限的关系需要拿到实际 `LabelSpec.horizon` 后校验；`CombinationStudySpec.evaluation.mode`、`label_horizon` 与 `CompositeSpec`、`LabelSpec` 的一致性，以及组合收获范式的合法性，均在 `CombinationStudyRunner` 的输入校验阶段完成。单个 dataclass 不额外接收数据集或标签对象。

固定算子不接受 `ic_fit`；`ic_weighted` 必须提供完整 `ic_fit`。`vote` 只接受 `time_series`，`rank` 只接受 `cross_sectional`；等权和 IC/ICIR 加权在两种模式下均可用。无意义或互相矛盾的字段直接报错，不接受后静默忽略。`min_observations>=2`、`min_valid_groups>=2`；时序块长须大于等于 `max(min_observations, label_horizon)`，且由调用方显式给定，不在模块里暗设“一个季度”。

训练与比较应使用独立的 `CombinationStudySpec`，显式指定训练期、可选验证期、必选样本外期的起止时点，评价标签、`EvaluationConfig`、一个 `DiagnosticPortfolioSpec`，并始终输出各自可用样本覆盖与共同样本对照结果。各时间段不重叠；监督算子的训练边界必须与 `ICFitSpec` 一致，样本外起点不早于冻结状态生效日。固定算子无需拟合生效等待。标签尾部自然缺失不构成拟合错误。等权基线从相同 `FactorMatrix` 和方向生成，不复用拟议 IC 权重。

### 6.2 冻结状态与结果

下列**待开发类**把原先的文字清单落到具体类型。`state_id` 由 `fit` 根据规范化配置、成分顺序、训练边界、质量明细和拟合系数生成确定性指纹；重拟合若状态内容不同，生成新的状态。固定算子的质量字段为空，`effective_at=None` 表示不受训练截止限制。

~~~python
from factors.diagnostic_portfolio.models import DiagnosticPortfolioResult


@dataclass(frozen=True)
class CombinationWarning:
    """可定位到阶段与样本的非致命问题。"""

    stage: Literal['input', 'fit', 'combination',
                   'evaluation', 'portfolio']
    code: str
    message: str
    timestamp: pd.Timestamp | None = None
    product: str | None = None
    constituent: str | None = None


@dataclass(frozen=True)
class FittedCombinationState:
    """一次固定规则或监督拟合得到的冻结合成状态。"""

    state_id: str
    spec: CompositeSpec
    constituent_names: tuple[str, ...]
    coefficients: tuple[float, ...]
    train_window: TimeWindow | None
    label_spec: LabelSpec | None
    correlation: Literal['pearson', 'rank'] | None
    score: Literal['ic', 'icir'] | None
    ts_block_size: int | None
    quality_by_component: tuple[float | None, ...]
    zero_weight_reasons: tuple[str | None, ...]
    valid_group_count: int
    effective_at: pd.Timestamp | None
    config_snapshot: Mapping[str, Any] = field(repr=False)
    quality_detail: pd.DataFrame = field(repr=False)
    cross_product_dispersion: pd.DataFrame | None = field(repr=False)
    warnings: tuple[CombinationWarning, ...] = ()

    def __post_init__(self) -> None:
        k = len(self.constituent_names)
        if not self.state_id or k < 2 or len(set(self.constituent_names)) != k:
            raise ValueError('状态 ID 或成分名称无效')
        if (len(self.coefficients) != k
            or len(self.quality_by_component) != k
            or len(self.zero_weight_reasons) != k):
            raise ValueError('系数、质量与原因必须逐成分对齐')
        if any(not np.isfinite(a) or a < 0 for a in self.coefficients):
            raise ValueError('合成系数必须为有限非负数')
        if not np.isclose(sum(self.coefficients), 1.0):
            raise ValueError('合成系数之和必须为 1')
        if self.spec.operator == 'ic_weighted':
            if (self.train_window is None or self.label_spec is None
                or self.effective_at is None or self.score is None
                or self.correlation is None):
                raise ValueError('监督状态缺少训练与生效信息')
            if any(q is None or not np.isfinite(q)
                   for q in self.quality_by_component):
                raise ValueError('监督状态的成分质量必须全部有限')
            fit = self.spec.ic_fit
            if fit is None:
                raise ValueError('监督状态缺少 IC 拟合配置')
            if (self.train_window != TimeWindow(fit.train_start, fit.train_end)
                or self.label_spec.name != fit.label_name
                or self.correlation != fit.correlation
                or self.score != fit.score
                or self.ts_block_size != fit.ts_block_size
                or self.effective_at <= fit.train_end):
                raise ValueError('监督状态与训练配置或生效边界不一致')
            if self.valid_group_count < fit.min_valid_groups:
                raise ValueError('监督状态的有效组数不足')
            if (tuple(self.quality_detail.columns) != self.constituent_names
                or len(self.quality_detail) != self.valid_group_count):
                raise ValueError('共同有效组 IC 明细与状态不一致')
            if (self.spec.mode == 'time_series'
                and self.cross_product_dispersion is None):
                raise ValueError('时序状态必须保留品种间 IC 离散度')
            if (self.spec.mode == 'cross_sectional'
                and self.cross_product_dispersion is not None):
                raise ValueError('截面状态不应包含品种间 IC 离散度')
        elif (self.train_window is not None or self.label_spec is not None
              or self.effective_at is not None
              or self.score is not None or self.correlation is not None
              or self.ts_block_size is not None
              or self.valid_group_count != 0
              or any(q is not None for q in self.quality_by_component)
              or not self.quality_detail.empty
              or self.cross_product_dispersion is not None):
            raise ValueError('固定算子不得伪造监督拟合信息')
~~~

### 6.3 公共计算契约

~~~python
composite = CompositeFactor(spec, constituents)
state = composite.fit(matrix, dataset, label_result=None)
batch = composite.transform(matrix, dataset, state)
one_bar = composite.update(timestamp_matrix, dataset, state)
~~~

- `fit`：固定算子生成固定状态且不接触标签；IC 算子只在 `ICFitSpec` 指定窗口中读取指定标签，构造完整成熟样本并冻结权重。训练失败不返回似是而非的状态。
- `transform`：接受完整已处理矩阵和 `ResearchDataset`，返回全索引结果；不接收标签。允许在训练区间生成仅供解释的样本内值，但结果要标记“拟合内/冻结后”，不得把前者写成历史实时预测。
- `update`：接受**恰好一个时间戳**的矩阵和研究数据集，只读取该时点的 `main_panel` 行集合及 `universe.eligible`，校验矩阵包含完整当期截面；不接收标签或上游 `FactorState`。只处理完整截面，不允许逐品种到达后立即计算截面排名。拟合算子只允许在状态生效时点及其后调用；批量/增量等价性在这段冻结后区间检验。
- 两个接口共用同一行变换函数。`update` 不修改冻结状态；是否重新拟合由外层显式调用 `fit` 并替换状态，旧状态仍可用于回放。

## 7. 固定算子

### 7.1 等权

在方向对齐后，对第 $k$ 个成分赋固定权重 $a_k=1/K$：

$$s_{i,t}=\sum_{k=1}^{K}a_k z^{(k)}_{i,t}.$$

这里的 `z` 是上游完成缩尾、标准化等处理、再按 `ConstituentSpec.direction` 乘正负号的值。模块不再自动标准化；若输入尺度不同，等权的经济含义就不是“各成分贡献相等”，方案要求在配方中明确上游尺度。

### 7.2 时序投票

在每个品种、每个决策时点，有限成分值的符号形成票：`sign(z)>0` 为正票，`sign(z)<0` 为负票，精确零为中立票。用等成分权重计算净票分数；正负票抵消为零，不能擅自沿用前一期方向。该算子不做横截面排名，允许同一日各品种均为正票。`abstain` 政策下，缺失成分不进入分母；无有效票则输出 NaN。投票输出仍由下游诊断组合映射为研究权重。

### 7.3 截面排名

在每个时间戳，只取 `eligible=True` 且全部成分有限的共同截面，至少两品种。每列按升序平均秩处理并映射到 $[-1,1]$：

$$q^{(k)}_{i,t}
=\frac{2(\operatorname{rank}^{(k)}_{i,t}-1)}{N_t-1}-1,
\qquad s_{i,t}=\frac{1}{K}\sum_k q^{(k)}_{i,t}.$$

重复值使用平均秩；某列全相等时该列在当期所有品种得零。品种池外与非完整成分行输出 NaN；其余品种在同一完整成分截面内重新计算排名和 $N_t$，并记录样本缩减。此处排名是**因子合成的相对预测分数**；下游 `market_rank_ls` 可以再对单列复合分数排名形成品种权重，两次排序分别属于不同层次，须在结果配方中明示。

## 8. 成分缺失政策

| 算子 | 可选政策 | 行为 |
|---|---|---|
| 等权 | `strict`、`renormalize` | 严格模式下任一成分缺失即 NaN；重归一下只对有效成分按原权重再归一 |
| 时序投票 | `strict`、`abstain` | 严格模式下任一缺失即 NaN；弃权模式忽略缺失票，零值为中立票 |
| 截面排名 | `strict` | 先在同一完整成分截面上求每列秩；首版不提供成分缺失时改变各列排名样本的降级 |
| IC/ICIR 加权 | `strict`、`renormalize` | 严格模式要求全部成分有限；重归一只对当前有限且冻结系数为正的成分重算分母 |

`strict` 为默认。重归一的分母为当前有效成分的冻结权重之和；若为零，输出 NaN 并记录原因，不退回等权。只有一个正权重成分有效时允许输出，但有效成分数、参与贡献的成分数和实际系数必须可查询，便于剔除“退化为单因子”的观察再做敏感性分析。投票没有有效票时为 NaN，正负票相抵时为零。所有政策都要分别输出原始机会集覆盖率、复合有效覆盖率以及因缺失而降级的数量；对照实验另报共同样本指标。

## 9. IC/ICIR 加权的训练口径

### 9.1 统一准备

监督算子按相同的**训练期完整成分联合样本**估计每个成分质量：`eligible=True`，所有 $K$ 个方向对齐成分有限，目标标签为完整 $h$ 期且已成熟。即使最终选择 `renormalize`，拟合时也不能让某个成分仅因覆盖较少便在另一套样本上取得不可比的 IC。先在相同的完整成分联合样本上分别计算各成分 IC，再取对**所有**成分均有效的日期或“时间块 × 品种”组，使各成分的质量估计使用相同有效组；按 `ICFitSpec.correlation` 计算 Pearson IC 或双边平均秩后的 Rank IC。这一选择是实验配置，不能在测试期根据结果切换。标签必须为 `forward_return`，不直接用 `direction` 或 `future_volatility` 冒充收益 IC。

### 9.2 截面模式

对训练期每个全局时间戳，在当期共同有效品种中计算每列成分与同一标签的截面相关；少于 `min_observations`、成分或标签零方差时该日无效，并记录原因。有效日期序列记为 $IC_{k,t}$，每个有效日期等权参与：

$$Q_k^{IC}=\overline{IC_k},\qquad
Q_k^{ICIR}=\frac{\overline{IC_k}}{\operatorname{sd}(IC_{k,t})}.$$

标准差采用样本标准差，至少需要 `min_valid_groups` 个各成分共同有效的日期；任一成分的标准差为零或质量非有限时，ICIR 拟合整体报错，不能设成无穷大或静默剔除该成分。这里的 ICIR 不年化，不借用统计报告的年化 ICIR；多期标签使相邻日期 IC 相关，因此该比值仅作为训练期加权质量，不当作显著性检验。

### 9.3 时序模式

按训练期**全局研究时间轴**分成长度为 `ts_block_size` 的连续、不重叠时间块，从 `train_start` 固定锚点划分；不足完整块长的尾块不进入拟合并记录舍弃范围。对每一块、每一品种，在块内共同有效观测上计算该成分与未来标签的时序 IC；少于 `min_observations` 或零方差则该“块 × 品种”无效。一个块至少有两个对**全部成分**均可计算 IC 的品种，才能在相同品种集合上形成跨品种等权平均的块 IC $IC_{k,b}$，并计算块内品种 IC 的离散度作为补充诊断。

随后沿有效**时间块**而非沿品种计算 $\overline{IC_{k,b}}$ 与 $\operatorname{sd}(IC_{k,b})$，得到时序的 `IC` 与 `ICIR` 质量。这样 ICIR 描述时间稳定性；品种间离散度独立报告，不能混称为同一统计量。各成分使用同一块边界、同一块内品种集合和联合样本；`min_valid_groups` 检查有效块数。多期标签可能跨块重叠，因此块 ICIR 是描述性的稳定性权重，不等同于独立样本的检验统计量。现有 `ic_details(mode='time_series')` 只返回全训练区间的分品种 IC，不能直接当作这里的块 ICIR 拟合器。

### 9.4 从质量到系数

方向已由配置确定。设选择的质量为 $Q_k$，首版只对正质量分配系数：

$$\tilde a_k=\max(0,Q_k),\qquad
a_k=\frac{\tilde a_k}{\sum_j\tilde a_j}.$$

任一成分质量非有限、有效时间组不足，或所有成分质量非正使分母为零时，`fit` 整体报错，并提供各成分质量和失败原因。若部分成分质量非正，其系数为零并进入状态说明。不要在失败时隐式采用等权。冻结后的变换仅做 $\sum_k a_k z^{(k)}_{i,t}$，不在新时点重算 IC；若后续研究需要重新拟合，应显式产生新的状态和生效时点。


## 10. 固定编排顺序

`CombinationStudyRunner` 是独立入口，不等待未来的 `ResearchExperimentRunner`。它只编排现有组件，不复制 IC、组合权重和收益核算公式：

1. 校验 `ResearchDataset`、`FactorMatrix`、`CompositeSpec`、`LabelResult` 和比较配置。
2. 取得各成分的方向对齐视图；原始矩阵不原地修改。
3. 按完整预测终点构造监督拟合样本，调用 `CompositeFactor.fit` 并冻结状态；固定算子不读取标签。
4. 在要求的区间调用批量 `transform`，保留完整索引、缺失和有效系数。
5. 用同一矩阵生成方向对齐的各成分单列基线及等权基线；等权基线采用与拟议算子兼容的同一缺失政策，投票专用的 `abstain` 对照使用严格等权，并依靠共同机会集保证主比较公平。拟议算子本身为等权时仅保留一个等权结果，不重复报告。
6. 构造统计评价所需的 `factor/label/universe` 三列视图，复用现有 `coverage_stats`、`ic_details`，以及适用的 `grouped_details`。时序分组只用扩展或滚动历史阈值，不使用 `full_sample` 方式生成历史可用分组。
7. 构造诊断组合对照所需的共同机会集与 `DiagnosticSignal`，以同一 `DiagnosticPortfolioSpec` 对每个候选运行现有 `DiagnosticPortfolioExperimentRunner`。
8. 汇总成分相关、复合增量、合成权重与覆盖、组合收益和差值，返回内存中的 `CombinationStudyResult`。

`CombinationStudyResult` 至少保留：合成结果、各候选单列值、训练/比较区间、统计共同样本掩码、经济共同机会集掩码、候选统计结果、候选 `DiagnosticPortfolioResult`、成分相关矩阵或分期明细、增量表、警告及全部配置。若某个必需候选无法构造合法单列信号，研究比较明确失败；不通过删除失败基线宣称复合胜出。

## 11. 公平对照的两个样本口径

### 11.1 各自可用样本

每个成分和复合因子分别在原动态品种池上报告总覆盖、分时点和分品种覆盖，以及缺失或降级原因。此表反映真实可用范围，不拿“共同样本”掩盖复合覆盖下降。IC 拟合本身始终使用训练期完整成分联合样本。

### 11.2 统计共同样本

比较 IC、Rank IC、分组或回归时，选同一评价区间、同一完整标签列和原品种池，并要求所有被比较信号在该行有限。然后对每个候选使用同一行掩码。最终测试期只能评价已冻结的候选，不能依据该期 IC 重新选择成分、方向或超参数。“最佳单因子”若出现在报告里，必须按事前确定的训练/验证期指标选定；测试期同时报告所有成分，不事后挑选最高者。

### 11.3 经济共同机会集

诊断组合收益的资格掩码只可依赖当期已知信息：

$$U^{common}_{i,t}
=U_{i,t}\land\bigwedge_{c\in C}\operatorname{finite}(s^{(c)}_{i,t}),$$

其中 $C$ 是本次公平对照的候选信号集合。**不能把未来标签是否非空纳入这个掩码**，否则会根据未来收益筛选当日可交易机会。调用现有组合运行器时，为所有候选构造相同、独立的新 `ResearchDataset.universe` 视图，原数据集不修改。所有候选共享同一 `DiagnosticPortfolioSpec`、全局调仓时间轴、风险估计、仓位上限和成本率；只替换单列信号。比较毛收益、代理净收益、Sharpe、回撤、权重换手、风险暴露和贡献，并记录共同机会集比原品种池缩小了多少。

如果使用各自可用机会集补充做真实覆盖研究，必须另表报告，不与主共同样本对照混成一个差值。经济对照使用 `True_Return` 的**下一全局单期**收益；多期标签不作为逐日净值收益。

## 12. 合成专属诊断与结果解释

首版不另建一套完整 `FactorEvaluator`。通用覆盖、IC 和分组复用已有函数；合成专属诊断只实现以下可复核表格：

1. **成分结构**：共同训练样本的 Pearson/Spearman 相关矩阵；按模式补充分品种或逐期相关，并标注有效样本数。相关高只说明信号相近，不能直接断言预测冗余。
2. **覆盖与降级**：原机会集、共同成分样本、复合有效样本；分时点有效成分数、严格缺失、重归一或弃权发生次数。
3. **预测增量**：在统计共同样本上，复合与等权、各单因子的 IC/Rank IC 和分组结果差值；差值只描述同口径表现，不自动推断统计显著性或条件因果贡献。
4. **系数诊断**：每个成分的训练质量、有效组数、零权重原因和冻结系数。单次冻结实验的“权重稳定性”表现为系数在应用区间不变；不同预先定义的训练窗口或重新拟合实验之间再比较系数漂移，不在一次实验里凭空生成滚动权重。
5. **经济增量**：在相同研究权重规则下的毛收益、成本后收益、换手、暴露与贡献差值；若净收益提高但 IC 未提高，应进一步检查信号尺度、仓位约束和成本来源。

按实际配置分别标记训练期、可选验证期和必选样本外期的结果。单一 IC、单一 Sharpe 或孤立最优参数点不能自动批准候选。首版输出描述性比较与结构化警告；形式化多重检验、自动参数搜索和报告页面均在后续研究基础设施中设计。

## 13. 与诊断组合接口的最小调整

`DiagnosticSignal.source_stage` 新增 `'composite'`，`warnings` 允许 `'combination'` 阶段；原 `'raw'/'preprocessed'`、既有警告阶段及调用方式继续有效。`factor_name` 取复合因子稳定名称，`values` 是一列完整索引 `pd.Series`。对现有 `factors/diagnostic_portfolio/models.py` 的改动精确到以下声明；继续使用现有 `DiagnosticSignal.__post_init__` 校验，其余字段不重定义：

~~~python

_WARNING_STAGES = ('factor_computation', 'preprocess', 'combination')

# DiagnosticSignal 类中替换原字段注解

~~~

`recipe` 采用可 JSON 化的声明式映射，至少包含：


## 14. 错误、警告与降级

### 14.1 直接报错

- 矩阵/标签索引不合法、不唯一、列重复或与研究面板不一致；非数值、无穷值、成分少于两个。
- 成分配方顺序与矩阵列不一致；非法方向；算子、模式与缺失政策不兼容。
- 监督算子缺少训练窗口或指定标签；指定标签不是未来收益、成熟且完整的训练样本不足、有效时间组数不足、ICIR 标准差为零、质量非有限或正质量系数和为零。
- 状态与当前配置、成分列或生效时点不匹配；`update` 收到多个时间戳、不完整当期截面或过早日期。
- 比较时用错 `HarvestProfile`，或所需基线无法转换为合法 `DiagnosticSignal`。

### 14.2 保留结果并记录警告

- 单个时点截面太小或全并列，输出按算子政策为 NaN/零。
- 个别成分缺失导致严格模式缺失、重归一只剩一个成分、投票弃权或完全无票。
- 某些训练日期、品种或时间块因零方差或样本不足未能贡献 IC，但仍满足整体拟合门槛。
- 测试区间标签尾部自然缺失、复合覆盖低、诊断组合某时期有效品种不足。

警告进入 `CompositeFactorResult` 和 `CombinationStudyResult`；不能仅打印。任何降级都保留时点、品种、成分和原因，不把 NaN 无声置零。严重程度和有效数量同时进入结果，使研究者能区分正常缺失与研究失败。

## 17. 人工黄金路径

### 17.1 等权、方向与缺失

假设成分 `A`、`B` 已完成上游尺度处理，方向分别为 $+1$、$-1$。某合格行原矩阵 $(A,B)=(2,-4)$，方向对齐后 $(2,4)$，等权结果为 $3$。另一行 $(2,\mathrm{NaN})$：`strict` 输出 NaN，`renormalize` 输出 $2$，有效系数为 $(1,0)$、有效成分数为 1。若该行品种池准入为 False，无论输入值如何都输出 NaN，并不计入拟合或有效覆盖。

### 17.2 时序投票

方向对齐后的两成分为 $(+2,-3)$ 时，净票为 $0$；$(+2,\mathrm{NaN})$ 在 `strict` 下为 NaN，在 `abstain` 下为 $+1$；$(0,\mathrm{NaN})$ 在 `abstain` 下为 $0$（零是中立票而非缺失）。两成分都缺失时输出 NaN。测试应覆盖多个品种同日都为正票的场景，证明未引入横截面去中心。

### 17.3 截面排名与下游映射

同一时点三个合格品种 $P_1,P_2,P_3$ 的两个方向对齐成分分别为 $(2,1,0)$ 和 $(0,2,1)$。升序秩映射为 $(1,0,-1)$ 与 $(-1,1,0)$，等权复合分数为 $(0,0.5,-0.5)$。若下游使用 `market_rank_ls` 且无上限绑定，再次排名得到品种权重 $(0,0.5,-0.5)$。下一全局期研究收益若为 $(+1\%,+2\%,-1\%)$，组合毛收益为 $1.5\%$。两次排名分别发生在因子合成和品种权重映射，不可省略或互换。

### 17.4 IC 与 ICIR 系数

在截面模式，人工构造的两个有效日期 IC 序列若为：

~~~text
成分 A: 0.2, 0.4
成分 B: 0.1, 0.5
~~~

二者平均 IC 都是 $0.3$，按 IC 加权为 $(0.5,0.5)$。用样本标准差计算，A 的 ICIR 约为 $2.1213$，B 的约为 $1.0607$，按 ICIR 加权约为 $(2/3,1/3)$。单元测试应先用三品种可手算截面验证相关系数函数，再用此序列验证质量归一；不能直接把预设 IC 表当作唯一算子测试。

### 17.5 时序块、成熟端点与边界

两个完整时间块中，某成分的“块内分品种 IC”分别为 $(1,0.5)$、$(0.5,0.5)$，块 IC 依次为 $0.75$、$0.5$；沿块求均值为 $0.625$，样本标准差约 $0.1768$，ICIR 约 $3.5355$。首个块内品种间离散度非零，第二块为零；这些值另表报告，不把品种间标准差当作 ICIR 分母。

另设品种 $P$ 的研究观测日为 $t_1,t_3,t_6$，$h=2$ 时 $t_1$ 标签的完整终点是 $t_6$。训练截止若为 $t_4$，即使 `LabelResult.labels` 中预先计算了数值，`fit` 也必须排除该行。设 `min_valid_obs<h` 且尾部部分收益仍产生标签值时，也必须排除未达到完整 $h$ 期端点的行。

### 18.1 输入、配置与缺失

### 18.2 因果拟合

- 截面逐日 IC/Rank IC、时序按全局固定边界分块且品种等权平均、块尾丢弃、ICIR 样本标准差与零方差行为。

### 18.3 批量、增量和输入不可变

- 固定状态下批量与按全局时间戳输入的增量值、有效系数和缺失原因相等。

- 经济共同机会集只由当期信号与资格决定，不受 $h$ 期标签尾部 NaN 影响；同一组合规格下各候选的调仓时间轴相同。

## 19. 结果元数据与可复核性

即使首版不落盘，内存结果仍要携带一次实验的关键事实：

- 数据：`DatasetSpec` 摘要、研究面板起止、`scheduled/realized` 视图、品种池规格与有效行数。
- 成分：基础因子名称和参数、预处理步骤及顺序、方向、暖机说明、矩阵列顺序与各列覆盖。
- 标签：`LabelSpec`、完整终点规则、训练期成熟样本数与被排除原因。
- 合成：算子、缺失政策、拟合统计口径、质量表、冻结系数、状态生效时点、每行有效系数。
- 对照：训练/验证/样本外边界、统计共同样本和经济共同机会集的掩码定义、同一 `DiagnosticPortfolioSpec`。
- 警告：按输入、拟合、合成、统计对照和诊断组合五个阶段分开记录。

配置和数值结果的确定性必须由测试保护。同一输入重复运行，信号、系数、样本掩码和比较表相等；并行或列顺序变化不能改变结果。结果对象不把 pandas 对象误称为真正不可变，调用边界通过复制和测试保证不原地改动上游对象。

## 20. 主要风险与方案取舍

1. **上游预处理未统一增量化**：组件只验证“已处理矩阵 → 复合值”的批量/增量等价，不宣称“原始行情 → 复合值”全链路实时等价。未来若接策略层，须单独补齐各成分预处理的增量重放。
2. **ICIR 样本偏少**：尤其是时序分块后，有效块数可能很少。配置必须显式给出块长与最小有效组数，诊断展示逐块 IC 与有效品种数；不足则失败，不用激进系数制造表面精度。
3. **收益标签与组合收益不同步**：多期未来标签用于拟合及统计，诊断组合始终按其独立的下一期单期收益轴核算。比较机会集不得使用未来标签掩码。
4. **复杂度先于证据**：首版坚持等权基线、正质量 IC/ICIR 权重与一次冻结状态。相关矩阵求逆、回归、自动状态切换及正交化留待基础结果证明需要后再设计。
5. **配方能解释不等于已可复跑**：当前没有保存成分矩阵与拟合输入的合成运行仓库。`DiagnosticSignal.recipe` 用于解释来源；若需脱离当前数据复跑，应后续补充权威输入快照与存储设计。

## 21. 首版完成标准

组件完成后应能：

- 从完整日频研究面板接收两列以上、已处理且带配方的成分矩阵，准确执行方向与动态品种池规则。
- 以等权、时序投票、截面排名或训练期 IC/ICIR 权重生成可追溯的单列复合因子，并在冻结后区间保持批量与增量等价。
- 明确拒绝未成熟标签、错误模式、样本不足、非法配置和无正质量系数；缺失与降级均可审计。
- 在时序和截面两种模式下，对复合、成分及等权基线输出各自覆盖与共同样本统计证据。
- 将复合值作为 `source_stage='composite'` 的 `DiagnosticSignal`，在同一经济机会集和组合规格下比较研究权重、代理毛/净收益、换手、风险和贡献。
- 保持 `factors` 对下游交易模块的单向低耦合；不改变既有单因子或诊断组合数值语义。

2. 回归与正则化合成、约束系数、非线性模型；新方法仍须在相同样本和固定诊断组合配置下胜过简单基线。
3. 显式滚动重估和状态版本管理、跨窗口系数稳定性；每个重估日只使用已成熟标签。
4. 独立合成实验存储、报告与未来统一编排器；需要保存真实输入快照，而不只是配置文字。
5. 上游预处理的增量接口与策略/完整回测交付；只有全链路因果、重放和状态生命周期验证后，才可作为实时候选。

本方案不预设 V2 功能清单。任何后续扩展都应由当前实验无法回答的明确研究问题驱动。
