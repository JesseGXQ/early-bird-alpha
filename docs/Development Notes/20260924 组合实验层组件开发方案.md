## 2. 开发目标

组合实验层用于回答：

> 在不引入订单、成交、保证金、真实移仓和账户状态的前提下，如果采用一套固定、透明、因果且可复现的连续权重规则，单因子能否形成足够稳定、广泛且覆盖简单成本的组合收益？

V1 建立以下研究闭环：

~~~text
ResearchDataset + DiagnosticSignal + DiagnosticPortfolioSpec
                         ↓
                  联合输入校验
                         ↓
              信号映射与基础权重
                         ↓
              风险缩放与组合约束
                         ↓
              调仓日程与有效权重
                         ↓
         下一期 True_Return、换手与成本
                         ↓
      收益、净值、暴露、贡献、风险与绩效
                         ↓
             DiagnosticPortfolioResult
~~~

V1 的目标不是给出“可实盘交易”的结论，而是给出：

> 某个单因子或已经准备好的单列信号，在明确的数据、时间、收获范式、权重规则和成本代理下，能够形成可复现的研究代理收益，值得或不值得进入完整策略回测。

## 3. V1 范围

### 3.1 V1 支持

V1 同步支持两个策略家族、三份可执行研究配方：

| 策略家族 | 配方 | 信号到权重的核心链路 |
|---|---|---|
| 时序 CTA | ts_inv_vol_gross_one | clip → 逆波动率 → 等品种风险预算 → gross=1 |
| 时序 CTA | ts_inv_vol_target_vol | 在 gross-one 基础权重上使用滚动协方差估计组合风险，再缩放至目标波动率 |
| 截面多空 | market_rank_ls | 截面平均排名 → 去中心化 → 市场中性 → gross=1 |

其中 ts_inv_vol_gross_one 是 V1 新增的研究基准范式；ts_inv_vol_target_vol 和 market_rank_ls 复用现有 HarvestProfile 的语义。

V1 还支持：

- 日频 ResearchDataset。
- 单因子原始值或完成预处理后的单列信号。
- 全局固定间隔调仓。
- 非调仓日冻结研究权重。
- 动态品种池进入与退出。
- 时序因子的单品种事前波动率估计。
- 滚动样本协方差和目标波动率缩放。
- 单品种绝对权重上限、最大 gross 和最大缩放倍数。
- 统一单边成本率或按品种固定单边成本率。
- 毛收益、代理净收益及相应净值。
- 换手、gross/net exposure、事前风险、实现风险。
- 品种、多空方向和可选板块 PnL 贡献。
- 核心绩效指标。
- 结构化警告、元数据和完整中间表。

### 3.2 V1 不支持

V1 不支持：

- 板块中性截面组合。
- 逆波动率加权的板块中性投影。
- 板块风险预算和风险平价。
- 协方差与成本约束优化器。
- 硬换手预算或换手惩罚优化。
- 多因子合成和因子权重拟合。
- 多日错峰 sleeve。
- 权重在非调仓日的自然漂移。
- 时变成本率、盘口成本和非线性冲击。
- 真实主力合约映射和精确移仓路径。
- 合约乘数、张数取整、订单、成交和部分成交。
- 保证金、现金、账户权益和强平。
- 日内频率。

即使 factors/profiles.py 已经定义 sector_neutral_rv、sector_neutral_inv_vol、constrained_alpha_opt 和 sector_risk_budget_cta，V1 运行器也必须明确拒绝这些尚未实现的范式，不得静默降级成相似但语义不同的权重规则。

## 4. 系统边界与依赖方向

### 4.1 与 FactorEvaluator 的关系

FactorEvaluator 负责预测关系与信号性质诊断，例如覆盖率、IC、回归、命中率、分组和衰减。

DiagnosticPortfolioExperiment 负责信号到连续研究权重及代理收益的转换。

二者是兄弟组件，不互相调用：

~~~text
                         ┌→ FactorEvaluator
Factor / Label / Dataset ┤
                         └→ DiagnosticPortfolioExperiment
~~~

FactorEvaluator 的结果不是组合实验的必需输入。组合实验也不得把某个 IC 阈值内置为能否运行的条件。是否允许一个因子进入组合实验由研究流程决定，而不是由运行器自动批准。

### 4.2 与 ResearchExperimentRunner 的关系

未来 ResearchExperimentRunner 负责：

1. 构建数据和动态品种池。
2. 计算因子并执行预处理。
3. 构造标签并运行统计诊断。
4. 将明确阶段的单列信号包装成 DiagnosticSignal。
5. 按配置运行一个或多个 DiagnosticPortfolioExperiment。
6. 汇总实验身份、统计证据和组合证据。

本组件必须可以独立运行，不等待 ResearchExperimentRunner 完成。未来 Runner 只负责编排，不在外部重新实现权重、成本或绩效公式。

### 4.3 与完整回测的关系

组合实验层不依赖：

~~~text
strategy/
portfolio/
backtester/
executor/
account/
~~~

它不导入 BarMarketEvent、TargetPosition、Order、Fill、Account 或 PerformanceRecorder。

完整回测以后可以消费 CandidateFactor 和研究配方，但不得把 DiagnosticPortfolioResult 当作账户回测结果。二者的差异用于量化实现折损。

### 4.4 允许依赖

允许依赖：

- factors.models 中的研究领域对象。
- factors.profiles 中的 HarvestProfile。
- pandas、numpy 和标准库。
- utils 中不携带账户或执行语义的纯工具。

组合实验层不直接复用 analytics/recorder.py。该记录器的输入是账户快照，且其绩效语义属于完整回测。V1 在组合实验内部实现针对收益序列的纯绩效函数；未来若两层公式统一，再提取无状态公共工具。

## 5. 架构不变量

以下不变量必须由测试保护。

### 5.1 时间不变量

1. 时点 t 的信号、品种池、波动率和协方差只能使用 t 及以前可见的数据。
2. 时点 t 形成的研究权重只能赚取下一全局研究时点的 True_Return。
3. 调仓日程由全局时间轴和显式锚点决定，不得因不同因子的首个有效值不同而漂移。
4. 风险窗口可以包含时点 t 已经观察到的 True_Return[t]，不得包含 True_Return[t+1]。
5. 样本最后一个时间戳没有下一期收益，不形成新的可评价调仓决策。

### 5.2 索引不变量

1. 信号、主面板、品种池和权重统一使用唯一、升序的 MultiIndex[timestamp, product]。
2. 下一期收益必须按全局时间轴对齐，不能把某品种“下一条非缺失记录”错误当作组合的下一研究期。
3. 任何输入中出现研究面板以外的索引行均为错误。
4. 输入缺少的研究面板行可以重索引为 NaN，但必须进入缺失政策。

### 5.3 收益不变量

一期组合毛收益为：

$$
R_{t+1}^{gross}
=
\sum_i w_{i,t}r_{i,t+1}.
$$

用于 IC 等第一层诊断的重叠 h 期标签不得作为逐日组合收益连乘。V1 只使用 ResearchDataset.main_panel 中的单期 True_Return。

### 5.4 权重不变量

1. 非调仓日保持上次有效研究权重不变，不模拟名义权重漂移。
2. 品种池退出优先级高于冻结规则：退出品种立即归零。
3. 新进入品种池的品种只能在下一计划调仓日获得非零权重。
4. 非有限信号、非有限事前波动率和不合格品种的目标权重为零。
5. 截面 market_rank_ls 的净敞口在数值容差内为零。
6. 所有最终权重必须满足配置的单品种上限和最大 gross。

### 5.5 换手与成本不变量

V1 使用单边权重变动口径：

$$
Turnover_t
=
\sum_i |w_{i,t}-w_{i,t^-}|.
$$

由于 V1 不模拟非调仓日漂移，$w_{i,t^-}$ 就是应用当日强制退出前的上一有效研究权重。

1. 初始建仓从零权重开始计算。
2. 从 $+w$ 反向至 $-w$ 产生 $2|w|$ 的权重变化。
3. 品种池强制退出计入换手和成本。
4. 未调仓且无强制退出时，换手和成本为零。
5. 成本率必须与单边换手口径一致。

### 5.6 可解释性不变量

1. 品种贡献之和必须等于组合毛收益。
2. 多空方向贡献之和必须等于组合毛收益。
3. 有分类数据时，板块贡献之和必须等于组合毛收益。
4. 约束绑定、风险估计降级和空仓原因必须保留在结果中。
5. 报告只能消费 DiagnosticPortfolioResult，不能在绘图阶段重新计算另一套权重或收益。

### 5.7 输入不可变不变量

任何函数都不得原地修改 DiagnosticSignal.values、ResearchDataset.main_panel、ResearchDataset.universe 或辅助分类表。

## 6. 核心领域对象

配置和结果对象使用 frozen dataclass。冻结只能防止属性重绑定，不能让 pandas 对象真正不可变，因此仍需用测试保护输入不被修改。

### 6.1 DiagnosticSignal

DiagnosticSignal 表示进入组合实验的单列信号。

| 字段 | 类型 | 含义 |
|---|---|---|
| name | str | 信号稳定名称 |
| values | pd.Series | MultiIndex[timestamp, product] 单列数值 |
| source_stage | Literal['raw', 'preprocessed'] | 信号来自原始因子还是预处理结果 |
| factor_name | str | 来源因子名称 |
| recipe | Mapping[str, Any] | 因子参数和预处理配方 |
| warnings | tuple[str, ...] | 上游计算警告 |

V1 不接受多列 DataFrame。复合因子以后也应先收敛为一列明确的预测变量，再扩展 source_stage 枚举。

校验规则：

- name 和 factor_name 非空。
- values 必须是数值型 pd.Series。
- 索引层级严格命名为 timestamp、product。
- 索引唯一；可排序但不允许重复聚合。
- 不允许正负无穷；NaN 按缺失信号政策处理。
- recipe 必须可以序列化，不允许放入策略、账户或优化器实例。

### 6.2 RebalanceConfig

| 字段 | 类型 | 规则 |
|---|---|---|
| interval | int | 正整数，表示每隔多少个全局研究时点调仓 |
| anchor | date / pd.Timestamp / None | 调仓锚点；None 表示全局时间轴首个时间戳 |

anchor 不在时间轴上时，使用大于等于 anchor 的首个时间戳作为实际锚点。anchor 晚于倒数第二个时间戳时没有可评价调仓，属于配置错误。

### 6.3 RiskConfig

| 字段 | 类型 | 适用范围 |
|---|---|---|
| volatility_lookback | int | 时序两种配方必填 |
| volatility_min_periods | int | 时序两种配方必填，且不大于 lookback |
| covariance_lookback | int / None | 目标波动率配方必填 |
| covariance_min_periods | int / None | 目标波动率配方必填 |
| target_volatility | float / None | ts_inv_vol_target_vol 必填，年化正数 |

所有经济参数显式配置，不为波动率窗口、协方差窗口和目标波动率设置隐藏默认值。

滚动标准差使用 ddof=1。volatility_min_periods 至少为 2。

### 6.4 ConstraintConfig

| 字段 | 类型 | 规则 |
|---|---|---|
| max_product_weight | float / None | 单品种最终绝对权重上限，取值 (0, +∞) |
| max_gross | float | 最终 gross 上限，正数 |
| max_leverage | float / None | 目标波动率缩放倍数上限，正数 |

max_leverage 只约束目标波动率缩放倍数；max_gross 约束最终绝对权重之和。二者即使在某些配方下数值效果相近，也必须分别记录，不能合并成同一字段。

### 6.5 CostConfig

| 字段 | 类型 | 规则 |
|---|---|---|
| rate | float / Mapping[str, float] | 统一或按品种的单边单位权重成本率 |

规则：

- 所有成本率必须有限且非负。
- Mapping 的品种代码规范化为大写。
- Mapping 必须覆盖 DatasetSpec.products 中全部品种；多余键报错，避免拼写错误被忽略。
- V1 不支持日期维度成本面板。

### 6.6 DiagnosticPortfolioSpec

| 字段 | 类型 | 含义 |
|---|---|---|
| name | str | 本次组合实验名称 |
| harvest_profile | HarvestProfile | 收获范式 |
| rebalance | RebalanceConfig | 调仓规则 |
| risk | RiskConfig / None | 风险参数 |
| constraints | ConstraintConfig | 权重约束 |
| costs | CostConfig | 成本代理 |
| clip_bound | float / None | 时序 clip 的正数边界 |
| min_cross_section_size | int / None | 截面排名所需最少有效品种数，至少 2 |
| realized_volatility_lookback | int | 输出组合滚动实现波动率的窗口，正整数 |
| annualization_factor | int | V1 日频默认 252，必须为正整数 |

配置的适用性由 harvest_profile 决定：

| 范式 | 必需配置 | 禁止或忽略 |
|---|---|---|
| ts_inv_vol_gross_one | risk 中的单品种波动率参数、clip_bound | covariance 和 target_volatility 必须为 None |
| ts_inv_vol_target_vol | 完整 RiskConfig、clip_bound、max_leverage | min_cross_section_size 必须为 None |
| market_rank_ls | min_cross_section_size | risk 和 clip_bound 必须为 None |

不允许“接受后忽略”互相矛盾的配置。出现不适用字段时直接报错，保证配置哈希与实际行为一致。

### 6.7 DiagnosticPortfolioResult

| 字段 | 类型 | 索引/列语义 |
|---|---|---|
| signal_name | str | 输入信号名称 |
| spec | DiagnosticPortfolioSpec | 完整不可变配置 |
| target_weights | pd.DataFrame | index=决策时间，columns=product |
| rebalance_flags | pd.Series[bool] | 全局决策时间轴 |
| weight_changes | pd.DataFrame | 当期有效权重减前一期有效权重 |
| turnover | pd.Series | 决策时间索引 |
| decision_cost | pd.Series | 决策时间索引 |
| product_contributions | pd.DataFrame or pd.Series | index=收益实现时间，columns=product；或 Index[timestamp, product] |
| portfolio_returns | pd.DataFrame | gross_return、cost、proxy_net_return |
| nav | pd.DataFrame | gross_nav、proxy_net_nav |
| exposures | pd.DataFrame | gross、net、long、short、active_count |
| risk | pd.DataFrame | ex_ante_volatility、realized_volatility、scaling_factor |
| product_attribution | pd.DataFrame | 分品种汇总贡献和占比 |
| direction_attribution | pd.DataFrame | long、short 汇总贡献 |
| sector_attribution | pd.DataFrame / None | 有分类数据时输出 |
| performance | pd.DataFrame | index=gross/proxy_net，列为核心绩效 |
| status | pd.DataFrame | 每个决策时点的有效数、约束状态和降级原因 |
| warnings | tuple[str, ...] | 汇总警告 |
| metadata | Mapping[str, Any] | 输入范围、时间约定、公式口径和版本信息 |

所有中间表必须使用稳定排序。输入列顺序不同不得改变最终产品列顺序；产品列统一按品种代码升序排列。

## 7. HarvestProfile 调整

### 7.1 新增 ts_inv_vol_gross_one

新增：

~~~python
ts_inv_vol_gross_one = HarvestProfile(
    name='ts_inv_vol_gross_one',
    strategy_family='time_series',
    signal_mapping='clip',
    risk_scaling='inverse_volatility',
    neutrality='none',
    risk_allocation='equal_product',
    portfolio_target='gross_one',
    position_limit='per_instrument_and_gross',
    cost_proxy='linear_turnover',
    uses_covariance=False,
)
~~~

它用于隔离信号、逆波动率和基础风险分配本身的经济价值，不引入组合协方差和目标波动率。

### 7.2 注册表政策

现有 MAINSTREAM_HARVEST_PROFILES 继续表示理论文档中的六种主流范式，不因新增研究基线而改名或改变原顺序。

新增：

~~~python
V1_DIAGNOSTIC_PORTFOLIO_PROFILES = (
    ts_inv_vol_gross_one,
    ts_inv_vol_target_vol,
    market_rank_ls,
)
~~~

DiagnosticPortfolioExperiment 仅接受该元组中的配置。factors/__init__.py 导出新基线、V1 注册表、公共配置、结果对象和运行器。

## 8. 公共入口与纯函数边界

### 8.1 运行器

公共入口：

~~~python
class DiagnosticPortfolioExperiment:
    def run(
        self,
        signal: DiagnosticSignal,
        dataset: ResearchDataset,
        spec: DiagnosticPortfolioSpec,
    ) -> DiagnosticPortfolioResult:
        ...
~~~

运行器无持久可变状态。同一输入重复调用必须得到相同结果。

### 8.2 纯函数

至少将以下行为实现为无状态、可独立测试的纯函数：

- 校验并构造联合输入面板。
- 生成全局调仓标志。
- clip 信号映射。
- 截面平均排名去中心化。
- 滚动单品种波动率。
- 滚动协方差矩阵。
- 协方差数值修复。
- 时序基础权重。
- 截面市场中性权重。
- 目标波动率缩放。
- gross 和单品种上限。
- 权重变化、换手和成本。
- 下一期贡献和组合收益。
- 暴露、归因、净值和绩效。

纯函数只接受计算所需的最小 pandas/numpy 对象和参数，不接受完整 Runner、账户或策略上下文。

## 9. 联合输入和全局时间轴

### 9.1 联合面板

运行器先以 ResearchDataset.main_panel.index 为唯一主索引：

1. 校验 main_panel 索引唯一且可排序。
2. 校验 True_Return 存在并为数值型。
3. 将 universe 重索引到主索引；缺失布尔值是数据错误，不自动填充。
4. 检查 DiagnosticSignal 是否包含主索引以外的行；存在则报错。
5. 将信号重索引到主索引，主面板中未提供的信号行成为 NaN。
6. 不因信号或收益缺失删除主面板行。

联合长表至少包含：

~~~text
timestamp
product
signal
true_return
eligible
~~~

### 9.2 全局时间轴

全局时间轴为主面板 timestamp 层级去重、升序后的 DatetimeIndex。

每个产品的收益先透视为：

~~~text
index: global timestamp
columns: product
values: True_Return
~~~

权重 t 与收益 t+1 按该全局时间轴相邻行配对。禁止按产品对非缺失记录直接 shift(-1)，因为这会让缺少某日记录的产品跨越多个组合研究期。

### 9.3 可评价区间

最后一个全局时间戳只作为前一决策权重的收益实现时点，不在该日建立新的可评价目标权重，也不计样本末端虚构的建仓成本。

V1 不收取样本结束时的强制平仓成本。该约定写入 metadata：

~~~text
terminal_liquidation_cost: false
~~~

## 10. 调仓日程和权重状态机

### 10.1 调仓日生成

令全局时间轴为 $T_0,\dots,T_{N-1}$。只有 $T_0,\dots,T_{N-2}$ 可以成为决策时点。

若 anchor=None，则实际锚点为 $T_0$。若 anchor 不在时间轴，取第一个满足 $T_k\ge anchor$ 的时间戳。

从实际锚点在全局时间轴中的位置 k 开始，每隔 interval 个全局研究时点标记一次计划调仓：

$$
is\_rebalance(T_j)
=
\mathbf 1\{j\ge k,\;(j-k)\bmod interval=0\}.
$$

### 10.2 状态转换顺序

每个决策时点执行：

~~~text
上一期有效权重
    ↓
识别当期 universe 退出品种并立即归零
    ↓
若为计划调仓日：
    使用当期 eligible、signal 和风险数据重算全部目标权重
否则：
    保留未退出品种的上一期权重
    新进入品种继续为零
    ↓
应用最终约束校验
    ↓
计算 weight_change、turnover 和 decision_cost
~~~

### 10.3 计划调仓失败

在计划调仓日：

- 时序模式没有任何有效信号/波动率品种时，全组合目标权重为零。
- 截面模式有效品种少于 min_cross_section_size 时，全组合目标权重为零。
- 截面信号全相等导致去中心化结果全零时，全组合目标权重为零。

这些情况不抛出整个实验，但在 status 和 warnings 中记录。因为这是明确的“该日无法形成组合”，而不是数据契约被破坏。

## 11. 时序 CTA 权重算法

### 11.1 信号映射

对每个合格品种：

$$
g_{i,t}
=
\max(-c,\min(s_{i,t},c)),
$$

其中 c=clip_bound。

缺失或非有限信号的 $g_{i,t}$ 为 NaN，随后该品种权重设为零。V1 不用零填充后再参与波动率或有效数量统计。

### 11.2 单品种事前波动率

使用该品种截至 t 的 True_Return：

$$
\widehat\sigma_{i,t}
=
\operatorname{Std}
\left(
r_{i,t-L_\sigma+1:t}
\right).
$$

规则：

- ddof=1。
- 至少 volatility_min_periods 个有限收益。
- 波动率必须有限且严格大于零。
- 波动率窗口按每个产品的全局时间轴计算，缺失日期保留为缺失，不压缩时间。

逆波动率中的日频或年化尺度会在 gross 归一化时抵消，因此基础权重使用单期波动率。

### 11.3 等品种风险预算和 gross-one

对信号和波动率均有效的品种：

$$
u_{i,t}
=
\frac{g_{i,t}}{\widehat\sigma_{i,t}}.
$$

基础 gross-one 权重为：

$$
w^{base}_{i,t}
=
\frac{u_{i,t}}{\sum_j |u_{j,t}|}.
$$

若分母为零或非有限，则当期全组合空仓。

“等品种风险预算”表示各品种在同样信号强度下，通过 $1/\sigma$ 获得相近的独立波动风险预算；它不意味着考虑相关性后的精确等风险贡献。

### 11.4 ts_inv_vol_gross_one

该范式使用 $w^{base}$ 进入约束阶段，不进行组合目标波动率缩放。

### 11.5 ts_inv_vol_target_vol

先用 $w^{base}$ 和当期协方差矩阵估计年化事前组合波动率：

$$
\widehat\sigma_{p,t}^{ann}
=
\sqrt{
A\,
(w_t^{base})^\mathsf T
\widehat\Sigma_t
w_t^{base}
}.
$$

目标缩放倍数：

$$
\lambda_t^*
=
\frac{\sigma^*}
{\widehat\sigma_{p,t}^{ann}}.
$$

应用缩放倍数上限：

$$
\lambda_t
=
\min(\lambda_t^*,\lambda_{max}).
$$

未约束目标权重：

$$
w^{scaled}_{i,t}
=
\lambda_t w^{base}_{i,t}.
$$

若组合风险为零、非有限或协方差估计失败，则该计划调仓日全组合空仓，不回退到 gross-one；否则结果会违反 HarvestProfile 声明的目标波动率语义。

## 12. 截面 market_rank_ls 权重算法

### 12.1 有效截面

在计划调仓日 t，截面有效产品必须同时满足：

- universe 为 True。
- signal 有限。

若有效数量小于 min_cross_section_size，当期全组合空仓。

### 12.2 平均排名和去中心化

使用升序平均排名处理重复值：

$$
rank_{i,t}
=
\operatorname{RankAverage}(s_{i,t}).
$$

去中心化分数：

$$
q_{i,t}
=
rank_{i,t}
-
\frac{1}{N_t}
\sum_j rank_{j,t}.
$$

因此：

$$
\sum_i q_{i,t}=0.
$$

未约束权重：

$$
w^{base}_{i,t}
=
\frac{q_{i,t}}
{\sum_j |q_{j,t}|}.
$$

从而：

$$
\sum_i w^{base}_{i,t}=0,
\qquad
\sum_i |w^{base}_{i,t}|=1.
$$

若所有信号相等，则平均排名相等、分母为零，当期全组合空仓。

### 12.3 为什么不使用头尾分组

V1 的截面黄金路径使用连续 rank 权重而不是头尾 quantile：

- 所有有效品种都可以贡献信息。
- 重复值由平均排名确定性处理。
- 权重可以手工复算。
- 与 market_rank_ls 的 signal_mapping='rank' 保持一致。

头尾分组已经属于 FactorEvaluator 的分组诊断语义；以后若增加 quantile_group 组合，应作为新的显式 HarvestProfile，不能静默替换当前算法。

## 13. 滚动样本协方差

### 13.1 输入窗口

协方差仅用于 ts_inv_vol_target_vol。

在计划调仓日 t：

1. 取最终基础权重非零品种集合。
2. 取截至 t、长度不超过 covariance_lookback 的全局收益窗口。
3. 每个品种至少需要 covariance_min_periods 个有限观测。
4. 缺少自身方差的品种从当期基础组合中移除，随后重新做 gross-one 归一化。

### 13.2 样本协方差

使用 pairwise complete observations 计算样本协方差。原因是动态品种池和局部缺失可能让全截面 listwise complete 样本过少。

数值修复按固定顺序执行：

1. 对角线使用各品种自身样本方差。
2. 非对角缺失协方差填零，并记录缺失配对数量。
3. 取 $(\Sigma+\Sigma^\mathsf T)/2$ 强制对称。
4. 做特征值分解，将小于零的特征值截断为零。
5. 重建半正定协方差矩阵。

若修复后的矩阵仍含非有限值，或基础组合方差小于等于数值容差，则当期目标波动率估计失败并空仓。

V1 不实现 Ledoit-Wolf、EWMA、因子协方差或其他收缩估计。

### 13.3 元数据

每个目标波动率调仓日记录：

- 使用窗口起止时间。
- 有效品种数。
- pairwise 缺失协方差数量。
- 修复前最小特征值。
- 截断特征值数量。
- 修复后组合事前波动率。

## 14. 组合约束及其顺序

约束顺序必须固定：

~~~text
生成基础权重
→ 可选目标波动率缩放
→ 最大缩放倍数
→ 最大 gross
→ 单品种绝对权重上限
→ 重新计算最终 gross、net 和事前风险
~~~

### 14.1 最大 gross

若缩放后：

$$
G_t=\sum_i |w_{i,t}| > G_{max},
$$

则统一缩放：

$$
w_{i,t}
\leftarrow
w_{i,t}\frac{G_{max}}{G_t}.
$$

### 14.2 时序组合的单品种上限

时序组合对每个品种执行：

$$
w_{i,t}
\leftarrow
\max(-c_i,\min(w_{i,t},c_i)).
$$

V1 不把被截断的权重重新分配给其他时序品种。这样不会因为某个品种触发上限而被动增加其他信号的风险。

结果可以低于 gross 或目标波动率，必须报告：

- upper-limit-binding 的品种数。
- 最终 gross。
- 最终事前波动率。
- 目标波动率缺口。

### 14.3 截面组合的单品种上限

截面组合需要同时保持单品种上限和市场中性：

1. 将正权重与负权重分成两侧。
2. 分别对每侧执行 cap-and-redistribute。
3. 在未触及上限的同侧品种中，按原绝对权重比例分配剩余侧 gross。
4. 迭代至没有新增 binding 品种。

原始目标为多头侧 $+0.5$、空头侧 $-0.5$。若任一侧因品种数量和上限无法承载 0.5，则取两侧共同可达到的较小绝对侧 gross，使：

$$
LongExposure_t
=
|ShortExposure_t|,
$$

从而保持 net=0，但允许最终 gross 小于 1。

约束结束后若净敞口绝对值超过数值容差，则属于实现错误而不是警告。

## 15. 调仓、换手和成本

### 15.1 权重变化

令当期约束后的有效权重为 $w_t$，上一决策时点的有效权重为 $w_{t^-}$：

$$
\Delta w_{i,t}
=
w_{i,t}-w_{i,t^-}.
$$

初始 $w_{i,t^-}=0$。

非调仓日若没有品种退出：

$$
\Delta w_{i,t}=0.
$$

### 15.2 换手

$$
Turnover_t
=
\sum_i|\Delta w_{i,t}|.
$$

V1 不使用二分之一换手口径。

### 15.3 品种成本

统一成本率时：

$$
Cost_t
=
\kappa\sum_i|\Delta w_{i,t}|.
$$

按品种成本率时：

$$
Cost_t
=
\sum_i\kappa_i|\Delta w_{i,t}|.
$$

### 15.4 成本与收益时间对齐

调仓成本发生于决策时点 t，并从随后 t 到 t+1 持有区间的收益中扣除：

$$
R_{t+1}^{proxy\_net}
=
R_{t+1}^{gross}
-
Cost_t.
$$

结果中同时保存：

- decision_cost：索引为决策时点 t。
- portfolio_returns.cost：索引为收益实现时点 t+1。

二者数值相同、索引相差一个全局研究期，避免调用方自行 shift。

## 16. 收益、净值和缺失收益政策

### 16.1 产品贡献

$$
C_{i,t+1}
=
w_{i,t}r_{i,t+1}.
$$

若 $w_{i,t}=0$，即使 $r_{i,t+1}$ 缺失，该品种贡献按零处理。

若 $w_{i,t}\ne0$ 且内部样本日期的 $r_{i,t+1}$ 缺失，则实验失败。V1 不允许：

- 把该收益填零。
- 临时删除该品种后重新归一化历史权重。
- 跳过整个组合收益日期。

这些做法都会使用未来已知的缺失状态或改变既定持仓语义。

### 16.2 组合收益

$$
R_{t+1}^{gross}
=
\sum_i C_{i,t+1}.
$$

$$
R_{t+1}^{proxy\_net}
=
R_{t+1}^{gross}-Cost_t.
$$

### 16.3 净值

初始净值约定为 1，但不额外插入虚构时间戳。收益实现时间 t 的净值为：

$$
NAV_t
=
\prod_{\tau\le t}(1+R_\tau).
$$

gross_nav 和 proxy_net_nav 分别由对应收益序列计算。

若任一期收益小于等于 -1，净值不具有有效复利含义，实验失败。

## 17. 暴露、风险和归因

### 17.1 暴露

对每日有效研究权重输出：

$$
Gross_t=\sum_i|w_{i,t}|,
$$

$$
Net_t=\sum_iw_{i,t},
$$

$$
Long_t=\sum_i\max(w_{i,t},0),
$$

$$
Short_t=\sum_i\min(w_{i,t},0).
$$

active_count 为绝对权重大于数值容差的品种数。

### 17.2 事前风险

ts_inv_vol_target_vol 使用最终约束后权重重新计算事前年化波动率。目标缩放前和约束后的风险都进入 status，risk 表中的 ex_ante_volatility 保存最终风险。

ts_inv_vol_gross_one 若已经具备有效协方差参数则仍不额外估计组合风险，因为该配方禁止 covariance 配置；其 ex_ante_volatility 为 NaN，并在 metadata 中说明“不适用”，不是计算失败。

market_rank_ls 的 V1 也不计算事前协方差风险。

### 17.3 实现风险

对 gross_return 使用 DiagnosticPortfolioSpec.realized_volatility_lookback 的滚动标准差：

$$
\widehat\sigma_{realized,t}^{ann}
=
\sqrt A\,
\operatorname{Std}(R^{gross}_{t-L+1:t}).
$$

该窗口属于所有组合范式共享的结果口径，因此位于 DiagnosticPortfolioSpec，而不属于只有时序组合使用的 RiskConfig。

### 17.4 PnL 归因

产品归因至少输出：

- gross_contribution_sum。
- contribution_share；总贡献为零时为 NaN。
- positive_period_count。
- active_period_count。

方向归因按形成收益时的权重符号划分：

- long_contribution。
- short_contribution。

若 dataset.auxiliary['classification'] 存在，并提供 product、sector，则按 sector 汇总产品贡献。分类缺失的产品归入显式的 unclassified，不静默删除。

V1 不计算风险贡献。

## 18. 核心绩效指标

对 gross_return 和 proxy_net_return 分别计算相同指标。

### 18.1 总收益

$$
TotalReturn
=
\prod_{t=1}^{T}(1+R_t)-1.
$$

### 18.2 算术年化收益

$$
AnnualizedArithmeticReturn
=
A\operatorname{Mean}(R_t).
$$

### 18.3 CAGR

$$
CAGR
=
\left(
\prod_{t=1}^{T}(1+R_t)
\right)^{A/T}
-1.
$$

### 18.4 年化波动率

$$
AnnualizedVolatility
=
\sqrt A\operatorname{Std}(R_t),
$$

样本标准差使用 ddof=1。

### 18.5 Sharpe

V1 无风险收益固定为零：

$$
Sharpe
=
\sqrt A
\frac{\operatorname{Mean}(R_t)}
{\operatorname{Std}(R_t)}.
$$

无风险收益假设写入 metadata。标准差为零或有效期数少于 2 时返回 NaN 和警告，不返回误导性的零。

### 18.6 最大回撤

$$
DD_t
=
\frac{NAV_t}{\max_{\tau\le t}NAV_\tau}-1,
$$

$$
MDD=\min_t DD_t.
$$

### 18.7 performance 表

~~~text
index:
    gross
    proxy_net

columns:
    total_return
    annualized_arithmetic_return
    cagr
    annualized_volatility
    sharpe
    max_drawdown
    n_periods
~~~

## 19. 运行器固定编排顺序

DiagnosticPortfolioExperiment.run() 的固定顺序：

1. 校验 spec 与 HarvestProfile 是否匹配。
2. 校验 DiagnosticSignal。
3. 校验 ResearchDataset 和 True_Return。
4. 构建联合长表、全局时间轴和宽表视图。
5. 生成计划调仓标志。
6. 预计算时序模式所需的单品种波动率。
7. 逐决策时点运行权重状态机：
   - 应用强制退出；
   - 必要时生成新基础权重；
   - 必要时估计协方差和目标波动率；
   - 应用约束；
   - 保存 status。
8. 计算权重变化、换手和决策成本。
9. 将有效权重与下一全局时间戳收益对齐。
10. 校验非零持仓的内部缺失收益。
11. 计算贡献、毛收益和代理净收益。
12. 计算净值、暴露、风险、归因和绩效。
13. 汇总 warnings 和 metadata。
14. 构造 DiagnosticPortfolioResult。

伪代码：

~~~python
def run(signal, dataset, spec):
    validate_spec(spec)
    panel = align_inputs(signal, dataset)
    timeline = build_global_timeline(panel)
    rebalance_flags = build_rebalance_schedule(timeline[:-1], spec.rebalance)

    previous_weights = zero_weights()
    records = []

    for timestamp in timeline[:-1]:
        eligible = universe_at(timestamp)
        carried = force_exit(previous_weights, eligible)

        if rebalance_flags[timestamp]:
            proposed = build_weights(
                timestamp=timestamp,
                panel=panel,
                spec=spec,
            )
        else:
            proposed = carried

        final_weights = enforce_constraints(proposed, spec)
        change = final_weights - previous_weights
        record(timestamp, final_weights, change)
        previous_weights = final_weights

    contributions = align_weights_to_next_returns(records, panel)
    returns = aggregate_returns_and_costs(contributions, records, spec.costs)
    return build_result(records, contributions, returns, spec)
~~~

## 20. 人工黄金路径

### 20.1 时序 gross-one

某调仓日两个品种：

| product | signal | clip_bound | clipped | volatility |
|---|---:|---:|---:|---:|
| A | 2.0 | 1.0 | 1.0 | 0.02 |
| B | -1.5 | 1.0 | -1.0 | 0.01 |

逆波动率原始权重：

$$
u_A=1/0.02=50,
\qquad
u_B=-1/0.01=-100.
$$

gross-one 权重：

$$
w_A=1/3,
\qquad
w_B=-2/3.
$$

下一期收益：

| product | next True_Return |
|---|---:|
| A | 0.03 |
| B | -0.01 |

组合毛收益：

$$
R^{gross}
=
\frac13(0.03)
-
\frac23(-0.01)
=
0.016666\ldots
$$

测试必须逐项验证 clipped、u、权重、产品贡献及组合收益。

### 20.2 截面 rank 多空

某调仓日：

| product | signal | average rank | centered rank |
|---|---:|---:|---:|
| A | 10 | 1.0 | -2.0 |
| B | 20 | 2.5 | -0.5 |
| C | 20 | 2.5 | -0.5 |
| D | 40 | 4.0 | 1.0 |
| E | 50 | 5.0 | 2.0 |

绝对分数之和为 6，权重为：

| product | weight |
|---|---:|
| A | -1/3 |
| B | -1/12 |
| C | -1/12 |
| D | 1/6 |
| E | 1/3 |

应满足：

$$
\sum_iw_i=0,
\qquad
\sum_i|w_i|=1.
$$

### 20.3 固定间隔与强制退出

interval=2，调仓日为 T0、T2、T4：

| 时点 | 计划调仓 | A universe | B universe | 行为 |
|---|---|---|---|---|
| T0 | 是 | True | True | 建立 A、B 权重 |
| T1 | 否 | True | False | A 冻结，B 强制归零并计成本 |
| T2 | 是 | True | True | A、B 按新信号重算，B 可重新进入 |
| T3 | 否 | True | True | 权重冻结 |

测试必须确认 T1 不因 B 退出而重新分配 A 的权重。

### 20.4 成本

若某品种从 +0.2 反向到 -0.3：

$$
|\Delta w|=|-0.3-0.2|=0.5.
$$

若单边成本率为 0.0003：

$$
Cost=0.5\times0.0003=0.00015.
$$

成本在下一收益实现时间戳从 gross_return 扣除。

## 21. 错误、警告与降级政策

### 21.1 致命错误

以下情况抛出 ValueError，并停止实验：

- 不支持的 HarvestProfile。
- 配置字段冲突、非法窗口、非法约束或负成本。
- 成本映射缺少或多出品种。
- 非日频 DatasetSpec。
- 主面板缺少 True_Return。
- 索引名称错误、重复或存在输入面板外信号行。
- universe 重索引后缺失。
- 输入含正负无穷。
- 非零持仓对应内部下一期收益缺失。
- 截面最终权重违反市场中性数值容差。
- 最终权重违反 hard cap 或 max_gross 数值容差。
- 单期组合收益小于等于 -1。

### 21.2 可降级情况

以下情况当期空仓或降低目标，同时记录 status：

- 计划调仓日没有有效时序信号和波动率。
- 截面有效品种数不足。
- 截面信号全相等。
- 目标波动率协方差估计失败。
- 单品种上限导致无法使用全部 gross。
- 目标波动率受 max_leverage、max_gross 或产品上限限制。

### 21.3 警告结构

warnings 保存面向实验级别的去重摘要；逐日细节进入 status。警告字符串使用稳定代码前缀，例如：

~~~text

COVARIANCE_ZERO_FILLED
COVARIANCE_EIGEN_CLIPPED
TARGET_VOL_NOT_REACHED
PRODUCT_CAP_BOUND
GROSS_CAP_BOUND
~~~

status 至少包含：

~~~text
is_scheduled_rebalance
is_forced_exit
n_eligible
n_valid_signal
n_valid_risk
n_active
turnover
gross_exposure
net_exposure
scaling_factor
n_product_caps_bound
~~~

## 24. 测试计划

所有 pytest 命令从仓库根目录执行。核心测试只使用 synthetic 人工面板，不依赖 db 或仓库外 RAW_DATA。

### 24.1 模型与配置

- frozen dataclass 无法重新赋值。
- 非法 interval、窗口、min_periods、目标波动率和上限报错。
- Profile 与不适用配置冲突报错。
- 成本映射品种集合不一致报错。
- 不支持的四种 HarvestProfile 报错。

### 24.2 输入与时间轴

- MultiIndex 层级错误、重复和乱序。
- 信号为主面板子集时正确重索引。
- 信号出现面板外行时报错。
- universe 缺失时报错。
- 全局下一期与产品下一非缺失记录不同时，使用全局下一期。
- 最后一个时间戳不产生孤立调仓成本。

### 24.3 时序权重

- clip 上下边界。
- 波动率窗口和 ddof。
- 零波动率、缺失波动率和窗口不足。
- inverse-vol 和 gross-one。
- 全零信号空仓。
- 产品上限绑定后不向其他时序品种重分配。

### 24.4 截面权重

- 平均排名和重复值。
- 去中心化、net=0、gross=1。
- 有效品种不足。
- 全相等信号。
- 单品种上限的两侧重分配。
- 约束不可完全使用 gross 时仍保持 net=0。

### 24.5 调仓状态

- interval=1 每期调仓。
- interval>1 固定间隔调仓。
- anchor 在时间轴内和时间轴之间。
- 非调仓日冻结。
- 新品种等待下一调仓日。
- 非调仓日强制退出。
- 调仓日组合无效时旧权重全部平为零。

### 24.6 风险与目标波动率

- 协方差只使用 t 及以前数据。
- pairwise 缺失填零。
- 对称化和负特征值截断。
- target_volatility / ex_ante_volatility 缩放。
- max_leverage 和 max_gross 的优先顺序。
- 产品上限造成目标波动率缺口。
- 无效协方差当期空仓。

### 24.7 换手与成本

- 初始建仓。
- 加仓、减仓、平仓和方向反转。
- 强制退出。
- 非调仓零换手。
- 统一成本率。
- 按品种成本率。
- 决策成本与下一收益期成本列的索引对齐。

### 24.8 收益、净值和归因

- 权重乘下一期 True_Return。
- 零权重对应缺失收益贡献为零。
- 非零权重对应内部缺失收益报错。
- 产品贡献加总。
- long/short 贡献加总。
- sector 和 unclassified 贡献加总。
- gross/proxy net 净值。
- 收益小于等于 -1 报错。

### 24.9 绩效

- 总收益。
- 算术年化。
- CAGR。
- 年化波动率。
- Sharpe。
- 最大回撤。
- 单期和零波动序列返回 NaN 警告。

### 24.10 因果性

对时点 t 之后的信号、收益、品种池和分类数据分别做扰动，验证：

- t 及以前的目标权重不变。
- t 及以前的风险估计不变。
- t 及以前的换手与成本不变。
- t+1 以后允许改变。

### 24.11 端到端黄金路径

构造含以下事件的小面板：

- 两次计划调仓。
- 一个重复值截面。
- 一个零波动品种。
- 一个品种中途退出并再次进入。
- 一次方向反转。
- 两种品种成本率。
- 一个产品权重上限绑定。

分别运行时序 gross-one、时序 target-vol 和截面 rank 三份配置，逐表验证结果。

## 26. V1 完成标准

V1 只有同时满足以下条件才算完成：

- 同一 DiagnosticPortfolioExperiment 可以运行 ts_inv_vol_gross_one、ts_inv_vol_target_vol 和 market_rank_ls。
- 两个策略家族使用同一数据、调仓、收益、成本、结果和警告契约。
- 所有权重和收益均严格遵守 t 决策、t+1 收益。
- 固定间隔调仓、权重冻结、动态进入和强制退出行为明确且经过测试。
- 时序 inverse-vol 与截面 rank 权重可以在人工面板上手工复算。
- 滚动协方差和目标波动率不存在未来信息。
- 单品种上限、最大 gross 和最大缩放倍数均由测试保护。
- 换手、成本、贡献、净值和核心绩效可以手工复算。
- 结果同时保存权重、贡献、暴露、风险、约束状态和警告，不只输出净值。
- 核心测试不依赖本机真实行情。
- 不导入或创建订单、合约张数、成交、保证金、账户或强平状态。
- 公共接口由 factors/__init__.py 稳定导出。
- 完整 pytest 回归通过。

V1 完成后可以支持：

> 某个单因子在明确的时序 CTA 或全市场截面多空收获规则下，形成了可复现的毛收益和代理成本后收益，其收益来源、换手、暴露、风险和约束状态均可追溯。

V1 仍不能支持：

> 该因子已经形成满足真实合约映射、执行、保证金和账户约束的可交易策略收益。

## 28. 最终原则

组合实验层的最小经济对象不是订单和账户，而是：

$$
\boxed{
\text{因果信号}
\rightarrow
\text{透明连续权重}
\rightarrow
\text{下一期研究收益}
\rightarrow
\text{可解释的代理净值}
}
$$

它必须比完整回测简单，以隔离信号质量；也必须比 IC 和分组收益具体，因为信号映射、风险缩放、调仓和成本本来就是因子能否被收获的一部分。

V1 的核心验收原则是：

> 每一个净值点都能向前追溯到当时可见的信号、品种池、风险估计和权重；每一份组合收益都能向下分解到品种贡献、换手和成本；任何真实执行语义都不在本组件中伪造。
