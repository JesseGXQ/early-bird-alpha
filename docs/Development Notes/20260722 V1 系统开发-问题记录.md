下面，我将围绕第9章：V1与V2能力边界，具体描述相应修改：
1. 数据：将动态品种池放入V1，包含基础过滤条件为品种上市时长、日成交量等流动性约束。
    - 品种池参数进入实验配置。
2. 数据：暂时取消日内因子研究功能。日内因子研究的因子构造理论、数据来源、数据量、标签构造、交易成本建模、评价方法、合成和对策略的交付都和日频因子研究不同。整套pipeline和日频因子研究的具有显著差异，**领域知识和实现复杂度也显著更高**。V1和V2版本都暂时不要涉及日内因子研究框架。
3. 因子接口：删去复合与注册查询功能。保留增量接口。
4. 因子样例：时序动量+截面动量+展期收益率为三个基础因子，后续增加基差动量、仓单变化率因子。暂时取消因子族、复合因子功能，这是个人项目因子库膨胀到一定阶段，或者说是机构级的能力。
