# Alpha101 算子表达式实现说明

## 1. 文档目的

《101 Formulaic Alphas》中的 Alpha 是一套**算子表达式**，并不是可以脱离执行语义直接
计算的完整算法。例如 `rank(x)` 只说明做横截面排名，却没有完整规定：返回原始名次还是
百分位、并列如何处理、缺失值是否参与排名。不同算子库即使逐字实现同一条 Alpha 公式，
仍可能产生显著不同的信号。

本文记录 `alphas101_strict.py` 当前实际采用的算子契约。这里的“严格”是指公式树、窗口
取整和缺失值处理尽量忠于论文；**不表示论文已经唯一确定了下文所有实现参数**。

本文将约定分为三类：

- **论文明确规定**：例如非整数时间窗口向下取整、`scale` 的绝对值和目标、行业内去均值。
- **当前实现选择**：例如 rank 使用百分位、tie 取平均、`ts_argmax` 使用 1-based 位置。
- **Pandas/NumPy 默认行为**：例如滚动标准差和协方差使用 `ddof=1`。

## 2. 数据布局和两个计算轴

所有数值输入采用“日期 × 标的”的 `pandas.DataFrame`：

```text
             asset_A  asset_B  asset_C
2026-01-05      ...      ...      ...
2026-01-06      ...      ...      ...
```

- 行轴是时间，所有 `ts_*`、`delay`、`delta`、`correlation`、`covariance`、
  `decay_linear` 等操作沿行轴滚动，即每一列独立计算。
- 列轴是当日横截面，`rank`、`scale`、`indneutralize` 沿列轴计算。
- 滚动窗口中的“天”在代码中实际是**行数/观测数**，不是日历天数，也不会自动识别交易日。
- 代码假定输入已经按时间升序排列，但当前**没有验证**索引单调性。若输入降序，所有
  `delay` 和滚动窗口的经济含义都会反转。
- 必需行情字段必须拥有与 `close` 完全相同的 index、columns 及顺序，否则初始化报错。
- 当前未禁止重复日期或重复标的列；调用者应保证二者唯一。
- 必需数值字段在初始化时转换为 `float`，因此条件结果和离散信号最终通常也是浮点数。

## 3. 全局窗口、无产出期和缺失值约定

### 3.1 非整数窗口

所有传入 `_window(d)` 的窗口或位移统一执行：

```python
floor(float(d))
```

例如 `17.9282 → 17`、`1.06157 → 1`。结果小于 1 时抛出 `ValueError`。这是论文附录
明确规定的语义。

### 3.2 窗口边界

Pandas 的整数滚动窗口采用默认边界：

- 当前行包含在窗口中；
- 长度为 `d` 的窗口由当前行及之前 `d-1` 行组成；
- `center=False`，结果记在窗口最右端，即当前日期；
- 没有前视数据。

### 3.3 `min_periods`

所有滚动算子显式使用 `min_periods=d`。这意味着窗口内必须有 **d 个非缺失观测**才计算，
不是“只要有若干样本就计算”。因此：

- 每列开头至少有 `d-1` 行处于无产出期，结果为 NaN；
- 窗口中只要有一个 NaN，通常该窗口结果就是 NaN；
- 对双变量滚动算子，必须有 d 对同时有效的 `(x, y)` 观测。

### 3.4 无穷与 NaN

- `safe_divide`、`safe_log`、`correlation`、`covariance` 会把 `+inf/-inf` 转成 NaN。
- `compute(number)` 在每条 Alpha 的最终出口再次把 `+inf/-inf` 转成 NaN。
- 不使用 `fillna(0)`，也不以 epsilon 替换公式中的零分母。
- 普通 Pandas/NumPy 算术遵循 NaN 传播规则。
- 需要注意：不是每个中间算子都会立即清理无穷值。例如 `returns()`、`product()`、
  `signed_power()` 本身不调用 `_finite()`；如果极端输入在中间产生 inf，inf 可能先参与后续
  排名或运算，最终出口才会清理。正常的正价格数据一般不会触发这一点，但这是当前实现
  的真实边界，而不是一个已经完全封闭的“任何中间异常都立即 NaN”契约。

## 4. 算子逐项说明

### 4.1 `_window(d)`

| 项目 | 当前实现 |
|---|---|
| 输入 | 可转换为 float 的整数或小数 |
| 取整 | 向下取整 `floor` |
| 最小值 | 1 |
| 0/负数 | 抛出 `ValueError` |
| NaN/无穷 | 由 `floor()` 抛出异常 |

### 4.2 `returns(close)`

使用 `close.pct_change(fill_method=None)`：

```text
returns[t] = close[t] / close[t-1] - 1
```

- 是简单收益率，不是对数收益率。
- 第一行是 NaN。
- 不向前填充缺失 close。
- 按 DataFrame 当前行顺序计算，不检查交易日是否连续。
- **若调用者显式传入 `returns`，则直接使用调用者数据，不重新计算或核验其定义。**
- 前一日 close 为 0 时可产生 inf；`returns()` 自身不清理该 inf。

### 4.3 `ts_sum(x, d)` 与 `sma(x, d)`

`ts_sum` 是完整窗口滚动求和；`sma` 是完整窗口算术平均。

- 均使用 floor 后的 d。
- 均要求 d 个有效观测。
- `sma(x,d)` 数学上等于 `ts_sum(x,d)/d`，但代码主要用它构造 `adv{d}`。
- 不采用指数权重，也不对异常值缩尾。

### 4.4 `stddev(x, d)`

调用 `DataFrame.rolling(d, min_periods=d).std()`，未显式传入 `ddof`，因此采用 Pandas
默认：

```text
ddof = 1
```

也就是样本标准差，分母为 `d-1`，不是总体标准差的 d。

- d=1 时结果为 NaN。
- 常数窗口在 d≥2 时返回 0。
- 论文没有明确规定 ddof；`ddof=1` 是当前实现选择/Pandas 默认，不是论文唯一答案。

### 4.5 `correlation(x, y, d)`

调用 `x.rolling(d, min_periods=d).corr(y)`：

- 每个标的沿时间计算 Pearson 相关系数。
- 需要 d 对同时非缺失的观测。
- 常数窗口因任一侧标准差为 0，相关系数为 NaN。
- d=1 时相关系数为 NaN。
- 输出的 `+inf/-inf` 转成 NaN，不填 0。
- Pandas 会按 index/columns 标签对齐 x、y；平台输入字段本身要求同形同序。
- 相关系数在代数上不受协方差/方差共同 ddof 的影响，但具体 NaN 和数值稳定性仍由
  Pandas 实现决定。

### 4.6 `covariance(x, y, d)`

调用 `x.rolling(d, min_periods=d).cov(y)`，未显式传入 `ddof`，故：

```text
ddof = 1
```

- 返回样本协方差，分母为 `d-1`。
- d=1 时为 NaN。
- 常数序列与另一序列的协方差在有效窗口中为 0。
- 输出无穷值转成 NaN。
- 论文没有规定 ddof；这是当前实现/Pandas 默认值。

### 4.7 `rank(x)`：横截面排名

调用：

```python
x.rank(axis=1, method="average", pct=True)
```

精确语义：

| 项目 | 当前实现 |
|---|---|
| 方向 | 每个日期沿标的列横截面排名 |
| 顺序 | 升序；最小值排名最低 |
| 输出 | 百分位名次 `rank / 当日有效标的数` |
| 数值范围 | `1/N ... 1`，不是 `0 ... 1` |
| tie | 并列名次取平均 `method="average"` |
| NaN | 不参与排名，原位置保持 NaN |
| 分母 N | 当日该表达式中非 NaN 的标的数，会随日期变化 |

例：`[10, 20, 20, NaN]` 的输出为 `[1/3, 2.5/3, 2.5/3, NaN]`。

论文只写了“cross-sectional rank”，没有规定百分位映射和 tie 方法。百分位加平均 tie 是
当前实现选择。它尤其影响阈值为 0.5 的公式和横截面样本数随时间变化的场景。

### 4.8 `ts_rank(x, d)`：时间序列排名

对每个标的、每个完整窗口执行：

```python
pd.Series(window).rank(method="average", pct=True).iloc[-1]
```

- 只返回**当前值（窗口最后一个值）**在该窗口内的百分位名次。
- 升序排名；窗口最小值接近 `1/d`，最大值为 1。
- 输出范围为 `1/d ... 1`，不包含 0。
- tie 取平均名次。
- 需要 d 个有效观测，否则 NaN。

论文没有规定 `Ts_Rank` 返回 `1..d` 原始名次还是百分位。本实现选择百分位，使其与
横截面 `rank` 处于相近尺度，也避免在 Alpha68/86/95 等比较式中加入论文不存在的人工
窗口倍率。这是重要的复现假设。

### 4.9 `scale(x, a=1)`

逐日横截面执行：

```text
scale(x)[t,i] = a * x[t,i] / sum_j(abs(x[t,j]))
```

- 分母只对当日非 NaN 标的求和；至少有一个非 NaN 才生成分母。
- 原始 NaN 位置保持 NaN。
- 当日所有有效值都为 0 时，分母 0 被转成 NaN，因此该日结果全部为 NaN，而不是 0。
- a 可以为任意标量；当前公式使用默认 a=1。
- 不做去均值、去极值或市场中性化；`scale` 只约束绝对值和。

横截面方向和 `sum(abs(x))=a` 来自论文；零向量如何处理没有明确规定，返回 NaN 是当前
实现选择。

### 4.10 `delay(x, d)` 与 `delta(x, d)`

```text
delay(x,d)[t] = x[t-d]
delta(x,d)[t] = x[t] - x[t-d]
```

- d 先向下取整。
- 位移按行位置进行，不按日期差值进行。
- `delay` 前 d 行为 NaN。
- 不跨列，不填补停牌或缺失交易日。

### 4.11 `product(x, d)`

- 使用完整窗口的 `np.prod`。
- d 先向下取整，需要 d 个有效观测。
- 不使用对数域计算，长窗口或大数可能上溢为 inf，小数可能下溢。
- 算子内部不主动把 inf 转成 NaN，最终 `compute()` 会清理仍存在的 inf。

### 4.12 `ts_min(x, d)` 与 `ts_max(x, d)`

- 返回包含当前行在内、过去 d 行的最小/最大值。
- d 先向下取整，需要 d 个有效观测。
- 并列值不影响返回的数值。
- 论文中的一元 `min(x,d)`/`max(x,d)` 按时间序列 min/max 理解。

### 4.13 `ts_argmax(x, d)` 与 `ts_argmin(x, d)`

当前实现分别使用 `np.argmax(window) + 1` 和 `np.argmin(window) + 1`。

| 项目 | 当前实现 |
|---|---|
| 计数基准 | 1-based |
| 窗口方向 | 从最旧观测向当前观测计数 |
| 返回范围 | `1 ... d` |
| 位置 1 | 窗口最旧观测 |
| 位置 d | 当前观测 |
| 并列 | NumPy 返回第一次出现，即选择离当前最远的那一次 |
| NaN | 完整窗口要求使函数不会在含 NaN 窗口上执行 |

例：窗口 `[5, 2, 5]` 的 `ts_argmax` 返回 1，而不是 3。

论文只说“which day ... occurred”，没有明确 0/1-based、从当前向过去还是从过去向当前，
也没有规定 tie。这一契约是当前实现中最需要与其他平台对齐的假设之一。

### 4.14 `decay_linear(x, d)`

窗口按 `[最旧, ..., 当前]` 排列，使用归一化权重：

```text
[1, 2, ..., d] / (1 + 2 + ... + d)
```

因此当前值权重最大，为 `d / sum(1..d)`；最旧值权重最小，为 `1 / sum(1..d)`。

- d 先向下取整。
- 要求完整的 d 个有效观测。
- 权重和严格归一到 1。
- 不对缺失值重新分配权重。

这对应“权重随数据变旧线性衰减”的解释。论文写作 `d,d-1,...,1` 时没有显式写出数组
存储方向；本文用“当前权重 d、最旧权重 1”消除该歧义。

### 4.15 `signed_power(x, a)`

实现为：

```text
sign(x) * abs(x) ** a
```

- 保留底数符号，指数可为标量或同形 DataFrame。
- `sign(0)=0`、`sign(NaN)=NaN`。
- 与普通 `x ** a` 不同：负底数遇到小数指数时仍返回实数。
- `0` 的负指数等极端情况仍可能产生 NaN/inf，函数内部不清理，最终出口清理 inf。

部分公式对已经非负的 rank 使用普通 `**`，其结果与 SignedPower 等价；显式写有
`SignedPower` 或指数本身为表达式时使用本函数。

### 4.16 `safe_log(x)`

- 只在 `x > 0` 时计算自然对数 `ln(x)`。
- `x <= 0`、NaN、正负无穷导致的无效结果统一为 NaN。
- 不使用 `log1p`，不加 epsilon，不取绝对值。

### 4.17 `safe_divide(x, y)`

- DataFrame 分母中等于 0 的元素先替换为 NaN。
- 标量分母等于 0 时直接抛出 `ZeroDivisionError`。
- 结果中的 `+inf/-inf` 转成 NaN。
- 不使用 epsilon，不截尾。
- NumPy/Pandas 标签对齐规则仍然有效。
- 当前公开契约只支持 DataFrame 或标量分母，没有为 Series 分母设计专门分支。

### 4.18 比较和条件表达式

`_comparison(left, right, "lt")` 实现逐元素严格小于 `<`；其他当前预留分支实现 `<=`。

- 真为 `1.0`，假为 `0.0`。
- right 为 DataFrame 时，任一操作数为 NaN 的位置结果为 NaN，而不是 Pandas 比较默认
  产生的 False。若直接向该内部函数传入标量 NaN，当前实现不会为 right 另建有效性掩码，
  有效 left 会得到 0；现有 101 条公式没有传入标量 NaN。
- 当前 101 条公式通过该辅助函数实现需要输出数值布尔量的主要比较式。
- Alpha9/10/21/23/24/27/46/49/51 等复杂三元条件使用 `where` 单独实现，并额外添加
  有效性掩码，以避免无产出期产生伪 0、1 或 -1。
- `||` 按逐元素逻辑或解释，不使用 Python 标量布尔短路。
- 比较遵循 IEEE/Pandas 精确比较，不设浮点容差；例如 `== 1` 没有近似判断。

### 4.19 二元 `elementwise_min/max`

论文同时出现 `min(x,d)`（时间序列最小值）与 `min(x,y)`（两个表达式逐元素取小）。代码
分别使用不同函数消除重载歧义：

- `ts_min/ts_max`：时间序列滚动算子；
- `elementwise_min/elementwise_max`：两个同形表达式逐元素比较。

二元 min/max 采用 complete-case：x 或 y 任一为 NaN，结果就是 NaN。相等时选择 x，但
数值结果没有差别。

### 4.20 `indneutralize(x, groups)`

当前实现是论文所述的**逐日、组内简单去均值**：

```text
neutralized[t,i] = x[t,i] - mean(x[t,j] for j in same_group(t,i))
```

- 不是带权回归，不使用市值权重，也不做标准化或去极值。
- 均值跳过组内 x 的 NaN。
- x 为 NaN 的位置仍为 NaN。
- 分类标签缺失的标的不参与任何组，结果为 NaN。
- 组内只有一个有效标的时，该标的结果为 0。
- 静态分类用“标的 → 分组”的 Series；动态分类用“日期 × 标的”的 DataFrame。
- 静态 Series 会按标的列重排；动态 DataFrame 会同时按日期和标的重排。
- 每次中性化只使用当日分类，不做分类生效日滞后，调用者必须避免未来信息。
- Alpha100 按原公式连续执行两次相同 subindustry 去均值；理论上第二次接近恒等操作，
  但仍保留公式结构和浮点结果。

论文明确要求组内横截面去均值，但没有规定缺失分类、单成员组和动态分类时点；上述行为
是当前实现选择。

## 5. 输入派生量的实现假设

### 5.1 `adv{d}`

论文附录将 `adv{d}` 定义为过去 d 日的 average daily dollar volume。当前实现：

1. 代码按 `data.get("dollar_volume", data.get("amount"))` 取值：若不存在
   `dollar_volume` 键，则尝试 `amount`；
2. 若取得的是 DataFrame，直接作为日成交额；若显式存在 `dollar_volume=None`，不会再
   回退读取 `amount`；
3. 两者都未提供时，构造 `vwap * volume`；
4. `_adv(d) = sma(dollar_volume, d)`，d 向下取整且要求完整窗口。

当前不自动乘股票/期货合约乘数、不做币种换算，也不核验 amount 单位。论文部分公式直接
比较 `adv` 与 `volume`，存在量纲歧义；本实现选择服从论文附录的 dollar-volume 定义。
这是与许多网络版 Alpha101（常把 adv 当平均成交量）最容易产生巨大差异的地方。

### 5.2 `cap`

- 只在调用需要它的 Alpha56 时读取。
- 必须是日期 × 标的 DataFrame。
- `_field("cap")` 会重排到 close 的 index/columns；缺少的日期或标的变成 NaN。
- 不自动用价格和股本推导，不做币种或单位调整。

### 5.3 行业分类

`sector`、`industry`、`subindustry` 只在相应 Alpha 被调用时要求存在。它们是标签，不转换
成 float。分类体系和层级由调用者决定；实现不会验证 sector/industry/subindustry 的嵌套
一致性。

### 5.4 价格、成交量和 VWAP

实现不会自动完成下列处理：

- 前复权/后复权；
- 除权除息处理；
- 主力合约拼接或换月复权；
- 停牌日补值；
- 涨跌停、不可交易标的过滤；
- 极端值缩尾；
- VWAP 计算或成交额单位换算。

这些必须在输入层确定，否则即使算子完全一致也不能复现同一组 Alpha。

## 6. 输出和调用行为

`Alphas101Strict.compute(number)`：

- 只接受 1 到 101；越界抛出 `ValueError`。
- 动态调用对应的 `alphaNNN()`。
- 最终把正负无穷替换成 NaN。
- 不做最终横截面去均值、标准化、winsorize、缺失填充、行业中性化或交易掩码；只有公式
  明确写出的操作才执行。
- 输出与 close 同样的日期 × 标的布局。

调用某个需要 `cap` 或行业分类的 Alpha 时，如果对应字段缺失，会抛出带字段名的
`KeyError`，不会静默跳过该算子。

## 7. 当前实现的复现签名

若要在另一套引擎中复现当前结果，至少应锁定以下配置：

| 维度 | 当前值 |
|---|---|
| 时间窗口小数 | floor |
| 滚动窗口 | 含当前观测，过去 d 行 |
| `min_periods` | d，要求完整窗口 |
| 横截面 rank | 升序百分位，`rank/N` |
| rank 范围 | `1/N..1` |
| rank tie | average |
| `ts_rank` | 当前值在窗口中的升序百分位 |
| `ts_rank` tie | average |
| stddev | 样本标准差，ddof=1 |
| covariance | 样本协方差，ddof=1 |
| correlation | Pearson；常数窗口 NaN |
| `ts_argmax/min` | 1-based，从最旧到当前，并列取最旧一次 |
| decay 权重 | 最旧 1，当前 d，归一化和为 1 |
| scale | 逐日横截面，绝对值和为 a |
| SignedPower | `sign(x)*abs(x)**a` |
| 除零/非法 log | NaN |
| 行业中性化 | 当日组内等权去均值 |
| adv | 日均成交额；默认 `sma(vwap*volume,d)` |
| returns | 简单 close-to-close 收益率 |
| 最终异常处理 | inf→NaN，不填值 |

## 8. 仍属约定而非论文定论的项目

以下参数对结果有实质影响，但论文没有给出足够细节，当前代码只是选定了一个可重复口径：

1. rank/ts_rank 的百分位映射、是否从 0 开始以及 tie 方法；
2. 标准差和协方差的 ddof；
3. `ts_argmax/min` 的方向、基数和并列选择；
4. decay 权重与窗口数组方向的对应；
5. 所有滚动算子必须满窗口才计算；
6. 零向量 scale 返回 NaN；
7. 缺失分类、单成员行业组的中性化行为；
8. adv 的 dollar-volume 口径及合约乘数；
9. 数据复权、可交易样本和行业分类生效时点。

因此，对外发布因子值、做跨语言复现或与其他 Alpha101 库比较时，应把第 7 节的“复现
签名”与公式一起版本化。只保存 101 条表达式本身，不足以保证可重复性。
